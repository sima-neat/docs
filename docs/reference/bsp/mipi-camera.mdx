# MIPI Camera Configuration

MIPI and GMSL cameras are carrier-board dependent, so they are configured
through device tree overlays rather than shipped defaults. The examples below
come from the reference bring-up on a Waveshare carrier board; the port and bus
numbers will differ on yours.

:::note
See [Carrier Board Bring-up](./carrier-board.mdx) for which components need
adaptation, and [Build the BSP from Source](./build-from-source.mdx) for
building and installing an overlay.
:::

## Enable camera power

Drive the camera power-down line through a GPIO hog. Here port 5, GPIO 6 is used
as the camera power line:

```dts
&port5 {
    cam-hog0 {
        gpio-hog;
        /* Set port5 gpio6 to GPIO_ACTIVE_HIGH mode */
        gpios = <6 0>;
        output-high;
        line-name = "cam0_powdn";
    };
};
```

## Enable the I2C port

Cameras are controlled over I2C. This enables SIO port 5, I2C #2 at 400 kHz:

```dts
&i2c52 {
    status = "okay";
    clock-frequency = <400000>;
    #address-cells = <1>;
    #size-cells = <0>;
};
```

Confirm the bus appears once booted:

```console
root@modalix:~# ls /dev/i2c-*
root@modalix:~# i2cdetect -r -y 0
```

## Configure the power supplies

Camera rails are declared as fixed-voltage regulators — virtual handles telling
Linux that specific voltage rails exist and are powered. They are added to the
root node through an overlay fragment:

```dts
/ {
    fragment@10 {
        target-path = "/";   /* Root node of the base tree */
        /* fixed-voltage regulator nodes for the camera rails */
    };
};
```
