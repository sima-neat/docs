# Release Compatibility

Each Modalix platform release is built from one commit in the public kernel and
U-Boot repositories. To rebuild a component that matches the image on your board,
check out the commit for that release before you build. See
[Build the BSP from Source](./build-from-source.mdx).

## How to Read This Table

- The repositories have no release tags. Each release is a single commit on
  `master`, titled `SiMa.AI Release <version>`.
- `master` always holds the latest release. Building it for a board that runs an
  older release gives you a kernel or bootloader that does not match that board's
  root filesystem and modules.
- Find the release on a running board with `cat /etc/buildinfo`.

To check out a release:

```console
root@sdk:/data/simaai-linux$ git checkout 65aba29989da
```
