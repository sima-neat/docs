# MIPI Camera Interfaces

:::note
Please install or upgrade `sima-cli` before continuing. This guide is intended for use with the latest `sima-cli` version.
:::

:::note
This procedure requires a host with the latest `sima-cli` version installed. It also requires a **Modalix DevKit** firmware version that includes the `.dtbo` files for MIPI support.
:::

The **Modalix DevKit** includes two MIPI interfaces for camera input. The MIPI ports are located on the carrier board.

Before you start, power off the **Modalix DevKit** and attach a MIPI camera to one of the MIPI ports.

Power on the DevKit, and log in to Linux on it over SSH or the serial console.

From Linux, set the U-Boot `dtbos` variable to the appropriate **Device Tree Blob Overlay** (`.dtbo`) file, then reboot. The correct file depends on the **carrier board**, **camera manufacturer**, **sensor type**, and **camera port**.

The filename follows this pattern:

```text
modalix-som-<carrier_board>-<camera_manufacturer>-<sensor_type>-<port>.dtbo
```

Select each component based on your hardware:

| Component | Values | Description |
| --- | --- | --- |
| Carrier Board | `connectech`, `seeedstudio`, `waveshare` | The carrier board model |
| Camera Manufacturer | `ARDU`, `ECON`, `LI` | Arducam, e-con Systems, or Leopard Imaging |
| Sensor Type | `IMX477`, `IMX568`, `FPGA-IMX568`, `KOBE1-IMX568`, `IMX678`, `IMX415`, `AR0234`, `AR0822`, `OG05C10` | The camera sensor model |
| Port | `0CAM`, `1CAM`, `2CAM`, `3CAM`, `DUAL` | The MIPI port number connected to the camera |

By default, the Modalix DevKit has the Waveshare carrier board. For example, for an Arducam IMX477 camera connected to port 1 of a Modalix DevKit:

The U-Boot environment is on a read-only mount, `/var/uboot`. Make it writable, set the variable with `sudo`, and make it read-only again:

```console
sima@modalix:~$ sudo mount -o remount,rw /var/uboot
sima@modalix:~$ sudo fw_setenv dtbos modalix-som-waveshare-ARDU-IMX477-1CAM.dtbo
sima@modalix:~$ sudo mount -o remount,ro /var/uboot
sima@modalix:~$ fw_printenv dtbos
sima@modalix:~$ sudo reboot
```

The camera overlays in platform release 3.0.0 are listed below. To list the overlays on your board, run this command:

```console
sima@modalix:~$ ls /boot/modalix-som-*.dtbo
```

To validate the interfaces, connect the Modalix DevKit to a display and log in. Then, use libcamera to verify camera connectivity.

1. List available cameras:

   ```console
   sima@modalix:~$ cam -l
   ```

2. Show different camera formats for camera 1:

   ```console
   sima@modalix:~$ cam -c 1 -I
   ```

3. Capture an image from camera 1:

   ```console
   sima@modalix:~$ rm -rf frame* && cam -c 1 --capture=1 -F -s pixelformat=NV12
   ```

## Use Multiple Cameras {#multiple-cameras}

To use more than one camera, set `dtbos` to one overlay for each camera, separated by spaces. U-Boot applies every overlay in the list.

The cameras can be different models. Use the overlay that matches the model and port of each camera. For example, for a Modalix DevKit with an e-con Systems IMX678 camera on port 1 and a Leopard Imaging OG05C10 camera on port 2:

The U-Boot environment is on a read-only mount, `/var/uboot`. Make it writable, set the variable with `sudo`, and make it read-only again:

```console
sima@modalix:~$ sudo mount -o remount,rw /var/uboot
sima@modalix:~$ sudo fw_setenv dtbos "modalix-som-waveshare-ECON-IMX678-1CAM.dtbo modalix-som-waveshare-LI-OG05C10-2CAM.dtbo"
sima@modalix:~$ sudo mount -o remount,ro /var/uboot
sima@modalix:~$ fw_printenv dtbos
sima@modalix:~$ sudo reboot
```

- Use one overlay for each port.
- The order of the overlays does not matter.
- A `DUAL` overlay sets up both ports of the Waveshare carrier board with the same camera model. Use either a `DUAL` overlay or two port overlays, not both.
- For the ports that have an overlay on each carrier board, see [Supported MIPI Cameras](../../interfaces/supported-cameras.mdx#ports).
- Not every combination has been tested. Verify yours with `cam -l` and a capture from each camera.

After the board boots, run `cam -l`. It lists one entry for each camera.
