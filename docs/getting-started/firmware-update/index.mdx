# Firmware Update

Keep the DevKit firmware current, recover a device that does not boot, or install a specific firmware release.

This section applies to platform release %platform_version%.

:::note
The guides in this section install images that SiMa.ai provides. To write an image that you built yourself, see [Flash an Image to eMMC](/hardware/deployment/flash-image).
:::

:::note
Please install or upgrade `sima-cli` before continuing. These guides are intended for use with the latest `sima-cli` version.
:::

:::warning
Upgrading a Modalix DevKit across these firmware versions requires a special conversion procedure:

- **1.7 to 2.0:** Follow [Convert to eLxr](/hardware/reference/tech-notes/elxr-conversion) to move from Yocto Linux to eLxr.
- **2.x (including 2.0) to 3.0:** Follow the [Convert from 2.1.3 to 3.0.0](/hardware/reference/tech-notes/convert-2-1-3-to-3-0-0) tech note. First update to 2.1.3, then use netboot to install 3.0.0. A direct firmware update from 2.x to 3.0 is not supported.
:::

## Operating Systems {#os}

SiMa.ai Modalix DevKits run **eLxr Linux**, a Debian-derived distribution. Units shipped **after mid-December 2025** come with eLxr preloaded. Earlier Modalix units (shipped before mid-December 2025) are preloaded with Yocto and can be converted to eLxr following the [Convert to eLxr](/hardware/reference/tech-notes/elxr-conversion) article.

eLxr is a Debian-based OS for development on the Modalix platform. It offers:

- Full Debian package management (`apt`)
- A broader user-space environment for development and debugging
- The ability to build and install tools directly on the device
- Faster iteration without cross-compilation
- A broader ecosystem of libraries and frameworks

Use the firmware update workflows below to update a DevKit, create bootable recovery media, or reflash firmware over the network.

:::tip
If your DevKit does not have Internet access, use a host-based workflow. Use **Net Boot Recovery** to boot from the host and flash eMMC, or **Create Boot Image** to prepare removable boot media. The host machine needs Internet access to download the firmware image unless you already have the image available locally.
:::
