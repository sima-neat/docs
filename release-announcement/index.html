Palette is SiMa.ai’s software platform for building and deploying physical AI applications on Modalix. It connects agentic development, model compilation, execution libraries and system insight in one development experience.

Bring vision, language and voice into products that perceive and interact with the world—from smart cameras and industrial systems to robotics.
