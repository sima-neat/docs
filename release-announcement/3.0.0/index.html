    05 / A NEW FOUNDATION. FAMILIAR APIS.

    More power.
    Less friction.

    Your core C++ and Python Model, Graph and Run APIs are preserved. A new execution foundation works behind the interfaces you already know.

    ModelGraphRunC++ / PYTHON
    01 Purpose-built execution +

    Kernels, Runner, Scheduler and Codecs separate numerical operations, model execution, scheduling and video processing. Flexible memory sharing and DMA allocation help larger models and concurrent workloads fit.

    02 Build, containerize, deploy +

    Build images with the SDK and your host’s Docker or Colima daemon using Buildx. Publish to your registry, then pull and run on the DevKit with access to Modalix drivers. Offline bundles and refreshed toolchains reduce setup friction.

    03 Ready for field maintenance +

    A/B upgrades, USB-drive recovery and simaai-trootctl support servicing deployed systems. Debian 13/eLxr, Docker, VLANs, automatic NVMe provisioning and PCIe management expand deployment options.

    04 Explore Palette Studio +

    Palette Studio is an early release of a new front-end for building applications. Explore the workflows and help shape its evolution with feedback. Alongside the core release, QAT 1.1 improves training and export; separately released PoLiMa 0.3 advances robotics examples.
