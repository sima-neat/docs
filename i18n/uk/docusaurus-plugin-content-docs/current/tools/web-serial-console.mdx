# Web Serial Консоль.

**SiMa.ai Web Serial Console** — це інструмент, який працює в браузері та призначений для підключення до SiMa.ai DevKit безпосередньо з браузера на базі Chromium через [Web Serial API.](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API). Встановлення не потрібне — просто відкрийте інструмент у сумісному браузері, під’єднайте ваш DevKit через USB і встановіть з’єднання.

<a className="docs-button" href={useBaseUrl('/tools/serial/index.html')} target="_blank" rel="noreferrer">Запустіть консоль Web Serial.</a>

## Вимоги

Інтерфейс API Web Serial доступний лише в браузерах, що базуються на Chromium:

- **Google Chrome** (рекомендовано)
- **Microsoft Edge**

:::note
Браузери Firefox і Safari не підтримують API Web Serial і не можуть використовуватися з цим інструментом.
:::

### Linux: доступ до групи `dialout`

У Linux послідовні пристрої, як-от `/dev/ttyUSB0`, належать `root:dialout` і мають режим `crw-rw----`. Нові облікові записи користувачів за замовчуванням не входять до групи `dialout`, тому браузер не може відкрити пристрій і **ваш DevKit не з’явиться у списку вибору послідовного порту**, навіть якщо `lsusb` і `dmesg` показують адаптер USB – Serial, а `/dev/ttyUSB0` існує.

Додайте свого користувача до групи `dialout`:

```console
sudo usermod -aG dialout $USER
```

Потім **вийдіть із системи та ввійдіть знову або перезавантажте комп’ютер** — зміна групи не застосовується до поточного сеансу. Перевірте за допомогою команди:

```console
groups | grep dialout
```

:::note
Цей крок стосується лише Linux. Для macOS і Windows він не потрібен.
:::

## Почнімо.

1. Під’єднайте ваш SiMa.ai DevKit до комп’ютера за допомогою кабелю USB – Serial.
2. Відкрийте [Web Serial Консоль.](pathname:///tools/serial/index.html) у підтримуваному браузері.
3. Натисніть **[+] Створити нове з’єднання** в панелі команд.
4. Оберіть у спливаючому вікні браузера послідовний порт, який відповідає вашому DevKit, і натисніть кнопку **Підключити**.
5. Консоль автоматично виявить запит на вхід і виконає вхід, використовуючи стандартні облікові дані (`sima`/`edgeai`).

## Інтерфейс

### Термінал

Вводьте команди безпосередньо у вікно термінала та натискайте **Enter**, щоб виконати їх на підключеному DevKit.

### Панель команд

Панель команд у нижній частині сторінки забезпечує швидкий доступ до найпоширеніших дій:

| Кнопка | Дія |
| --- | --- |
| **[+] Нове з’єднання** | Відкрийте нову вкладку для встановлення додаткового з’єднання DevKit. |
| **Налаштування** | Налаштуйте швидкість передачі даних і параметри керування потоком перед підключенням. |
| **Увійти** | Надішліть стандартні облікові дані (`sima`/`edgeai`). |
| **Мережа** | Запустіть `ifconfig` на активному DevKit. |
| **Місце на диску** | Запустіть `df -h` на активному DevKit. |
| **Створити** | Відобразити `/etc/buildinfo` з активного DevKit. |
| **Вихід** | Надішліть команду `logout` до активного DevKit. |
| **Зрозуміло** | Очистіть вивід термінала. |
| **Світла/Темна тема** | Перемкніть тему інтерфейсу. |
| **Повноекранний режим** | Увійти в режим повноекранного відображення. |
| **[Приховати]** | Згорніть панель команд, щоб збільшити область відображення термінала. |

### Кілька з’єднань

Консоль підтримує одночасне підключення до кількох пристроїв DevKit. Кожне підключення відкривається як окрема вкладка у верхній частині області термінала. Натисніть на вкладку, щоб перемикатися між активними підключеннями, або натисніть **×** на вкладці, щоб від’єднатися та закрити поточну сесію.

## Від’єднання

Натисніть кнопку **×** на вкладці підключення, щоб розірвати з’єднання. Перед закриттям з’єднання консоль автоматично надішле команду `logout` до DevKit.
