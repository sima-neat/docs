# Збирання та застосування пакета оновлення

Пакет оновлення замінює програмне забезпечення на платі без повторного запису всієї
eMMC. Шар Yocto збирає його як пакет SWUpdate — файл `.swu`. Плата записує нове програмне
забезпечення в копії, з яких вона зараз не працює, перемикається на них і повертається до
попередньої кореневої файлової системи, якщо нова не завантажується. Ця сторінка стосується
образів, зібраних за розділом [Збирання повного образу за допомогою Yocto](../software/yocto-image.mdx).

:::caution[Ще не перевірено на обладнанні]
Цю сторінку написано на основі шару Yocto та вихідного коду U-Boot для випуску платформи
2.1.3. Пакет для цієї сторінки не збирали й не застосовували.
:::

## Як працює оновлення {#how-it-works}

eMMC містить по дві копії U-Boot, каталогу завантаження та кореневої файлової
системи. Див.
[схему розділів](../software/yocto-image.mdx#partitions). Оновлення виконує
такі дії:

1. Записує нову кореневу файлову систему та новий U-Boot у копії, які не
   використовуються.
2. Копіює нове ядро, дерева пристроїв та оверлеї до каталогу завантаження, який
   не використовується, `boot-0` або `boot-1`.
3. Перемикає плату на нові копії, задає в середовищі U-Boot `upgrade_available` значення `1`,
   а `bootcount` — `0`, і перезавантажує плату.

Якщо нове програмне забезпечення не завантажується більше разів, ніж дозволяє `bootlimit`,
U-Boot повертається до попередньої кореневої файлової системи та скидає `upgrade_available`.

## Збирання пакета {#build}

Спочатку зберіть образ, а потім зберіть пакет у тому самому каталозі збирання:

```console
sima-user@sima-user-machine:~/build$ MACHINE=modalix bitbake simaai-image-minimal-upgrade
```

Файл `.swu` розміщено в `tmp/deploy/images/modalix`, разом з образом. Він містить:

| Частина | Файли |
| --- | --- |
| Коренева файлова система | Файл `.rootfs.ext4.gz` образу |
| U-Boot | `u-boot.bin` і сценарій завантаження `boot.scr.uimg` |
| Ядро | `Image` і `Image.enc` |
| Дерева пристроїв та оверлеї | Файли `.dtb` плати та всі файли `.dtbo` |
| Опис оновлення та сценарій | `sw-description` і `update_modalix.sh` |

:::note
У загальнодоступному шарі `sw-description` називає кореневу файлову систему
`simaai-image-palette-modalix.rootfs.ext4.gz`, а рецепт пакує кореневу файлову
систему `simaai-image-minimal`. Перш ніж збирати пакет, узгодьте ці дві
назви.
:::

## Застосування пакета {#apply}

1. Скопіюйте файл `.swu` на плату.
2. Запустіть `swupdate` від імені root:

   ```console
   root@modalix:~# swupdate -v -H simaai-image-palette:1.0 -i /tmp/update.swu
   ```

   Назва та ревізія після `-H` мають збігатися із записом у `sw-description`.
   У загальнодоступному шарі це `simaai-image-palette` і `1.0`. Після завершення
   оновлення плата перезавантажується.

3. Після перезавантаження перевірте версію збірки образу, що працює:

   ```console
   root@modalix:~# grep SIMA_BUILD_VERSION /etc/buildinfo
   ```

## Відновлення {#recover}

- Якщо новий образ не завантажується, U-Boot сам повертається до попередньої кореневої
  файлової системи, як описано в розділі [Як працює оновлення](#how-it-works).
- Якщо жодна копія не завантажується, запишіть повний образ знову. Див. розділ
  [Прошивання образу на eMMC](./flash-image.mdx).

## Що не розглядається {#not-covered}

- Пакети оновлення для образу eLxr.
- Підписані пакети оновлення.
- Як плата позначає оновлення як успішне після вдалого завантаження.
