# Встановіть ROS2 на SOM Devkit Modalix.

У цій технічній записці описано, як встановити [Операційна система для роботів 2 (ROS 2)](https://docs.ros.org/) на модуль SOM Modalix DevKit і чому ROS 2 є цінним доповненням до апаратного забезпечення SiMa.ai для реалізації фізичних обчислювальних завдань, пов’язаних зі штучним інтелектом.

## Що таке ROS 2?

ROS 2 — це операційна система для роботів другого покоління, набір програмних бібліотек і інструментів з відкритим вихідним кодом, призначений для створення роботів і фізичних застосунків штучного інтелекту. На відміну від монолітної операційної системи, ROS 2 є проміжним шаром, який працює поверх Linux і забезпечує стандартний спосіб взаємодії та обміну даними між численними незалежними процесами всередині робота: датчиками, виконавчими механізмами, моделями сприйняття, планувальниками та контролерами.

Основні характеристики:

- **Архітектура на основі вузлів.** Кожна функція (драйвер камери, детектор, контролер двигуна, модуль SLAM) працює як незалежний *вузол*. Вузли створюються під час роботи, тому один і той самий вузол обробки даних можна використовувати в різних роботах.
- **Комунікація на основі DDS.** ROS 2 використовує стандарт Data Distribution Service (DDS) для обміну повідомленнями в режимі реального часу між одноранговими вузлами за принципом «видавець/підписник» із можливістю налаштування параметрів якості обслуговування (надійність, довговічність, термін дії, активність), що є обов’язковою вимогою для робототехнічних систем, де важливі безпека та точність у часі.
- **Стандартні типи повідомлень.** Великий каталог загальновживаних визначень повідомлень (`sensor_msgs`, `geometry_msgs`, `nav_msgs`, `vision_msgs` тощо) дозволяє компонентам, що відповідають за сприйняття, планування та керування, від різних виробників взаємодіяти між собою без використання спеціального допоміжного коду.
- **Підтримує різні платформи та роботу в режимі реального часу.** ROS 2 працює на Linux, підтримує архітектури ARM64 та x86_64 і розроблений для сумісної роботи з ядрами реального часу та стеками мікроконтролерів (micro-ROS).
- **Широка екосистема інструментів.** `rviz2` для тривимірного відображення, `rqt` для внутрішнього аналізу, `rosbag2` для запису та відтворення потоків даних із датчиків і `ros2 launch` для декларативного запуску системи.

## Навіщо запускати ROS 2 на SOM-модулі Modalix?

Фізичний ШІ — автономні мобільні роботи, дрони, роботизовані маніпулятори, автономні мобільні роботи (AMR), інтелектуальні камери з приводами — потребує як **високопродуктивного нейронного виведення**, так і **детермінованої, добре зрозумілої програмної платформи** для датчиків, керування та безпеки. Modalix SOM було розроблено саме для такої комбінації:

- **Перенесіть обробку даних для сприйняття на MLA, а ROS 2 залиште на ядрах Arm.** Вузли сприйняття (розпізнавання об’єктів, сегментація, визначення глибини, пози, об’єднання даних BEV) можуть викликати функції MLA в MLSoC, а видавці ROS 2 передають результати у стандартному форматі `vision_msgs` або `sensor_msgs` — спеціальні протоколи міжпроцесної взаємодії не потрібні.
- **Одна плата, повний набір функцій.** Обробка відеопотоку з камери, машинне навчання, проміжне програмне забезпечення ROS 2, планування та керування двигуном можуть працювати на одній і тій самій обчислювальній платформі Modalix, що усуває затримку та витрати на додаткову обчислювальну плату.
- **Енергоефективне розгортання на периферії.** Завдяки високій продуктивності на одиницю спожитої енергії, платформа Modalix дозволяє пристроям, що працюють від акумуляторів (дрони, автономні мобільні роботи, портативні пристрої для перевірки), запускати сучасні моделі виявлення та відстеження в режимі реального часу без перегріву.
- **eLxr на базі Debian.** Modalix SOM використовує eLxr — середовище виконання, похідне від Debian, тому стандартні пакети ROS 2 `apt` встановлюються без проблем — не потрібна поперечна компіляція або спеціальні шари Yocto для типових випадків.

## Необхідні умови

:::info
Для встановлення ROS 2 на Modalix SOM потрібна версія SDK **2.1.0** або новіша, що працює в середовищі виконання eLxr. Щоб перевірити або змінити середовище виконання, див. [Перетворити на eLxr](./elxr-conversion).
:::

Вам також знадобляться:

- А Modalix SOM DevKit увімкнено та доступно через мережу або послідовний порт.
- `sima-cli` встановлено на DevKit.
- Для завантаження пакетів необхідне активне підключення до Інтернету на пристрої DevKit.

## Встановіть ROS 2.

`sima-cli` надає інсталятор, який виконує всі необхідні дії за один раз: завантажує потрібну версію ROS 2 для Modalix SOM, налаштовує репозиторії apt і встановлює базові пакети та стандартний набір інструментів.

<details open>
<summary><strong>Крок 1. Встановіть ROS 2 за допомогою sima-cli.</strong></summary>

З командного рядка Modalix, виконайте:

```console
sima@modalix:~$ sima-cli install tools/ros2
```

Програма встановлення виконає наступне:

- Додайте необхідні репозиторії Debian `bookworm` та ROS 2 apt, а також ключ підпису ROS.
- Встановіть необхідні пакети для збірки: `cmake`, `colcon`, `vcstool`, а також пакети для розробки Qt і OpenCV, набір плагінів GStreamer та інші бібліотеки, необхідні для збірки та запуску вузлів ROS 2 на SOM.
- Встановіть пакети `ros2` та `colcon`.
- Додайте `source /usr/local/ros2/local_setup.bash` до `/home/sima/.bash_profile`, щоб середовище ROS 2 завантажувалося автоматично під час кожного входу в систему, і активуйте його для поточної оболонки.

</details>

<details open>
<summary><strong>Крок 2. Перевірте встановлення.</strong></summary>

Після завершення встановлення `sima-cli install tools/ros2`, середовище ROS 2 вже налаштовано в поточній оболонці. Переконайтеся, що `ros2` CLI додано до шляху:

```console
sima@modalix:~$ ros2
```

Потім запустіть стандартну демонстрацію взаємодії між «мовцем» і «слухачем» у двох окремих середовищах, щоб переконатися, що проміжне програмне забезпечення DDS працює належним чином:

```console
sima@modalix:~$ ros2 run demo_nodes_cpp talker
```

У другій командній оболонці на тому ж пристрої:

```console
sima@modalix:~$ ros2 run demo_nodes_py listener
```

Програма-слухач має виводити повідомлення `I heard: [Hello World: N]`, коли програма-передавач їх надсилає. ROS 2 тепер готова розміщувати на Modalix SOM вузли сприйняття, планування та керування разом із конвеєрами машинного навчання SiMa.ai.

</details>
