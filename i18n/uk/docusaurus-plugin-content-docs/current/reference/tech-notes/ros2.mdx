# Встановіть ROS 2 на Modalix SoM DevKit.

ROS 2 надає бібліотеки та інструменти для робототехнічних застосунків. Він дозволяє процесам, що відповідають за обробку даних із датчиків, сприйняття, планування та керування, обмінюватися даними. На обчислювальному модулі Modalix, ROS 2 працює на ядрах Arm. Застосунки, що відповідають за сприйняття, можуть використовувати MLA для обчислень нейронних мереж.

## Перш ніж почати.

Вам знадобиться:

- Modalix SoM DevKit з версією платформи **3.0 або новішою**, або **2.1.x**.
- `sima-cli` встановлено на DevKit.
- Для завантаження пакетів на DevKit потрібен доступ до Інтернету.
- Підключення до DevKit через SSH або послідовний порт.

Виконайте всі наведені нижче команди **на DevKit**.

## 1. Перевірте версію платформи.

Перегляньте інформацію про прошивку:

```bash
cat /etc/buildinfo
```

Використовуйте команду встановлення, призначену для вашої версії платформи, наведену нижче.

Щоб перейти з версії 2.1.x на 3.0.0, спочатку виконайте [Оновіть з версії 2.1.3 до 3.0.0.](./convert-2-1-3-to-3-0-0.md).

## 2. Встановіть ROS 2.

### Платформа 3.0 і новіші версії.

Запустити:

```bash
sima-cli neat install ros@v3.0.0
```

Дотримуйтесь інструкцій на екрані, щоб завершити встановлення та налаштувати середовище ROS 2.

### Платформа 2.1.x

Запустити:

```bash
sima-cli install tools/ros2
```

Програма встановлення додає джерела пакетів Debian Bookworm і ROS 2. Вона встановлює ROS 2, інструменти для збирання та необхідні бібліотеки. Крім того, вона додає налаштування середовища ROS 2 до файлу `/home/sima/.bash_profile`, щоб воно застосовувалося під час наступних сеансів.

Щоб завантажити середовище в поточній оболонці, виконайте команду:

```bash
source /usr/local/ros2/local_setup.bash
```

## 3. Перевірте встановлення.

Переконайтеся, що середовище ROS 2 завантажено в кожній оболонці, яка використовується для цієї перевірки.

1. Перевірте, чи доступна команда ROS 2:

   ```bash
   ros2
   ```

2. Запустіть відправник в одній оболонці:

   ```bash
   ros2 run demo_nodes_cpp talker
   ```

3. Відкрийте друге вікно термінала на тому ж DevKit.
4. Запустіть прослуховувач:

   ```bash
   ros2 run demo_nodes_py listener
   ```

Слухач має виводити повідомлення, наприклад, `I heard: [Hello World: 1]`. Ці повідомлення показують, що відправник і отримувач можуть обмінюватися даними.

Щоб зупинити демонстрацію, натисніть **Ctrl+C** у кожній консолі.
