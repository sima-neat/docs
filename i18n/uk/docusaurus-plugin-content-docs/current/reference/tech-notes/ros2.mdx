# Встановіть ROS 2 на модуль Modalix DevKit.

Використовуйте цей посібник, щоб встановити [Robot Operating System 2 (ROS 2)](https://docs.ros.org/) на Modalix SoM DevKit і дізнайтеся, як це впливає на обчислювальні навантаження, пов’язані з фізичним штучним інтелектом.

## Що таке ROS 2?

ROS 2 — це операційна система для роботів другого покоління, набір програмних бібліотек і інструментів з відкритим вихідним кодом, призначений для створення роботів і фізичних застосунків зі штучним інтелектом. Це не монолітна операційна система. Це проміжний шар, який працює на Linux і дозволяє незалежним процесам робота, таким як датчики, виконавчі механізми, моделі сприйняття, планувальники та контролери, знаходити один одного та обмінюватися даними.

Основні функції:

- **Архітектура на основі вузлів.** Кожна функція (драйвер камери, детектор, контролер двигуна, модуль SLAM) працює як незалежний *вузол*. Вузли створюються під час роботи, тому один і той самий вузол обробки даних можна використовувати в різних роботах.
- **Комунікація на основі DDS.** ROS 2 використовує стандарт Data Distribution Service (DDS) для обміну повідомленнями в режимі реального часу між одноранговими вузлами за принципом «видавець/підписник» із можливістю налаштування параметрів якості обслуговування (надійність, довговічність, термін дії, активність), що є обов’язковою вимогою для робототехнічних систем, де важлива безпека та точність у часі.
- **Стандартні типи повідомлень.** Великий каталог поширених визначень повідомлень (`sensor_msgs`, `geometry_msgs`, `nav_msgs`, `vision_msgs` тощо) дозволяє компонентам, що відповідають за сприйняття, планування та керування, від різних виробників взаємодіяти між собою без використання спеціального проміжного коду.
- **Підтримує різні платформи та роботу в режимі реального часу.** ROS 2 працює на Linux, підтримує архітектури ARM64 та x86_64 і розроблений для сумісної роботи з ядрами реального часу та мікроконтролерними системами (micro-ROS).
- **Широкий набір інструментів.** `rviz2` для тривимірного відображення, `rqt` для внутрішнього аналізу, `rosbag2` для запису та відтворення потоків даних із датчиків і `ros2 launch` для декларативного запуску системи.

## Навіщо запускати ROS 2 на платформі Modalix?

Фізичні системи штучного інтелекту, зокрема автономні мобільні роботи, дрони, роботизовані маніпулятори, автономні мобільні роботи (AMR) і інтелектуальні камери з механізмами керування, потребують як **високопродуктивного нейронного обчислення**, так і **детермінованої програмної платформи** для датчиків, керування та забезпечення безпеки. Модуль Modalix підтримує таку комбінацію:

- **Перенесіть обробку даних сенсорів на модуль MLA, а обчислення в ROS 2 виконуйте на ядрах Arm.** Вузли обробки даних сенсорів (розпізнавання об’єктів, сегментація, визначення глибини, пози, об’єднання даних BEV) можуть використовувати модуль MLA в MLSoC, а видавці ROS 2 передають результати у стандартному форматі `vision_msgs` або `sensor_msgs` — спеціальний протокол міжпроцесорної взаємодії не потрібен.
- **Одна плата, повний набір функцій.** Обробка відеопотоку з камери, машинне навчання, проміжне програмне забезпечення ROS 2, планування та керування двигуном можуть працювати на одній і тій самій обчислювальній платформі Modalix, що зменшує необхідність у використанні окремої додаткової обчислювальної плати.
- **Енергоефективне розгортання на периферії.** Забезпечувана Modalix продуктивність на одиницю спожитої енергії підтримує роботу платформ, що живляться від акумуляторів, таких як дрони, автономні мобільні роботи та портативні пристрої для проведення інспекцій.
- **eLxr Debian базова платформа.** На модулі Modalix SoM працює eLxr Debian, що є похідним від стандартного середовища виконання, тому стандартні пакети ROS 2 `apt` встановлюються без проблем — не потрібна попередня компіляція або спеціальні шари Yocto для типових випадків.

## Необхідні умови.

:::info
Для встановлення ROS 2 на Modalix SoM потрібна версія SDK **2.1.0** або новіша, що працює в середовищі виконання eLxr. Щоб перевірити або змінити середовище виконання, див. [Перехід на eLxr](./elxr-conversion).
:::

Вам також знадобляться:

- Модуль Modalix SoM DevKit увімкнено, і до нього можна отримати доступ через мережу або послідовний інтерфейс.
- `sima-cli` встановлено на DevKit.
- Для завантаження пакетів необхідне активне підключення до Інтернету на пристрої DevKit.

## Встановіть ROS 2.

`sima-cli` надає програму встановлення, яка завантажує відповідний дистрибутив ROS 2 для модуля Modalix, налаштовує джерела apt і встановлює базові пакети та стандартні інструменти.

<details open>
<summary><strong>Крок 1. Встановіть ROS 2 за допомогою sima-cli</strong></summary>

З командного рядка Modalix запустіть:

```console
sima@modalix:~$ sima-cli install tools/ros2
```

Програма встановлення:

- Додайте необхідні репозиторії Debian `bookworm` та ROS 2 для apt, а також ключ підпису ROS.
- Встановіть необхідні пакети для збірки: `cmake`, `colcon`, `vcstool`, а також пакети для розробки Qt і OpenCV, набір плагінів GStreamer та інші бібліотеки, необхідні для збірки та запуску вузлів ROS 2 на системі на модулі (SoM).
- Встановіть пакети `ros2` та `colcon`.
- Додайте `source /usr/local/ros2/local_setup.bash` до `/home/sima/.bash_profile`, щоб середовище ROS 2 завантажувалося автоматично під час кожного входу в систему, і активуйте його для поточної оболонки.

</details>

<details open>
<summary><strong>Крок 2. Перевірте встановлення.</strong></summary>

Після завершення `sima-cli install tools/ros2` інсталятор активує середовище ROS 2 у поточній оболонці. Переконайтеся, що CLI `ros2` доступний через `PATH`:

```console
sima@modalix:~$ ros2
```

Потім запустіть стандартну демонстрацію взаємодії між «мовцем» і «слухачем» у двох окремих середовищах, щоб переконатися, що проміжне програмне забезпечення DDS працює належним чином:

```console
sima@modalix:~$ ros2 run demo_nodes_cpp talker
```

В іншій командній оболонці на тому ж пристрої:

```console
sima@modalix:~$ ros2 run demo_nodes_py listener
```

Прослуховувач має виводити на екран повідомлення `I heard: [Hello World: N]`, коли відправник їх публікує. ROS 2 готовий розмістити на Modalix SoM вузли сприйняття, планування та керування разом із конвеєрами машинного навчання SiMa.ai.

</details>
