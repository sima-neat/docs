# Перехід з 2.1.3 на 3.0.0

Ця процедура застосовується до Modalix SoM DevKit та Modalix PCIe карт. На більшість нових плат на заводі встановлено прошивку версії 2.1.x.

У версії 2.1.x використовується системний образ, сумісний з Debian 12. У версії 3.0.0 використовується Debian 13. Вона також містить системні зміни для OverlayFS, A/B образів і SWUpdate.

Ці зміни роблять системний образ 3.0.0 несумісним із системним образом 2.1. Для переходу потрібна спеціальна процедура оновлення. Спочатку оновіть плату до останньої версії прошивки **2.1.3**. Потім використовуйте **netboot**, щоб запустити плату через мережу та записати образ 3.0.0 у її сховище.

У цій інструкції використовуються такі терміни:

- **Плата**: SoM DevKit або плата PCIe.
- **Хост**: комп’ютер Ubuntu або macOS, який надає образ завантаження через TFTP-сервер.
- **Прошивання**: запис системного образу в пам’ять пристрою.

## Перш ніж почати.

- Зробіть резервну копію файлів і конфігурації, які вам потрібні з пристрою.
- Переконайтеся, що плата має доступ до Інтернету для встановлення оновлення 2.1.3.
- Для онлайн-конвертації переконайтеся, що хост має доступ до Інтернету для оновлень CLI та завантаження образів.
- Якщо хост не має доступу до Інтернету під час перетворення, використовуйте процедуру для роботи в автономному режимі, описану в розділі 3.
- Використовуйте **sima-cli версії 2.1.19 або новішої** на хості. За наявності підключення до Інтернету, `sima-cli` автоматично оновлюється до останньої версії.
- Підготуйте Ethernet-з’єднання між платою та хостом.
- За можливості, підготуйте послідовне з’єднання для моніторингу плати.

Щоб встановити останню версію `sima-cli` на **хості**, виконайте команду:

```bash
curl -fsSL https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh | bash
```

## 1. Оновіть прошивку плати до версії 2.1.3.

Виконайте команди, наведені в цьому розділі, **на платі**.

1. Підключіться до плати через SSH або послідовний порт.
2. Перевірте версію прошивки:

   ```bash
   cat /etc/buildinfo
   ```

   Якщо на вашій платі встановлено останню версію **2.1.3**, перейдіть до розділу 2.

3. Встановіть останню версію `sima-cli`:

   ```bash
   curl -fsSL https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh | bash
   ```

4. Розпочніть оновлення прошивки:

   ```bash
   sima-cli update
   ```

5. Дотримуйтесь інструкцій на екрані, щоб встановити останню версію **2.1.3**.
6. Перезавантажте плату, коли буде надано відповідну інструкцію.
7. Перевірте ще раз файл `/etc/buildinfo`, щоб переконатися, що на платі працює версія **2.1.3**.

## 2. Під’єднайте плату до хоста.

Рекомендується використовувати пряме Ethernet-з’єднання з увімкненою функцією спільного доступу до Інтернету.

1. Під’єднайте Ethernet-порт плати до хоста.
2. Увімкніть спільний доступ до Інтернету на хості:
   - **Ubuntu**: дотримуйтесь інструкцій щодо налаштування спільного підключення, описаних у розділі [Налаштування мережі.](/hardware/getting-started/standalone-mode/network).
   - **macOS**: увімкніть функцію спільного доступу до Інтернету для інтерфейсу Ethernet, підключеного до плати.

Як альтернатива, під’єднайте обидві системи до однієї мережі. Хост повинен мати можливість зв’язатися з платою. Плата повинна мати можливість зв’язатися з TFTP-сервером хоста.

### Знайдіть IP-адресу плати.

За умови ввімкненої функції спільного доступу до Інтернету, хост призначає IP-адресу пристрою. Використовуйте послідовну консоль, щоб дізнатися цю адресу.

1. Під’єднайте послідовний порт плати до хоста. Див. [Послідовне з’єднання.](/hardware/getting-started/setup-serial).
2. Відкрийте термінал **на хості** та виконайте команду:

   ```bash
   sima-cli serial
   ```

3. Увійдіть до системи на платі.
4. Виконайте цю команду **на платі**:

   ```bash
   /sbin/ifconfig
   ```

5. Знайдіть Ethernet-інтерфейс, підключений до хоста.
6. Запишіть її IPv4-адресу, яка відображається після `inet`. Не використовуйте адресу loopback `127.0.0.1`.
7. В окремому терміналі **на хості** перевірте з’єднання:

   ```bash
   ping {ip}
   ```

Замініть `{ip}` на записану адресу у всіх командах. Залиште відкритим вікно послідовної консолі, щоб стежити за процесом перетворення.

### Плати PCIe без доступу до послідовного порту

До послідовного порту на платі PCIe може бути важко дістатися. Якщо ви не можете підключити послідовний кабель, скористайтеся наведеним нижче методом із використанням статичної IP-адреси.

На платі PCIe версії **2.1.3** використовується IP-адреса **192.168.1.10**, якщо вона не отримує IP-адресу.

1. Під’єднайте Ethernet-порт карти безпосередньо до хоста.
2. Налаштуйте підключений Ethernet-інтерфейс хоста на адресу **192.168.1.20**, щоб він перебував в одній підмережі з картою.
3. Перевірте з’єднання з хостом:

   ```bash
   ping 192.168.1.10
   ```

4. У розділі 3 використовуйте адресу **192.168.1.10** для `{ip}`.

Ці адреси стосуються Ethernet-порту карти. Інтерфейс [Інтерфейс Ethernet через PCIe.](/hardware/getting-started/pcie-mode/virtual-network) використовує окрему конфігурацію.

## 3. Завантажте та встановіть образ версії 3.0.0.

Виконайте команди в цьому розділі **на хості**.

1. Переконайтеся, що версія CLI — **2.1.19 або новіша**.
2. Якщо ви під’єднали послідовний кабель, залиште вікно послідовної консолі відкритим.
3. В окремому терміналі хоста запустіть процес конвертації:

   ```bash
   sima-cli bootimg -v 3.0.0 --netboot --devkit {ip} --autoflash
   ```

:::tip Хости Ubuntu
В Ubuntu запускайте `sima-cli` через `sudo`, оскільки сервер TFTP використовує привілейований UDP-порт 69. Наведена нижче команда використовує `which sima-cli`, щоб знайти абсолютний шлях до встановленого CLI та виконати перетворення:

```bash
sudo "$(which sima-cli)" bootimg -v 3.0.0 --netboot --devkit {ip} --autoflash
```

Замініть `{ip}` на IP-адресу плати.
:::

Ця команда запускає TFTP-сервер на хості. Вона дає вказівку пристрою завантажуватися з цього сервера. Потім опція `--autoflash` автоматично записує образ на пристрій.

Тримайте термінал хоста відкритим, доки процедура не буде завершена. Переконайтеся, що мережа підключена, а пристрій увімкнено.

### Офлайн-конвертація

Використовуйте цю процедуру, коли хост для мережевої завантажувальної системи не має доступу до Інтернету. На платі вже має бути встановлено останню версію прошивки 2.1.3.

Перш ніж від’єднати хост, встановіть останню версію `sima-cli` і завантажте обидва файли:

```bash
mkdir images && cd images
sima-cli download https://docs.sima.ai/pkg_downloads/SDK3.0.0/devkit/modalix/elxr/elxr-palette-modalix-3.0.0-arm64.img.gz
sima-cli download https://docs.sima.ai/pkg_downloads/SDK3.0.0/devkit/modalix/elxr/modalix-tftp-boot-minimal.tar.gz
cd ..
```

Ви також можете завантажити файли на інший комп’ютер. Скопіюйте каталог `images` на хост для мережевої завантажувальної системи (netboot). На хості для мережевої завантажувальної системи вже має бути встановлена остання версія `sima-cli`.

Залиште обидва файли в стиснутому вигляді. Підключіть плату до хоста, як описано в розділі 2. Для автономного перетворення не потрібно використовувати спільний доступ до Інтернету.

У каталозі, який містить `images`, запустіть на хості таку команду:

```bash
sima-cli bootimg --netboot --images images
```

На Ubuntu виконайте:

```bash
sudo "$(which sima-cli)" bootimg --netboot --images images
```

Ця команда використовує локальні файли для запуску TFTP-сервера. Дотримуйтесь інструкцій щодо завантаження та прошивання плати, наведених у розділі [Відновлення за допомогою мережевої завантажувальної системи.](/hardware/getting-started/firmware-update/net-boot). Потім перейдіть до розділу 4 нижче.

## 4. Перезавантажте плату.

1. Зачекайте, поки `sima-cli` не дасть команду перезавантажити пристрій.
2. Перезавантажте плату.
3. Зачекайте, поки плата запуститься.
4. Підключіться до плати через послідовний порт або SSH.
5. Перевірте версію прошивки **на платі**:

   ```bash
   cat /etc/buildinfo
   ```

6. Переконайтеся, що встановлена версія **3.0.0**, перш ніж продовжувати налаштування системи.

Для хост-систем PCIe дотримуйтесь інструкцій [Встановлення драйвера PCIe.](/hardware/getting-started/pcie-mode/driver-installation), щоб налаштувати драйвер хоста.
