# Налаштуйте NFS.

Використовуйте NFS, коли вам потрібно, щоб DevKit мав доступ до великих наборів даних або файлів моделей, які зберігаються на хості Ubuntu.

NFS (мережева файлова система) забезпечує спільний доступ до файлів між хостом Ubuntu (сервером) і Modalix DevKit (клієнтом). DevKit може отримувати доступ до сховища хоста без створення локальних копій.

:::note
NFS корисний, коли в DevKit відсутнє високошвидкісне сховище великої ємності, наприклад, NVMe. Це стосується таких платформ, як MLSoC і Modalix Early Access Kit (EA), де використання лише SD-карт як сховища може сповільнювати час завантаження.
:::

Використовуйте NFS у таких випадках:

- Великі моделі або набори даних необхідно передавати між різними пристроями.
- Обсяг локального сховища на пристрої користувача обмежений або недоступний.
- Ви віддаєте перевагу централізованому управлінню сховищем для оновлень.

<details open>
<summary><strong>Крок 1. Налаштуйте сервер NFS.</strong></summary>

1. Встановіть сервер ядра NFS:

   ```bash
   sima-user@sima-user-machine:~$ sudo apt update
   sima-user@sima-user-machine:~$ sudo apt install -y nfs-kernel-server
   ```

2. Створіть спільну папку:

   Оберіть папку, якою ви хочете поділитися з Modalix DevKit:

   ```bash
   sima-user@sima-user-machine:~$ sudo mkdir -p /mnt/nfs_share
   sima-user@sima-user-machine:~$ sudo chmod 777 /mnt/nfs_share
   ```

3. Відредагуйте файл налаштувань NFS:

   Відкрийте файл експорту:

   ```bash
   sima-user@sima-user-machine:~$ sudo nano /etc/exports
   ```

   Додайте наступний рядок в кінці, замінивши `<modalix_ip>` на IP-адресу Modalix DevKit:

   ```
   /mnt/nfs_share <modalix_ip>(rw,sync,no_subtree_check)
   ```

   Якщо ви хочете надати доступ з будь-якої IP-адреси у вашій мережі (для тестування), використовуйте:

   ```
   /mnt/nfs_share *(rw,sync,no_subtree_check)
   ```

4. Застосуйте зміни та перезапустіть службу NFS:

   ```bash
   sima-user@sima-user-machine:~$ sudo exportfs -a
   sima-user@sima-user-machine:~$ sudo systemctl restart nfs-kernel-server
   ```

</details>

<details open>
<summary><strong>Крок 2. Налаштуйте клієнт NFS.</strong></summary>

1. Створіть точку монтування:

   ```bash
   modalix:~$ sudo mkdir -p /mnt/
   ```

2. Змонтуйте мережеву файлову систему NFS:

   Замініть `<server_ip>` на IP-адресу хоста Ubuntu:

   ```bash
   modalix:~$ sudo mount <server_ip>:/mnt/nfs_share /mnt/
   ```

3. Перевірте надійність кріплення:

   Перевірте, чи правильно змонтовано мережеву файлову систему NFS:

   ```bash
   modalix:~$ df -h | grep mnt
   ```

</details>

<details open>
<summary><strong>Крок 3. Забезпечення постійного підключення</strong></summary>

Щоб автоматично монтувати мережеву файлову систему NFS під час завантаження, виконайте такі дії: Modalix:

1. Створіть файл `mnt.mount`:

   ```bash
   modalix:~$ sudo vi /etc/systemd/system/mnt.mount
   ```

2. Додайте цей вміст до файлу, замінивши `server_IP` на IP-адресу хоста Ubuntu:

   ```
   [Unit]
   Description=NFS Mount
   After=network-online.target
   Requires=network-online.target

   [Mount]
   What=<server_IP>:/mnt/nfs_share
   Where=/mnt/
   Type=nfs
   Options=defaults,_netdev

   [Install]
   WantedBy=multi-user.target
   ```

3. Збережіть зміни та вийдіть, а потім перевірте налаштування:

   ```bash
   modalix:~$ sudo systemctl daemon-reload
   modalix:~$ sudo systemctl enable mnt.mount
   modalix:~$ sudo systemctl start mnt.mount
   ```

</details>
