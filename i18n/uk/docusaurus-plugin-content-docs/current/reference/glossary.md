# Глосарій

Найпоширеніші абревіатури та терміни, які використовуються в цій документації. Записи згруповано за темами; у межах кожної групи вони розташовані в алфавітному порядку.

## Кремній та обчислювальні технології

**CVU**
: **Модуль комп’ютерного зору.** Апаратний прискорювач, розміщений на кристалі, призначений для обробки класичних задач комп’ютерного зору (фільтри, перетворення, ядра обробки зображень). MLSoC Modalix містить CVU EV74 від Synopsys, що працює на частоті 750 16-бітних операцій в секунду (GOPS).

**ISP**
: **Процесор обробки зображень.** Апаратний блок, розміщений на кристалі, який перетворює необроблені дані з датчика камери (матриця Байєра, монохромний сигнал тощо) в корисне зображення. MLSoC Modalix використовує ARM C-71 ISP, що працює на частоті 1,2 ГГц.

**MLA**
: **Апаратний прискорювач машинного навчання.** Апаратний блок, розміщений на кристалі, який виконує обчислення нейронної мережі. MLA є основною відмінною рисою MLSoC Modalix і є ціллю для застосунків NEAT.

**MLSoC**
: **Система на кристалі для машинного навчання.** Лінійка продуктів SiMa.ai – процесори штучного інтелекту для периферійних обчислень. Ця документація охоплює **MLSoC Modalix**, друге покоління.

**Modalix**
: Назва продукту, що позначає друге покоління SiMa.ai's MLSoC і кристалічну основу кожного комплекту, описаного тут.

**NoC**
: **Мережа на кристалі.** Внутрішньосхемне з’єднання, яке об’єднує MLA, CVU, ISP, обчислювальні ядра застосунку, контролери пам’яті та блоки вводу/виводу. NoC Modalix включає моніторинг продуктивності, брандмауер і засоби керування якістю обслуговування (QoS).

**tRoot**
: Апаратна підсистема кореня довіри на MLSoC, яка забезпечує безпечний запуск, зберігання ключів і аутентифікацію мікропрограми.

## Системне програмне забезпечення

**BSP**
: **Пакет підтримки апаратної платформи.** Набір низькорівневого програмного забезпечення — завантажувач, ядро, дерева пристроїв, драйвери та коренева файлова система — який забезпечує запуск плати SiMa.ai від моменту ввімкнення до отримання доступного для користувача середовища Linux. Див. [Пакет підтримки апаратної платформи](./bsp).

**eLxr**
: [Дистрибутив Debian, на основі якого створено Linux ](https://elxr.org/), який використовується як середовище виконання за замовчуванням на Modalix DevKit, що поставляються після середини грудня 2025 року. Управління користувацьким простором здійснюється за допомогою `apt`.

**sima-cli**
: Інструмент командного рядка, що використовується на хост-системі для прошивання мікропрограм, встановлення драйверів і керування пристроями SiMa.ai через мережу або PCIe.

**U-Boot**
: Завантажувач, який використовується на SiMa.ai DevKit. Відповідає за ініціалізацію DRAM, читання носіїв завантаження та завантаження ядра Linux.

**Yocto**
: Вбудована система збірки Linux (на основі poky), яка використовується для застарілого BSP MLSoC. Modalix DevKit спочатку поставлялися з образом Yocto і можуть бути перетворені на eLxr; див. [Перетворення на eLxr](./tech-notes/elxr-conversion).

## Застосунки та програмні платформи

**NEAT**
: Фреймворк застосунків SiMa.ai для MLSoC Modalix. NEAT замінює застарілий набір інструментів Palette/MPK. Повна документація доступна в [software docs](https://developer.sima.ai/software).

**Застосунок NEAT**
: Запакований конвеєр для виконання висновків на пристрої (модель + граф попередньої/пост-обробки + метадані середовища виконання), створений за допомогою набору інструментів NEAT і завантажений на MLSoC Modalix для виконання.

## Апаратне забезпечення та фізичні розміри

**DevKit**
: Попередньо зібраний набір для розробки SiMa.ai, наприклад, Modalix DevKit або Modalix Early Access DevKit, призначений для оцінки кремнієвого чипа та розробки застосунків перед проєктуванням спеціалізованої плати.

**eMMC**
: **Embedded MultiMediaCard.** Вбудована багатомедійна карта. Внутрішня флеш-пам’ять, припаяна до DevKit. Використовується для зберігання завантажувального образу та кореневої файлової системи.

**HHHL**
: **Half-Height, Half-Length.** Форм-фактор PCIe карти, сумісний з більшістю серверних і робочих станцій. Modalix PCIe Card — це карта HHHL.

**LPDDR5**
: **Low-Power Double Data Rate 5** пам’ять. Системна оперативна пам’ять, що використовується в продуктах Modalix. MLSoC Modalix підтримує 32- і 64-бітні конфігурації LPDDR5 у 8 каналах.

**SoC**
: **System on Chip.** Одинарний чип, який інтегрує процесори, прискорювачі, контролери пам’яті та вхід/вихід, на відміну від багаточипового модуля.

**SoM**
: **System on Module.** Модуль, який містить SoC, а також необхідну оперативну пам’ять, пам’ять і схеми живлення, підключені до роз’єму для інтеграції в спеціалізовану плату. Modalix DevKit побудований на основі Modalix SoM.

## Інтерфейси

**GMSL2**
: **Gigabit Multimedia Serial Link, версія 2.** Серійний протокол автомобільного класу для передачі даних з камер і датчиків за допомогою коаксіального кабелю (FAKRA). Підтримується на платі Modalix PCIe.

**MIPI CSI**
: **Mobile Industry Processor Interface — Camera Serial Interface.** Стандартний високошвидкісний серійний інтерфейс для підключення датчиків зображення до SoC.

## Розгортання

**Режим PCIe**
: Архітектура розгортання, в якій плата Modalix PCIe підключається до хост-машини. Хост-машина обробляє вхідні/вихідні дані та керує процесами; плата обробляє дані для виведення результатів. Див. [PCIe Режим](/hardware/getting-started/pcie-mode).

**Автономний режим**
: Архітектура розгортання, в якій система на базі Modalix DevKit або Modalix SoM працює як самостійний пристрій, обробляючи дані датчиків локально та передаючи результати через мережу. Див. [Автономний режим](/hardware/getting-started/standalone-mode).
