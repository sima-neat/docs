# Глосарій

Найпоширеніші абревіатури та терміни, які використовуються в цій документації. Записи згруповано за темами; у межах кожної групи вони розташовані в алфавітному порядку.

## Кремній і обчислювальні технології

**CVU**
: **Модуль комп’ютерного зору.** Апаратний прискорювач, призначений для обробки класичних завдань комп’ютерного зору (фільтри, перетворення, ядра обробки зображень). MLSoC Modalix містить CVU EV74 від Synopsys, що працює на частоті 750 16-бітних GOPS.

**ISP**
: **Процесор обробки зображень.** Апаратний блок, який перетворює необроблені дані з датчика камери (матриця Байєра, монохромний режим тощо) на корисне зображення. MLSoC Modalix використовує ARM C-71 ISP, що працює на частоті 1,2 ГГц.

**MLA**
: **Апаратний прискорювач машинного навчання.** Апаратний блок, який виконує обчислення нейронної мережі. MLA є основною відмінною рисою MLSoC Modalix і є ціллю для застосунків NEAT.

**MLSoC**
: **Система на кристалі для машинного навчання.** Лінійка периферійних процесорів штучного інтелекту від SiMa.ai. Ця документація охоплює **MLSoC Modalix**, друге покоління.

**Modalix**
: Назва продукту, що позначає SiMa.ai's MLSoC другого покоління, і кристалічна схема, яка є основою кожного комплекту, описаного тут.

**NoC**
: **Мережа на кристалі.** Внутрішньосхемне з’єднання, яке об’єднує MLA, CVU, ISP, ядра застосунків, контролери пам’яті та блоки вводу-виводу. NoC Modalix включає моніторинг продуктивності, брандмауер і засоби керування QoS.

**tRoot**
: Апаратна підсистема кореня довіри на MLSoC, яка забезпечує безпечний запуск, зберігання ключів і аутентифікацію мікропрограми.

## Системне програмне забезпечення

**BSP**
: **Пакет підтримки плати.** Набір низькорівневого програмного забезпечення — завантажувач, ядро, дерева пристроїв, драйвери та коренева файлова система, — який забезпечує запуск плати SiMa.ai від моменту ввімкнення до отримання функціонального середовища користувача Linux. Див. [Пакет підтримки апаратного забезпечення.](./bsp).

**eLxr**
: [Linux-дистрибутив, створений на основі Debian.](https://elxr.org/), що використовується як стандартне середовище виконання на Modalix DevKit, що поставляються після середини грудня 2025 року. Управління простором користувача здійснюється за допомогою `apt`.

**sima-cli**
: Інструмент командного рядка, що використовується на хості для прошивання мікропрограм, встановлення драйверів і керування пристроями SiMa.ai через мережу або PCIe.

**U-Boot**
: Завантажувач, що використовується на SiMa.ai DevKit. Відповідає за ініціалізацію DRAM, читання носіїв завантаження та завантаження ядра Linux.

**Yocto**
: Система збірки вбудованого Linux (на основі poky), що використовується для застарілого BSP MLSoC. Modalix DevKit спочатку поставлялися з образом Yocto і можуть бути перетворені на eLxr; див. [Перетворити на eLxr](./tech-notes/elxr-conversion).

## Застосунки та фреймворки

**NEAT**
: Фреймворк застосунків SiMa.ai для MLSoC Modalix. NEAT замінює застарілий набір інструментів Palette/MPK. Повна документація доступна за посиланням [docs.sima-neat.com](https://docs.sima-neat.com).

**Застосунок NEAT**
: Готовий до використання конвеєр для виконання висновків на пристрої (модель + граф попередньої/пост-обробки + метадані середовища виконання), створений за допомогою набору інструментів NEAT і завантажений на MLSoC Modalix для виконання.

## Апаратне забезпечення та фізичні розміри

**DevKit**
: Попередньо зібрана плата розробки SiMa.ai (Modalix DevKit, Modalix Early Access Kit, Modalix Early Access PCIe Card), призначена для оцінки кремнієвого чіпа та розробки застосунків перед проєктуванням спеціалізованої материнської плати.

**eMMC**
: **Embedded MultiMediaCard.** Вбудована багатомедійна карта. Внутрішня флеш-пам’ять, припаяна до DevKit. Використовується для зберігання завантажувального образу та кореневої файлової системи.

**HHHL**
: **Half-Height, Half-Length.** Форм-фактор PCIe карти, сумісний з більшістю серверних і робочих станцій. Modalix Early Access PCIe Card є HHHL-картою.

**LPDDR5**
: **Low-Power Double Data Rate 5** пам’ять. Системна оперативна пам’ять, що використовується в продуктах Modalix. MLSoC Modalix підтримує 32- і 64-бітні конфігурації LPDDR5 у 8 каналах.

**SoC**
: **System on Chip.** Одинарний чип, який інтегрує процесори, прискорювачі, контролери пам’яті та вхід/вихід, на відміну від багаточипового модуля.

**SoM**
: **System on Module.** Плата, яка містить SoC, а також необхідну оперативну пам’ять, пам’ять і схеми живлення, підключені до роз’єму для інтеграції в спеціалізовану материнську плату. Modalix DevKit розроблено на основі Modalix SoM.

## Інтерфейси

**GMSL2**
: **Gigabit Multimedia Serial Link, версія 2.** Серійний протокол автомобільного класу для передачі даних з камер і датчиків по коаксіальному кабелю (FAKRA). Підтримується на платі Modalix Early Access PCIe.

**MIPI CSI**
: **Mobile Industry Processor Interface — Camera Serial Interface.** Стандартний високошвидкісний серійний інтерфейс для підключення датчиків зображення до SoC.

## Розгортання

**Режим PCIe**
: Архітектура розгортання, в якій MLSoC Modalix розміщується на платі PCIe, підключеній до хост-системи. Хост-система обробляє вхідні/вихідні дані та керує процесами; плата обробляє дані для виведення результатів. Див. [Режим PCIe](/hardware/getting-started/pcie-mode).

**Автономний режим**
: Архітектура розгортання, в якій MLSoC Modalix працює як самостійний пристрій, без хост-системи, обробляючи дані з датчиків локально та передаючи результати через мережу. Див. [Автономний режим](/hardware/getting-started/standalone-mode/).
