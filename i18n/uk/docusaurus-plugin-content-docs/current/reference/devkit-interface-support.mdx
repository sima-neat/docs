# Підтримка інтерфейсів Modalix DevKit

На цій сторінці перелічено інтерфейси Modalix DevKit. Для кожного показано роз’єм на платі,
сигнали Modalix SoM, що стоять за ним, і те, що з ним робить дерево пристроїв випуску
платформи 2.1.3. DevKit — це Modalix SoM на платі-носії Waveshare, тому таблиця
стосується лише цієї комбінації.

:::caution[Ще не перевірено на обладнанні]
Цю сторінку написано на основі вихідного коду ядра для випуску платформи 2.1.3 та
інших сторінок цього сайту. Для жодного рядка ще немає зафіксованого тесту на обладнанні.
:::

## Інтерфейси {#interfaces}

Таблиця охоплює послідовну консоль, Gigabit Ethernet, USB, HDMI, накопичувач NVMe,
камери MIPI CSI-2, I2C, GPIO, SPI, аудіо I2S, Bluetooth, eMMC, годинник реального
часу та CAN. Назва інтерфейсу є посиланням на його посібник, якщо такий існує.

## Як читати статус {#status}

- **Підтримується**: випуск надає інтерфейс на цій платі. Його або вмикає дерево
  пристроїв SoM, або компонент розміщено на SoM і він не потребує налаштування.
- **Потрібен оверлей**: апаратна частина є, але дерево пристроїв випуску її не
  вмикає. Додайте оверлей дерева пристроїв, як описано в розділі
  [Дерева пристроїв та оверлеї](../software/device-tree.mdx).
- **Не підтримується**: інтерфейс не працює з Modalix SoM.
- **Не підтверджено**: на цій сторінці немає інформації.

## Інші плати {#other-boards}

Сигнали SoM однакові на кожній платі-носії. Роз’єми та оверлеї відрізняються.
Для іншої плати-носія почніть із розділів
[Плати-носії сторонніх виробників](../design/third-party-carriers.mdx) і
[Запуск плати-носія](../design/som-carrier.mdx).
