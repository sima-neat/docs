# Modalix DevKit

**Modalix DevKit** — це основний комплект розробника для оцінювання MLSoC Modalix і створення периферійних застосунків ШІ. Він поєднує апаратне прискорення Modalix із програмним стеком, необхідним для розроблення, тестування та виконання таких робочих навантажень, як комп’ютерний зір, великі мовні моделі (LLM) та багатомодальні конвеєри.

<Tabs>
<TabItem value="interfaces" label="Інтерфейси" default>

<img src="/img/devkit/modalix-devkit.png" alt="SiMa.ai Modalix Інтерфейси SoM." style={{width: '60%', display: 'block', margin: '0 auto'}} />

| Інтерфейс | Опис |
| --- | --- |
| Ethernet-порт (end0) | RJ45, мережеві інтерфейси 1GigE для віддаленого підключення. |
| COM-порт для підключення до хоста (USB-C). | Спрощує налагодження, забезпечуючи підключення до хост-системи. |
| MIPI Інтерфейси (X2) | Для підключення камер MIPI. [Налаштування](/uk/hardware/getting-started/standalone-mode/mipi-camera-interfaces) |
| USB Інтерфейси (X4) | Інтерфейси USB 3.0, що підтримують мікрофон, динамік і USB відеокамеру. |
| Інтерфейс HDMI (1 шт.) | HDMI 1.4 для підключення зовнішнього дисплея (максимальна роздільна здатність 4K при 30 Гц, 1080p при 60 Гц). |
| Вбудована пам’ять (eMMC) | 16 ГБ |
| NVMe | M.2, 512 ГБ |
| USB | 4 порти USB 3.0. |

Для отримання додаткової інформації про продукт відвідайте офіційний веб-сайт: [SiMa.ai](https://sima.ai/mlsoc/).

<TabItem value="features" label="Основні характеристики">

| Функція | Деталі |
| --- | --- |
| Продуктивність штучного інтелекту MLA | 50 тераоперацій за секунду для обчислень у нейронній мережі INT8. Також підтримує обчислення з точністю bf16. |
| Споживання енергії | Від 8 Вт до 12 Вт, залежно від навантаження. |
| Прикладний процесорний модуль (APU) | Вісім двопотокових ядер [Arm Cortex-A65 CPU](https://www.arm.com/products/silicon-ip-cpu/cortex-a/cortex-a65), що працюють на частоті до 1,4 ГГц. |
| Відеокодек | Підтримує стандарти стиснення H.264 (AVC), H.265 (HEVC) та MJPEG. Забезпечує підтримку профілів AVC Main/High, HEVC Main та MJPEG Baseline. Кодек підтримує H.264/H.265 зі швидкістю до 4K при 60 кадрах в секунду. |
| Відеодекодер | підтримує стандарти стиснення H.264 (AVC), H.265 (HEVC), AV1 та MJPEG. Він підтримує профілі AVC main/high, HEVC main, AV1 main та MJPEG Baseline. Він підтримує пікселі 4:2:0 і 8-бітну точність. Декодер підтримує H.264/H.265 зі швидкістю до 4KP60. |
| Модуль комп’ютерного зору (CVU) | Чотирьохядерний процесор Synopsys [Процесор ARC EV74 Vision](https://www.synopsys.com/dw/ipdir.php?ds=ev7x-vision-processors), що підтримує до **750 16-бітних GOPS**. |
| Пам’ять | 32 ГБ оперативної пам’яті LPDDR5, з яких 6 ГБ виділено для ядер ARM і 16 ГБ – для модуля машинного навчання (MLA). Решта об’єму пам’яті виділяється для інших компонентів системи. |
| Зберігання | 16 ГБ вбудованої пам’яті eMMC із роз’ємом для карти microSD для додаткового обсягу пам’яті. |
| Мережа | 1 порт 10GigE доступний через плату-носій. |

</TabItem>
