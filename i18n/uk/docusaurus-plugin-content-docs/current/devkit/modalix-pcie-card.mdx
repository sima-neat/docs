#  Модуль PCIe

**PCIe-карта Modalix** — це напіввисока/напівдовга (HHHL) PCIe-карта, розроблена на базі **MLSoC Modalix**. Вона встановлюється в хост-машину та забезпечує спеціалізоване апаратне прискорення обчислень Modalix через інтерфейс PCIe.

<Tabs>
<TabItem value="interfaces" label="Інтерфейси" default>

<img src={useBaseUrl('/img/devkit/modalix-ea-pcie-interfaces.jpg')} alt="Modalix PCIe Card interfaces" style={{width: '100%', display: 'block', margin: '0 auto'}} />

| Інтерфейс | Опис |
| --- | --- |
| Ethernet-порти (eth0, eth1) | RJ45, мережеві інтерфейси GigE для віддаленого підключення. |
| Інтерфейс PCI-Express 5.0 x4 | PCIe-інтерфейс для інтеграції в основну машину. Залежно від конфігурації основної машини можуть знадобитися адаптери. |
| COM-порт для підключення до основної машини | Підключає послідовну консоль до основної машини для налагодження. Зіставте стрілку на кабелі, що входить до комплекту, з крайнім лівим контактом. |
| Слот для SD-карти | Розташований на задній панелі плати Modalix PCIe. |
| GMSL2 FAKRA-порт для камери | Gigabit Multimedia Serial Link-порт для високошвидкісної передачі відео. |

</TabItem>
<TabItem value="features" label="Основні функції">

| Функція | Деталі |
| --- | --- |
| Інтерфейс PCIe | Один інтерфейс PCIe Gen 5.0 x4 з стандартним роз’ємом на краю плати. |
| Системна пам’ять | 16 ГБ або 32 ГБ LPDDR5 DRAM для забезпечення високої пропускної здатності та низької затримки. |
| eMMC Flash-пам’ять | Один інтерфейс eMMC flash-пам’яті об’ємом 32 ГБ для завантаження та системного зберігання. |
| QSPI NOR Flash | Один інтерфейс QSPI NOR flash об’ємом 128 Мбіт для зберігання мікропрограми та завантажувача. |
| Ethernet | Один інтерфейс Ethernet 10 Гбіт/с через роз’єм RJ45. |
| Інтерфейс JTAG | Один додатковий інтерфейс JTAG для апаратного налагодження та запуску. |
| Інтерфейс Micro SD | Один інтерфейс карти Micro SD для знімного зберігання та відновлення системи. |
| Debug UART (tRoot) | Один виділений інтерфейс debug UART для діагностики та налагодження tRoot. |
| Debug UART (Linux) | Один виділений інтерфейс debug UART для доступу до консолі Linux та налагодження. |
| Інтерфейси камери | Два порти GMSL2 FAKRA для підключення віддалених камер через послідовні лінії зв’язку. |
| Індикатор стану | Один світлодіод живлення для відображення стану живлення системи. |

</TabItem>
