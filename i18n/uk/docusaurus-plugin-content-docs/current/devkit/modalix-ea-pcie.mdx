# Modalix: Ранній доступ до PCIe карти.

Плата Modalix PCIe HHHL (половинної висоти/половинної довжини) у версії Early Access містить пристрій Modalix, який забезпечує високу продуктивність і спрощує процес машинного навчання для вбудованих периферійних застосунків.

<Tabs>
<TabItem value="interfaces" label="Інтерфейси" default>

<img src="/img/devkit/modalix-ea-pcie-interfaces.jpg" alt="SiMa.ai Modalix EA, інтерфейси карт PCIe." style={{width: '100%', display: 'block', margin: '0 auto'}} />

| Інтерфейс | Опис |
| --- | --- |
| Ethernet-порти (eth0, eth1) | RJ45, мережеві інтерфейси GigE для віддаленого підключення. |
| Інтерфейс PCI-Express 5.0 x4 | Високошвидкісний інтерфейс PCIe, що використовується для інтеграції в хост-систему. Залежно від конфігурації хоста можуть знадобитися адаптери. |
| COM-порт для хоста. | Спрощує налагодження, забезпечуючи підключення до хост-системи. Переконайтеся, що стрілка на кабелі, що входить до комплекту, під’єднана до крайнього лівого контакту для правильного вирівнювання. |
| Слот для SD-карт | Слот для SD-карт розташований на задній панелі плати Modalix EA PCIe. |
| Порт GMSL2 FAKRA для камери. | Гігабітний мультимедійний послідовний інтерфейс забезпечує стабільну передачу відео з високою пропускною здатністю. |

</TabItem>
<TabItem value="features" label="Основні характеристики">

| Функція | Деталі |
| --- | --- |
| PCIe інтерфейс. | Один інтерфейс PCIe Gen 5.0 x4 з стандартним роз’ємом для підключення до материнської плати. |
| Системна пам’ять | Інтерфейс DRAM LPDDR5 об’ємом 16 ГБ або 32 ГБ для забезпечення високої пропускної здатності та низької затримки. |
| eMMC, флеш-пам’ять | Один інтерфейс флеш-пам’яті eMMC об’ємом 32 ГБ для завантаження та зберігання системних даних. |
| QSPI NOR флеш-пам’ять | Один інтерфейс QSPI NOR flash об’ємом 128 Мбіт для зберігання прошивки та завантажувача. |
| Ethernet | Один інтерфейс Ethernet зі швидкістю 10 Гбіт/с через роз’єм RJ45. |
| Інтерфейс JTAG | Один додатковий інтерфейс JTAG для апаратного налагодження та тестування. |
| Інтерфейс Micro SD | Один інтерфейс для карт Micro SD, що використовується для знімного накопичувача та відновлення системи. |
| Відлагодження UART (Troot). | Один спеціальний інтерфейс UART для діагностики та налагодження Troot. |
| Відлагодження UART (у середовищі Linux). | Один спеціальний інтерфейс UART для налагодження, що забезпечує доступ до консолі Linux та проведення відлагоджувальних процедур. |
| Інтерфейси камери | Два порти GMSL2 FAKRA для підключення віддалених камер через послідовні канали передачі даних. |
| Індикатор стану | Один світлодіод для індикації стану живлення системи. |

</TabItem>
