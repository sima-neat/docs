# Modalix: Ранній доступ до DevKit.

**Modalix Early Access DevKit** — це застарілий комплект розробника для наявних клієнтів програми раннього доступу. Він підтримує оцінювання та створення прототипів на обладнанні Modalix для таких навантажень, як комп’ютерний зір, великі мовні моделі (LLM) й мультимодальна обробка в реальному часі.

<Tabs>
<TabItem value="interfaces" label="Інтерфейси" default>

<img src={useBaseUrl('/img/devkit/modalix-ea-kit-interfaces.png')} alt="SiMa.ai Modalix Інтерфейси набору для раннього доступу." style={{width: '80%', display: 'block', margin: '0 auto'}} />

| Інтерфейс | Опис |
| --- | --- |
| Ethernet-порти (eth0, eth1, eth2, eth3) | RJ45, мережеві інтерфейси 10GigE для віддаленого підключення. |
| Напруга живлення 12 В (роз’єм J8) | Потрібен адаптер живлення на 12 В, використовуйте адаптер живлення, що входить до комплекту, для підключення до цього порту. |
| Перемикач увімкнення/вимкнення живлення | Поруч із роз’ємом живлення, за потреби, використайте ручку, щоб дотягнутися до перемикача та ввімкнути/вимкнути пристрій. |
| COM-порт для хоста. | Спрощує налагодження, забезпечуючи підключення до хост-системи. Переконайтеся, що стрілка на кабелі, що входить до комплекту, під’єднана до крайнього лівого контакту для правильного вирівнювання. |
| Кнопка «Скинути» | Доступний лише в автономному режимі. Дозволяє перезавантажити пристрій для початкового запуску або відновити його роботу після виникнення помилок. |
| MIPI Інтерфейси (X4) | Для підключення камер. |
| Слот для мікро-SD-карт | Для додаткового місця для зберігання. |

Для отримання додаткової інформації про продукт відвідайте офіційний веб-сайт: [SiMa.ai](https://sima.ai/mlsoc/).

| Пам’ять | 64 ГБ оперативної пам’яті LPDDR5, з яких 10 ГБ виділено для ядер ARM, 40 ГБ – для модуля машинного навчання (MLA), решта використовується системою. |
| Зберігання | 10 ГБ вбудованої пам’яті eMMC із роз’ємом для карти microSD для додаткового обсягу пам’яті. |
| Мережа | 4 порти 10GigE. |
