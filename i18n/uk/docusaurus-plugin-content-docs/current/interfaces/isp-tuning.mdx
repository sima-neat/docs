# Налаштування ISP

Процесор обробки зображень (ISP) у MLSoC Modalix перетворює необроблені дані сенсора
камери на зображення, яке отримує застосунок. Отримати кадри з камери та отримати з неї
якісні зображення — це два окремі кроки. На цій сторінці пояснено, що таке налаштування,
які камери вже налаштовано і як отримати посібник із налаштування.

:::caution[Ще не перевірено на обладнанні]
Ця сторінка підсумовує інші сторінки цього сайту про камери та вихідний код ядра
для випуску платформи 2.1.3. Відповідальні за камери та ISP її ще не переглядали.
:::

## Захоплення та налаштування {#capture-and-tuning}

| | Захоплення | Налаштування якості зображення |
| --- | --- | --- |
| Результат | Плата бачить камеру, і камера видає кадри | Кадри мають правильну експозицію, баланс білого та колір |
| Що потрібно | Драйвер сенсора та оверлей дерева пристроїв | Дані налаштування для сенсора та його об’єктива |
| З чого почати | [MIPI Інтерфейси для підключення камер](../getting-started/standalone-mode/mipi-camera-interfaces.mdx) | «Modalix Посібник з налаштування камери та ISP» |

ISP — це Arm Mali-C71.

## Камери, які вже налаштовано {#tuned-cameras}

Випуск платформи налаштовано для камер із розділу
[Підтримувані камери MIPI](./supported-cameras.mdx): Arducam IMX477,
e-con Systems IMX568 та IMX678, а також Leopard Imaging AR0234 та OG05C10.
З однією з цих камер налаштовувати ISP для початку роботи не потрібно.

## Коли потрібне налаштування {#when}

- Ви використовуєте сенсор, якого немає в переліку вище. Див. розділ
  [Інтеграція власної камери](./custom-camera.mdx).
- Ви використовуєте підтримуваний сенсор з іншим об’єктивом або модулем камери.
- Якість зображення підтримуваної камери не відповідає потребам вашого
  застосунку.

## Отримання посібника з налаштування ISP {#tuning-guide}

«Modalix Посібник з налаштування камери та ISP» описує, як налаштувати ISP для камери. Його надають на запит. Див. розділ
[Довідкові документи](../reference/extra-docs.md).

Щоб звернутися до SiMa.ai щодо налаштування камери, зв’яжіться з представником SiMa.ai або
скористайтеся [сторінкою контактів SiMa.ai](https://sima.ai/contact/).

## Наступні кроки

- [Підтримувані камери MIPI](./supported-cameras.mdx): камери, які вже
  налаштовано, та їхні режими сенсорів.
- [Інтеграція власної камери](./custom-camera.mdx): перш ніж налаштовувати нову камеру,
  домогтися від неї захоплення.
- [Довідкові документи](../reference/extra-docs.md): як отримати посібник із
  налаштування.
