# Налаштуйте ваш DevKit.

Щоб швидко налаштувати та почати використовувати ваш Modalix DevKit, почніть із [Короткий посібник зі швидкого старту](pathname:///tools/qsg/index.html).

У цьому розділі наведено покрокові розширені інструкції щодо налаштування DevKit у різних сценаріях розгортання, зокрема в режимі **окремої системи** та в режимі PCIe. Також тут описано, як оновити прошивку DevKit, щоб забезпечити сумісність з останніми версіями програмного забезпечення.

Використовуйте посилання нижче, щоб отримати доступ до детальних інструкцій для кожного варіанта налаштування та процесу оновлення прошивки.

- [Налаштування послідовного з’єднання](./setup-serial)
- [Автономний режим](./standalone-mode/)
- [Режим PCIe](./pcie-mode)
