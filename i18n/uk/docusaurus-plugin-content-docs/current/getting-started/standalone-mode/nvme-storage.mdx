# NVMe Накопичувач

**Modalix DevKit** містить накопичувач NVMe об’ємом 500 ГБ. Якщо вам потрібен більший об’єм, замініть попередньо встановлений накопичувач на сумісний модуль M.2 NVMe, який встановлюється на плату-носій.

:::note
Будь ласка, встановіть або оновіть `sima-cli`, перш ніж продовжувати. Ця інструкція призначена для використання з останньою версією `sima-cli`.
:::

:::note
Цю команду необхідно запускати безпосередньо на Modalix DevKit.
:::

Щоб відформатувати диск NVMe, виконайте команду:

```console
modalix:~$ sima-cli nvme format
```

Після форматування диск NVMe монтується в `/media/nvme`.

Щоб перевірити монтування та переглянути використання дискового простору, виконайте команду:

```console
modalix:~$ df -h
```

Ця команда відображає доступний обсяг дискового простору на всіх змонтованих файлових системах, зокрема на диску NVMe.

Щоб повторно змонтувати диск NVMe, виконайте команду:

```console
modalix:~$ sima-cli nvme remount
```

Команди `format` і `remount` додають запис до файлу `/etc/fstab`, щоб диск NVMe автоматично монтувався під час завантаження системи.
