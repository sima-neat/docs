# Налаштування мережі

У автономному режимі налаштуйте як послідовний доступ, так і мережевий доступ. Послідовний доступ забезпечує можливість зв’язку з DevKit, коли мережеве з’єднання недоступне або налаштоване неправильно.

За замовчуванням мережеві інтерфейси DevKit використовують DHCP.

- Якщо ви хочете під’єднати DevKit безпосередньо до вашого комп’ютера, налаштуйте мережевий інтерфейс вашого комп’ютера зі статичною IP-адресою та під’єднайте його безпосередньо до DevKit.
- Якщо ви хочете, щоб DevKit автоматично отримував свою IP-адресу з мережі, налаштуйте інтерфейс на використання DHCP.

## Перевірте поточну IP-адресу

З послідовної консолі запустіть:

```console
sima@modalix:~$ ip a | grep inet
   inet 127.0.0.1/8 scope host lo
   inet6 ::1/128 scope host noprefixroute
   inet 192.168.91.181/22 brd 192.168.91.255 scope global dynamic noprefixroute end0
   inet6 fe80::ab34:b995:9f6e:160e/64 scope link noprefixroute
```

:::note
Якщо ви хочете перемикатися між статичною та DHCP-конфігурацією без перезавантаження пристрою, дотримуйтесь цих інструкцій.
:::

Якщо на DevKit встановлено `sima-cli`, виконайте цю команду, щоб перемкнутися між конфігураціями DHCP і статичної IP-адреси без перезавантаження:

```console
modalix:~$ sima-cli network
```

Команда відкриває інтерактивне меню для налаштування статичної мережі та мережі з використанням DHCP.

Якщо `sima-cli` недоступний, використовуйте `nmcli` для перемикання між попередньо налаштованими профілями підключення: `end0-static` і `end0-dhcp`.

:::note
Наступні інструкції використовують профілі `NetworkManager` і застосовуються до систем DevKit, на яких працює eLxr 2.1 або новішої версії. Якщо у вашій системі запущено попередню версію, зверніться до документації [v2.0.0](https://docs.sima.ai/v2.0.0/pages/overview/setup_standalone_mode/setup_network.html#network-setup-in-the-linux-shell).
:::

**Перехід на статичну IP-адресу**

Щоб змінити мережевий інтерфейс з DHCP на статичний, виконайте команду:

```console
modalix:~$ sudo nmcli connection up end0-static
modalix:~$ nmcli -f NAME,DEVICE,STATE connection show --active
modalix:~$ networkctl status
```

**Перехід на DHCP**

Щоб змінити мережевий інтерфейс зі статичного на DHCP, виконайте команду:

```console
modalix:~$ sudo nmcli connection up end0-dhcp
modalix:~$ nmcli -f NAME,DEVICE,STATE connection show --active
modalix:~$ networkctl status
```

**Зміна статичної IP-адреси**

Щоб змінити IP-адресу, яка використовується профілем `end0-static`, оновіть профіль і повторно активуйте його:

```console
modalix:~$ sudo nmcli connection modify end0-static ipv4.addresses 192.168.1.20/24
modalix:~$ sudo nmcli connection up end0-static
```

Замініть `192.168.1.20/24` на потрібну адресу та префікс. NetworkManager зберігає профілі в каталозі `/etc/NetworkManager/system-connections/`; застарілий файл `/etc/systemd/network/20-end0-static.network`, який використовувався у версіях 2.0 і раніше, більше не існує.

<TabItem value="auto-config" label="Спільний доступ до мережевого підключення хоста">

:::note
- Використовуйте цей параметр, коли DevKit не може безпосередньо під’єднатися до мережі розробника.
- Під’єднайте DevKit до Ethernet-порту хост-комп’ютера. Використовуйте USB-адаптер Ethernet, якщо на хост-комп’ютері немає Ethernet-порту.
- Хост-комп’ютер може надавати DevKit доступ до Інтернету, зокрема для встановлення пакетів Python за допомогою `pip`.
- Для цього параметра потрібне налаштування спільного доступу до Інтернету на хост-комп’ютері.
:::

1. На хості Ubuntu увімкніть функцію спільного використання інтернет-з’єднання:

   - У верхньому правому куті відкрийте `Settings`, а потім перейдіть до розділу `Network`.
   - Під `Wired` натисніть знак «плюс», щоб створити новий профіль налаштувань, якщо у вас ще немає профілю для цієї плати, або змініть наявний, якщо він є.
   - Якщо ви створюєте новий профіль, назвіть його «Shared» або будь-якою іншою назвою, яка вам подобається.
   - На вкладці `IPv4` виберіть `Shared to other computers`. Натисніть «Застосувати».
   - Якщо у вас вже було встановлено з’єднання, вимкніть його та знову ввімкніть, щоб зміни набули чинності.
   - Тепер хост повинен бути підключений до DevKit. `10.42.0.0/24` — це підмережа за замовчуванням, яка використовується Ubuntu для цієї конфігурації, але ваш хост може використовувати іншу підмережу.
   - Якщо наступний крок не поверне жодних результатів, виконайте команду `ifconfig` і знайдіть IP-адресу вашого Ethernet-інтерфейсу.

2. Відкрийте термінал на хост-машині Ubuntu та виконайте сканування пристроїв у цьому діапазоні IP-адрес:

   ```console
   sima-user@sima-user-machine:~$ nmap -sn 10.42.0.0/24 | grep report
      Nmap scan report for sima-user-machine (10.42.0.1)
      Nmap scan report for 10.42.0.241
   ```

   Результат містить перелік IP-адрес у цій підмережі. Адреса, що закінчується на `.1`, зазвичай належить хосту. Інша адреса належить DevKit. У цьому прикладі DevKit має адресу `10.42.0.241`, а хост – `10.42.0.1`.

3. Перевірте підключення, виконавши команду:

   ```console
   sima-user@sima-user-machine:~$ ssh sima@10.42.0.241
   ...
   Last login: Mon Nov 27 19:58:33 2023
   modalix:~$
   ```

4. З DevKit надішліть ping-запит на хост за адресою `10.42.0.1`. Якщо на хості запущено SSH-сервер, ви також можете підключитися до нього за допомогою SSH.

   ```console
   modalix:~$ ping 10.42.0.1
   ```

5. Якщо ви не можете виконати команду ping або підключитися до DevKit за допомогою SSH, скористайтеся методом налаштування статичної IP-адреси.

<TabItem value="uboot" label="Налаштування мережі в оболонці U-Boot">

:::note
Ця процедура застосовується лише до версії програмного забезпечення DevKit 2.0 або більш ранньої. Для версії 2.1 і новіших використовуйте конфігурацію в середовищі Linux. Налаштування мережі в U-Boot зберігає параметри мережі під час оновлень програмного забезпечення.
:::

1. Підключіться до DevKit через UART і термінал [serial](/hardware/getting-started/setup-serial).
2. Перезавантажте DevKit.
3. Натисніть будь-яку клавішу, щоб перейти до U-Boot, коли з’явиться повідомлення `Hit any key to stop autoboot`.
4. Щоб перемкнутися на статичну IP-адресу, введіть такі команди:

   ```console
   sima:~$ env set forcenetcfg static; saveenv
   sima:~$ boot
   ```

5. Після перезавантаження плата використовує `192.168.1.20` і `192.168.2.20` для першого та другого Ethernet-портів.
6. Щоб змінити статичну IP-адресу плати, відредагуйте мережевий файл за допомогою `vi` після завантаження пристрою.

   ```console
   modalix:~$ sudo vi /etc/systemd/network/20-end0-static.network
   ```

   :::warning
   Цей файл існує лише у версіях прошивки 2.0 і більш ранніх. У версіях 2.1 і новіших його замінено профілями NetworkManager — змініть статичну IP-адресу за допомогою `nmcli`, як описано на вкладці **Налаштування мережі в оболонці Linux**.
   :::

7. У розділі **Мережа** за потреби оновіть IP-адресу.
8. Щоб налаштувати режим DHCP, введіть наведені нижче команди та перезавантажте плату.

   ```console
   sima:~$ env set forcenetcfg dhcp; saveenv
   sima:~$ boot
   ```
