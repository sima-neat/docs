# Налаштування мережі

Підключіть Modalix DevKit до вашої мережі або безпосередньо до вашого хоста. За замовчуванням DevKit використовує DHCP для отримання IP-адреси.

:::tip Забезпечте можливість послідовного доступу.
За допомогою [послідовне з’єднання](/hardware/getting-started/setup-serial) ви можете перевірити IP-адресу та налаштувати мережеві параметри, якщо не вдається підключитися до мережі.
:::

## 1. Під’єднайте DevKit.

Оберіть тип підключення, який найкраще підходить для вашої конфігурації:

- **Підключення до мережі за допомогою DHCP:** Підключіть DevKit до вашого маршрутизатора або мережевого комутатора. Пристрій автоматично отримає IP-адресу.
- **Пряме підключення до хоста:** Підключіть Ethernet-порт DevKit до хоста. За потреби використовуйте адаптер USB до Ethernet. У версії прошивки 3.0 зазвичай можна підключитися без налаштування статичних IP-адрес; див. пораду нижче.
- **Доступ до Інтернету через хост:** Підключіть DevKit до хоста та увімкніть функцію спільного використання інтернет-з’єднання. Див. [Надайте доступ до Інтернету хосту.](#share-the-hosts-internet-connection).

:::tip Пряме підключення у прошивці 3.0.
Якщо під час завантаження немає доступного DHCP-сервера, прошивка 3.0 призначає DevKit локальну адресу в діапазоні `169.254.x.x` (`169.254.0.0/16`).

Безпосередньо підключений хост, який використовує DHCP, зазвичай призначає собі адресу в тому ж діапазоні, якщо ввімкнено резервне IPv4-з’єднання. Тоді хост і DevKit можуть взаємодіяти без статичної IP-конфігурації.

Це з’єднання забезпечує лише локальний доступ. Для доступу до Інтернету використовуйте мережу з доступом до Інтернету або увімкніть спільний доступ до Інтернету на хості.
:::

:::tip Пряме підключення у версії прошивки 2.1.3.
Якщо DHCP недоступний, DevKit за замовчуванням використовує адресу `192.168.1.20`. Налаштуйте підключений Ethernet-інтерфейс хоста на іншу статичну адресу в тій самій підмережі, наприклад `192.168.1.10/24`, щоб підключитися до DevKit через локальну мережу.
:::

## 2. Знайдіть IP-адресу DevKit. {#check-the-current-ip-address}

Якщо ви знаєте, що на вашому DevKit працює прошивка 3.0, виконайте цю команду **на хості** в тій самій локальній мережі:

```console
sima-user@sima-user-machine:~$ sima-cli device discover
```

Ця команда виводить IP-адреси виявлених Modalix DevKit пристроїв.

Для інших версій прошивки або якщо функція автоматичного пошуку не знаходить DevKit, відкрийте послідовний інтерфейс і виконайте цю команду **на DevKit**:

```console
modalix:~$ ip -4 addr
```

Знайдіть адресу після `inet` на підключеному Ethernet-інтерфейсі, наприклад, `end0`. Наприклад, `192.168.91.181/22` означає, що IP-адреса `192.168.91.181`. Не використовуйте адресу зворотного зв’язку `127.0.0.1`.

## 3. Перевірте з’єднання.

Виконайте ці команди **на хості**, замінивши `<devkit-ip>` на знайдену вами адресу:

```console
sima-user@sima-user-machine:~$ ping <devkit-ip>
sima-user@sima-user-machine:~$ ssh sima@<devkit-ip>
```

:::tip Якщо з’єднання не вдасться встановити.
Перевірте Ethernet-кабель та IP-адреси на обох пристроях. Для прямого з’єднання обидві адреси повинні знаходитися в одній підмережі. Якщо хост не підтримує автоматичне перемикання на локальну мережу, увімкніть цю функцію або налаштуйте статичні адреси на обох пристроях.

Використовуйте послідовну консоль, щоб перевірити або змінити мережеві налаштування DevKit.
:::

## Змініть налаштування DHCP або статичної IP-адреси.

Виконайте цю команду **на DevKit**, щоб відкрити меню налаштування мережі:

```console
modalix:~$ sima-cli network
```

Використовуйте меню, щоб перемикатися між DHCP і статичною IP-адресою без перезавантаження.

### Налаштуйте за допомогою NetworkManager.

Якщо `sima-cli` недоступний, використовуйте наведені нижче команди на eLxr версії 2.1 або новішої. Вони використовують попередньо налаштовані профілі `end0-dhcp` та `end0-static`.

Щоб увімкнути DHCP:

```console
modalix:~$ sudo nmcli connection up end0-dhcp
```

Щоб встановити статичну адресу та активувати її:

```console
modalix:~$ sudo nmcli connection modify end0-static ipv4.addresses 192.168.1.20/24
modalix:~$ sudo nmcli connection up end0-static
```

Замініть `192.168.1.20/24` на адресу та мережеву маску, які відповідають вашій конфігурації. Налаштуйте хост, використовуючи іншу адресу в тій самій підмережі.

Щоб перевірити активне з’єднання та IP-адресу:

```console
modalix:~$ nmcli -f NAME,DEVICE,STATE connection show --active
modalix:~$ ip -4 addr
```

:::caution Зміна параметрів мережі.
Зміна IP-адреси може призвести до розриву вашого SSH-з’єднання. Використовуйте послідовну консоль або підключіться знову, використовуючи нову адресу.
:::

## Надайте доступ до Інтернету хосту. {#share-the-hosts-internet-connection}

Використовуйте цей параметр, коли DevKit потребує доступу до Інтернету через хост Ubuntu.

1. Під’єднайте Ethernet-порт DevKit до хоста. Переконайтеся, що хост має доступ до Інтернету.
2. На хості відкрийте **Налаштування → Мережа → Дротове з’єднання** та створіть або відредагуйте підключення для цього Ethernet-порту.
3. На вкладці **IPv4** виберіть параметр **Надати доступ іншим комп’ютерам** і застосуйте зміни.
4. Вимкніть і знову ввімкніть з’єднання, щоб застосувати налаштування.
5. Переконайтеся, що DevKit використовує DHCP, потім [знайти його IP-адресу.](#check-the-current-ip-address) і перевірте з’єднання.

Ubuntu зазвичай використовує `10.42.0.0/24` для спільної мережі. Ваш хост може використовувати іншу підмережу. За потреби перевірте Ethernet-адресу хоста за допомогою `ip -4 addr`, а потім проскануйте цю підмережу:

```console
sima-user@sima-user-machine:~$ nmap -sn 10.42.0.0/24
```

Використовуйте функцію виявлення або послідовний консольний інтерфейс, щоб підтвердити, яка адреса належить DevKit.

## Старіша версія прошивки: U-Boot Налаштування мережі.

<details>
<summary>Версія прошивки 2.0 або раніша</summary>

Ці інструкції стосуються лише версій прошивки 2.0 або більш ранніх. Для версій прошивки 2.1 або новіших використовуйте наведені вище команди Linux. Додаткову інформацію про попередні версії можна знайти в [Документація до версії 2.0.0.](https://docs.sima.ai/v2.0.0/pages/overview/setup_standalone_mode/setup_network.html#network-setup-in-the-linux-shell).

1. Підключіться до DevKit через [послідовний термінал](/hardware/getting-started/setup-serial).
2. Перезавантажте DevKit. Коли з’явиться повідомлення `Hit any key to stop autoboot`, натисніть будь-яку клавішу, щоб перейти до U-Boot.
3. Щоб увімкнути налаштування статичної IP-адреси, виконайте команду:

   ```console
   sima:~$ env set forcenetcfg static; saveenv
   sima:~$ boot
   ```

   Перший і другий Ethernet-порти використовують `192.168.1.20` та `192.168.2.20`.

4. Щоб змінити статичну адресу після запуску Linux, відредагуйте розділ **Мережа** у цьому файлі:

   ```console
   modalix:~$ sudo vi /etc/systemd/network/20-end0-static.network
   ```

   Цей файл використовується лише у версіях прошивки 2.0 або більш ранніх. У версіях прошивки 2.1 і новіших використовуються профілі NetworkManager.

5. Щоб натомість увімкнути DHCP, виконайте ці команди в U-Boot:

   ```console
   sima:~$ env set forcenetcfg dhcp; saveenv
   sima:~$ boot
   ```

</details>
