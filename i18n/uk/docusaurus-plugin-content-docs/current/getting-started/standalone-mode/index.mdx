# Автономний режим

Для налаштування DevKit у автономному режимі необхідно налаштувати як його послідовне з’єднання, так і мережеві параметри, щоб забезпечити стабільний і надійний доступ. Послідовний інтерфейс слугує важливим каналом зв’язку, забезпечуючи безперервну взаємодію з DevKit незалежно від наявності мережевого з’єднання.

IP-адресу DevKit можна призначити одним із наведених нижче способів:

- Автоматичне налаштування через мережу.
- Автоматичне налаштування за допомогою комп’ютера розробника.
- Налаштування статичної IP-адреси вручну.

Вибір відповідного методу залежить від конкретного середовища мережі та вимог до підключення.

## Налаштування мережі DevKit {#network}

За замовчуванням мережеві інтерфейси DevKit використовують протокол DHCP.

- Якщо ви хочете під’єднати DevKit безпосередньо до вашого комп’ютера, налаштуйте мережевий інтерфейс вашого комп’ютера, призначивши йому статичну IP-адресу, і під’єднайте його безпосередньо до DevKit.
- Якщо ви хочете, щоб DevKit автоматично отримував свою IP-адресу з мережі, вам потрібно буде налаштувати інтерфейс для використання DHCP.

**Перевірка поточної IP-адреси**

У консолі послідовного порту виконайте команду:

```console
sima@modalix:~$ ip a | grep inet
   inet 127.0.0.1/8 scope host lo
   inet6 ::1/128 scope host noprefixroute
   inet 192.168.91.181/22 brd 192.168.91.255 scope global dynamic noprefixroute end0
   inet6 fe80::ab34:b995:9f6e:160e/64 scope link noprefixroute
```

:::note
Якщо ви хочете перемикатися між статичною та DHCP-конфігурацією без перезавантаження пристрою, дотримуйтесь цих інструкцій.
:::

Якщо у вас встановлено `sima-cli` на DevKit і ви хочете динамічно перемикатися між конфігураціями DHCP і статичної IP-адреси без перезавантаження, виконайте команду:

```console
davinci:~$ sima-cli network
```

Вам буде запропоновано інтерактивне меню для перемикання між статичною та DHCP-конфігураціями мережі.

Якщо `sima-cli` недоступний, використовуйте `nmcli` для перемикання між попередньо налаштованими профілями підключення: `end0-static` та `end0-dhcp`.

:::note
Наступні інструкції використовують профілі `NetworkManager` для налаштування мережевого інтерфейсу та застосовуються до систем DevKit, на яких працює eLxr версії 2.1 або новішої. Якщо на вашій системі встановлено попередню версію, зверніться до документації [Документація до версії 2.0.0](https://docs.sima.ai/v2.0.0/pages/overview/setup_standalone_mode/setup_network.html#network-setup-in-the-linux-shell).
:::

**Перехід на статичну IP-адресу**

Щоб змінити мережевий інтерфейс з DHCP на статичний, виконайте команду:

```console
davinci:~$ sudo nmcli connection up end0-static
davinci:~$ nmcli -f NAME,DEVICE,STATE connection show --active
davinci:~$ networkctl status
```

**Перехід на DHCP**

Щоб змінити налаштування мережевого інтерфейсу зі статичних на DHCP, виконайте команду:

```console
davinci:~$ sudo nmcli connection up end0-dhcp
davinci:~$ nmcli -f NAME,DEVICE,STATE connection show --active
davinci:~$ networkctl status
```

<TabItem value="auto-config" label="Auto Config Through Dev Computer">

:::note
- Підходить для випадків, коли мережа розробників недоступна для підключення до Ethernet від пристрою DevKit.
- Під’єднайте DevKit до Ethernet-порту комп’ютера розробника. Якщо на комп’ютері розробника немає доступного Ethernet-порту, використовуйте USB-адаптер для підключення до Ethernet.
- Комп’ютер може надавати доступ до Інтернету пристрою DevKit, що дозволяє встановлювати пакети Python за допомогою `pip`.
- Необхідно ввімкнути функцію спільного доступу до Інтернету на комп’ютері-хості.
:::

1. Дотримуйтесь наведених нижче інструкцій для комп’ютера з операційною системою Ubuntu. На інших платформах інструкції можуть відрізнятися; будь ласка, знайдіть відповідні інструкції в Інтернеті щодо способу спільного використання мережевих підключень.

   - У верхньому правому куті відкрийте `Settings`, а потім перейдіть до розділу `Network`.
   - У розділі `Wired` натисніть знак «плюс», щоб створити новий профіль налаштувань, якщо у вас ще немає профілю для цієї плати, або змініть наявний профіль, якщо він у вас є.
   - Якщо ви створюєте новий профіль, назвіть його «Загальний» або будь-яким іншим іменем, яке вам подобається.
   - На вкладці `IPv4` виберіть `Shared to other computers`. Натисніть «Застосувати».
   - Якщо у вас уже було встановлено з’єднання, вимкніть його та знову ввімкніть, щоб зміни набули чинності.
   - Тепер ваш комп’ютер має бути під’єднано до точки доступу. `10.42.0.0/24` — це стандартна підмережа, яка використовується Ubuntu для цієї конфігурації, але ваш комп’ютер може використовувати іншу підмережу.
   - Якщо наступний крок не дасть жодних результатів, виконайте команду `ifconfig` і знайдіть IP-адресу вашого Ethernet-інтерфейсу (зазвичай `eth0`) там.

2. Відкрийте термінал на комп’ютері з операційною системою Ubuntu. Введіть наступну команду, щоб просканувати пристрої в заданому діапазоні IP-адрес:

   ```console
   sima-user@sima-user-machine:~$ nmap -sn 10.42.0.0/24 | grep report
      Nmap scan report for sima-user-machine (10.42.0.1)
      Nmap scan report for 10.42.0.241
   ```

   У цьому списку наведено IP-адреси, які використовуються в цій підмережі. Адреса, що закінчується на `.1`, є адресою вашого хоста. Адреса, яка не закінчується на `.1`, є IP-адресою SiMa DevKit. У наведеному вище прикладі плата має адресу `10.42.0.241`, а хост – `10.42.0.1`.

3. Перевірте з’єднання, виконавши команду:

   ```console
   sima-user@sima-user-machine:~$ ssh sima@10.42.0.241
   ...
   Last login: Mon Nov 27 19:58:33 2023
   davinci:~$
   ```

4. Щоб перевірити, чи можна встановити з’єднання з вашим хостом з плати, надішліть ping-запит з плати: `10.42.0.1`. Якщо на вашому хості працює SSH-сервер, ви також можете використовувати SSH:

   ```console
   davinci:~$ ping 10.42.0.1
      PING 10.42.0.1 (10.42.0.1): 56 data bytes
      64 bytes from 10.42.0.1: seq=0 ttl=64 time=0.598 ms
      64 bytes from 10.42.0.1: seq=1 ttl=64 time=0.703 ms
      64 bytes from 10.42.0.1: seq=2 ttl=64 time=0.639 ms
      ^C
      --- 10.42.0.1 ping statistics ---
      3 packets transmitted, 3 packets received, 0% packet loss
      round-trip min/avg/max = 0.598/0.646/0.703 ms
   ```

5. Якщо ви не можете надіслати ping-запит або підключитися до плати за допомогою SSH, скористайтеся методом налаштування статичної IP-адреси.

</TabItem>
<TabItem value="uboot" label="Network Setup In The U-Boot Shell">

:::note
Ця процедура застосовується лише до версії програмного забезпечення DevKit 2.0 або більш ранньої. У версіях 2.1 і новіших користувачі можуть використовувати налаштування, що здійснюються в середовищі Linux. Налаштування мережі в U-Boot забезпечує збереження параметрів мережі під час оновлень програмного забезпечення.
:::

1. Підключіться до DevKit через UART і [послідовний термінал](/hardware/getting-started/setup-serial).
2. Перезавантажте DevKit.
3. Натисніть будь-яку клавішу, щоб перейти до U-Boot, коли з’явиться відповідне повідомлення: `Hit any key to stop autoboot`.

4. Щоб перемкнутися на статичну IP-адресу, введіть такі команди:

   ```console
   sima:~$ env set forcenetcfg static; saveenv
   sima:~$ boot
   ```

5. Плата перезавантажиться і використовуватиме `192.168.1.20` та `192.168.2.20` для першого та другого портів Ethernet.
6. Щоб змінити статичну IP-адресу пристрою, відредагуйте мережевий файл після завантаження пристрою, використовуючи `vi`.

   ```console
   davinci:~$ sudo vi /etc/systemd/network/20-end0-static.network
   ```

7. У розділі «**Мережа**» за потреби оновіть IP-адресу.
8. Щоб налаштувати режим DHCP, введіть наведені нижче команди та перезавантажте плату.

   ```console
   sima:~$ env set forcenetcfg dhcp; saveenv
   sima:~$ boot
   ```

## Налаштуйте сховище NVMe {#nvme}

**Modalix DevKit** містить 500 ГБ NVMe (Non-Volatile Memory Express) накопичувач.
Розробники, яким потрібна додаткова ємність, можуть замінити попередньо встановлений накопичувач на сумісний модуль M.2 NVMe, встановлений безпосередньо на материнську плату.

:::note
Будь ласка, встановіть або оновіть `sima-cli`, перш ніж продовжувати. Ця інструкція призначена для використання з останньою версією `sima-cli`.
:::

:::note
Цю команду необхідно запускати безпосередньо на Modalix DevKit.
:::

Після встановлення `sima-cli`, ви можете відформатувати диск NVMe, використовуючи таку команду:

```console
modalix:~$ sima-cli nvme format
```

Після форматування диск NVMe буде автоматично змонтовано в `/media/nvme`.

Щоб перевірити монтування та переглянути використання дискового простору, виконайте команду:

```console
modalix:~$ df -h
```

Ця команда відображає доступний обсяг дискового простору на всіх змонтованих файлових системах, включно з диском NVMe.

Якщо диск NVMe потрібно повторно змонтувати, виконайте команду:

```console
modalix:~$ sima-cli nvme remount
```

Обидві команди, `format` і `remount`, автоматично додають запис до файлу `/etc/fstab`, тому диск NVMe завжди автоматично монтується.

## Налаштування інтерфейсів MIPI {#mipi}

:::note
Будь ласка, встановіть або оновіть `sima-cli`, перш ніж продовжувати. Ця інструкція призначена для використання з останньою версією `sima-cli`.
:::

:::note
Для виконання цієї процедури потрібна хост-машина з встановленою останньою версією sima-cli. Також необхідна версія прошивки **Modalix Devkit__, яка має бути `1.7.0_master_B1965` або новішою. Це пов’язано з тим, що ця збірка містить необхідні файли `.dtbo` для підтримки MIPI.
:::

**Modalix DevKit** містить два MIPI інтерфейси для підключення MIPI камер як джерела вхідного сигналу для пристрою. MIPI порти розташовані безпосередньо на материнській платі, і розробникам потрібно буде дотримуватися наведеної нижче процедури, щоб їх активувати.

Перш ніж почати, переконайтеся, що MIPI камера підключена до одного з MIPI портів, коли **Modalix Devkit** вимкнено.

Після підключення під’єднайте послідовний кабель від хост-машини до **Modalix Devkit**. Потім увімкніть **Modalix Devkit**.

Далі встановіть послідовний термінал за допомогою `sima-cli` і негайно перейдіть до `uboot`, натиснувши будь-яку клавішу під час 3-секундного зворотного відліку.

```console
sima-cli serial -b 115200
...
Hit any key to stop autoboot:  0
sima$
```

Після завантаження в uboot встановіть змінну `dtbos` на відповідний файл **Device Tree Blob Overlay** (`.dtbo`). Правильний файл залежить від **материнської плати**, **виробника камери**, **типу сенсора** та **порту камери**. Після цього збережіть налаштування та завантажте операційну систему.

Ім’я файлу має таку структуру:

```text
modalix-som-<carrier_board>-<camera_manufacturer>-<sensor_type>-<port>CAM.dtbo
```

Обирайте кожен компонент відповідно до вашого апаратного забезпечення:

| Компонент | Цінності | Опис |
| --- | --- | --- |
| Основна плата | `connectech`, `seeedstudio`, `waveshare` | Модель материнської плати. |
| Виробник камери | `ARDU`, `ECON`, `LI` | Arducam, e-con Systems або Leopard Imaging. |
| Тип датчика | `IMX477`, `IMX568`, `IMX678`, `AR0234`, `OG05C10` | Модель сенсора камери. |
| Порт | `0CAM`, `1CAM`, `2CAM`, `3CAM`, `DUAL` | Номер порту MIPI, до якого підключена камера. |

Наприклад, плата розширення Connectech з сенсором Leopard Imaging IMX477, підключеним до порту 0:

```console
sima$ setenv dtbos modalix-som-connectech-LI-IMX477-0CAM.dtbo ; saveenv ; boot
```

Щоб перевірити роботу інтерфейсів, під’єднайте модуль SOM Modalix до дисплея та виконайте вхід до системи. Потім за допомогою libcamera перевірте з’єднання з камерою Modalix.

1. Список доступних камер:

   ```console
   sima@modalix:~$ cam -l
   ```

2. Відобразіть різні формати зображень для камери 1:

   ```console
   sima@modalix:~$ cam -c 1 -I
   ```

3. Зробіть знімок за допомогою камери 1:

   ```console
   sima@modalix:~$ rm -rf frame* && cam -c 1 --capture=1 -F -s pixelformat=NV12
   ```
