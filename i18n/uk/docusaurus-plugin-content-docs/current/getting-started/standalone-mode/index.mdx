# Автономний режим

В автономному режимі Modalix DevKit працює як самостійний периферійний пристрій. Він отримує дані з датчиків, камер, накопичувачів або мережевих інтерфейсів, обробляє їх локально та надсилає результати через мережу.

Використовуйте цей розділ, коли DevKit не встановлено в хост-машині як PCIe карту.
