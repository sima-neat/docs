# Налаштуйте послідовне з’єднання.

Під час початкового налаштування під’єднайтеся до послідовного інтерфейсу DevKit, незалежно від того, чи використовуєте ви автономний режим, чи режим PCIe.

В автономному режимі послідовний доступ дозволяє налаштовувати, контролювати та відновлювати роботу DevKit, навіть якщо мережеве підключення недоступне або налаштоване неправильно.

У режимі PCIe послідовний інтерфейс надає прямий доступ до оболонки PCIe-карти та консолей налагодження під час початкового налаштування. Використовуйте його для низькорівневого керування та усунення несправностей до того, як драйвер хост-системи або з’єднання PCIe повністю запрацюють.

Послідовний доступ в основному призначений для розробки та налагодження. Після розгортання звичайний режим роботи зазвичай не потребує послідовного з’єднання.

Оберіть конфігурацію підключення кабелів для вашого обладнання, а потім оберіть метод підключення послідовного терміналу для вашого комп’ютера.

## Відкрийте послідовний термінал.

<Tabs>
<TabItem value="mac-linux" label="macOS & Linux" default>

:::note
Будь ласка, встановіть або оновіть `sima-cli`, перш ніж продовжувати. Ця інструкція призначена для використання з останньою версією `sima-cli`.
:::

Використовуйте `sima-cli serial` на macOS або Linux для підключення до послідовного порту.

```console
sima-cli serial
```

Ця команда встановлює необхідні залежності для доступу до послідовного порту. Щоб вийти з терміналу послідовного порту, натисніть Ctrl + A, а потім Ctrl + X.

У деяких попередніх версіях прошивки система може використовувати іншу швидкість передачі даних для послідовної консолі. Якщо ви бачите нерозбірливий вивід у терміналі, ймовірно, це пов’язано з невідповідністю швидкості передачі даних. Спробуйте вказати вищу швидкість:

```console
sima-cli serial -b 921600
```

</TabItem>
<TabItem value="windows" label="Windows">

Щоб підключитися до DevKit з **Windows**, виконайте такі дії:

1. Визначте COM-порт:
   - Відкрийте **Диспетчер пристроїв** → Розгорніть **Порти (COM і LPT)**.
   - Знайдіть запис, схожий на **USB-послідовний порт (COMx)**.

2. Встановіть і відкрийте послідовний термінал:
   - Використовуйте [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html) або **Tera Term**.
   - Встановіть тип з’єднання на **Serial**.
   - Введіть правильний **номер COM-порту** (наприклад, `COM3`).
   - Встановіть значення **швидкості передачі даних** на `115200`.

3. Натисніть **Відкрити**, щоб розпочати з’єднання.

</TabItem>
