# Налаштуйте послідовне з’єднання.

Під час початкової розробки настійно рекомендується встановити з’єднання з DevKit через послідовний інтерфейс, незалежно від того, чи використовується система в автономній конфігурації, чи як PCIe пристрій у хост-системі.

В автономній конфігурації послідовне з’єднання забезпечує надійний доступ до DevKit, незалежно від того, як він отримує IP-адресу. Це гарантує, що розробники зберігають контроль над системою для виконання завдань конфігурації, моніторингу та відновлення, навіть якщо мережеве з’єднання недоступне або налаштоване неправильно.

У конфігурації PCIe, послідовний інтерфейс забезпечує прямий доступ до оболонки та консолей налагодження PCIe карти під час запуску. Це особливо корисно для низькорівневого керування та усунення несправностей, коли хост-система або PCIe з’єднання ще не повністю функціонують.

Послідовний інтерфейс призначений насамперед для розробки та запуску. Після повної конфігурації та розгортання системи, її подальша робота, як правило, не потребує послідовного з’єднання.

Залежно від операційної системи комп’ютера розробника, існують різні методи підключення до DevKit через послідовний інтерфейс.

<TabItem value="windows" label="Windows">

Щоб підключитися до DevKit через послідовний термінал у системі **Windows**, виконайте такі дії:

1. Визначте COM-порт:
   - Відкрийте **Диспетчер пристроїв** → Розгорніть розділ **Порти (COM і LPT)**.
   - Знайдіть запис, схожий на **USB Serial Port (COMx)**.

2. **Встановіть і відкрийте послідовний термінал**:
   - Використовуйте [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html) або Tera Term.
   - Встановіть тип з’єднання на **Послідовний**.
   - Введіть правильний **номер COM-порту** (наприклад, `COM3`).
   - Встановіть значення **швидкості передачі даних** на `115200`.

3. Натисніть кнопку **Відкрити**, щоб розпочати з’єднання.

</TabItem>
<TabItem value="mac-linux" label="MacOS та Linux. Настільні версії.">

:::note
Будь ласка, встановіть або оновіть `sima-cli`, перш ніж продовжувати. Ця інструкція призначена для використання з останньою версією `sima-cli`.
:::

Використовуйте команду `sima-cli serial` на Mac та Linux, щоб підключитися до послідовного порту апаратного забезпечення SiMa.

```console
sima-cli serial
```

Ця команда встановить необхідні компоненти на вашому комп’ютері для доступу до послідовного порту. Щоб вийти з послідовного терміналу, натисніть Ctrl + A, а потім Ctrl + X.

У деяких попередніх версіях прошивки система може використовувати іншу швидкість передачі даних для послідовної консолі. Якщо ви бачите спотворений вивід у терміналі, ймовірно, це пов’язано з невідповідністю швидкості передачі даних. Спробуйте вказати вищу швидкість:

```console
sima-cli serial -b 921600
```
