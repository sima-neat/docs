# Оновлення програмного забезпечення

Підтримуйте актуальність прошивки DevKit, відновлюйте роботу пристрою, який не завантажується, або встановлюйте певну версію прошивки.

:::note
Будь ласка, встановіть або оновіть `sima-cli`, перш ніж продовжувати. Ці інструкції призначені для використання з останньою версією `sima-cli`.
:::

:::warning
Для оновлення Modalix DevKit з версії SDK 1.7 до 2.0 потрібні додаткові кроки. Зверніться до посібника [Перехід на eLxr](/hardware/reference/tech-notes/elxr-conversion), щоб ознайомитися з процедурою перетворення.
:::

## Операційні системи {#os}

Комплекти розробника SiMa.ai Modalix DevKit працюють під керуванням **eLxr Linux** — дистрибутива на базі Debian. Пристрої, що надходять у продаж **після середини грудня 2025 року**, постачаються з попередньо встановленою eLxr. Раніші версії Modalix (поставлені до середини грудня 2025 року) мають попередньо встановлену Yocto і їх можна перетворити на eLxr, дотримуючись інструкцій у статті [«Перехід на eLxr»](/hardware/reference/tech-notes/elxr-conversion).

eLxr — це операційна система на базі Debian, призначена для розробки на платформі Modalix. Вона пропонує:

- Повноцінне керування пакетами Debian за допомогою `apt`.
- Розширена сфера застосування для розробки та налагодження.
- Можливість створювати та встановлювати інструменти безпосередньо на пристрої.
- Прискорення процесу розробки без використання перехресної компіляції.
- Більш розгалужена екосистема бібліотек і фреймворків.

Використовуйте наведені нижче інструкції з оновлення прошивки, щоб оновити DevKit, створити завантажувальний носій для відновлення або повторно встановити прошивку через мережу.

:::tip
Якщо ваш DevKit не має доступу до Інтернету, використовуйте робочий процес, що базується на хості. Використовуйте **Net Boot Recovery**, щоб завантажитися з хоста та встановити прошивку eMMC, або **Create Boot Image**, щоб підготувати знімний носій для завантаження. Хост-машині потрібен доступ до Інтернету для завантаження образу прошивки, якщо у вас немає цього образу локально.
:::
