# Створення образу завантаження

Використовуйте образ завантаження, коли стандартний шлях оновлення недоступний або коли вам потрібен змінний завантажувальний носій. Типові випадки включають:

- Внутрішнє сховище DevKit пошкоджено або не завантажується.
- Вам потрібно підготувати кілька завантажувальних SD-карт або знімних дисків для розгортання.

Використовуйте `sima-cli bootimg`, щоб завантажити та записати повний образ завантаження на знімний пристрій, такий як SD-карта або NVMe-накопичувач. Ви також можете використовувати сторонній інструмент, такий як [BalenaEtcher](https://etcher.balena.io/).

<Tabs groupId="bootimage-method">
<TabItem value="sima-cli" label="Використання sima-cli" default>

```console
sima-cli bootimg -v %platform_version% --boardtype [modalix|mlsoc]
```

Ця команда виконує наступні дії:

1. Завантажує образ завантаження для вказаного типу плати (`modalix` або `mlsoc`) і версії SDK.
2. Сканує вашу хост-машину на наявність знімних пристроїв зберігання.
3. Пропонує підтвердити, на який пристрій потрібно записати.
4. Записує образ завантаження безпосередньо на вибраний пристрій.

Після завершення процесу витягніть SD-карту та вставте її в DevKit. Під час наступного завантаження DevKit запускатиметься з нового образу.

**Важливі примітки:**

- Цю команду потрібно запускати на хост-машині Linux або macOS.
- Для завантаження образу потрібне підключення до Інтернету.

</TabItem>
<TabItem value="third-party" label="Використання сторонніх інструментів">

Ви також можете записати образ за допомогою стороннього інструменту для запису образів, такого як BalenaEtcher.

1. Спочатку завантажте образ за допомогою `sima-cli`.

   Щоб завантажити лише файл прошивки для ручних кроків оновлення, запустіть `sima-cli download` з URL-адресою відповідного архіву прошивки Modalix.

2. Розпакуйте вміст завантаженого архіву:

   ```console
   tar -xvf simaai-devkit-fw-modalix-yocto-1.7.0.tar.gz
   ```

3. Використовуйте BalenaEtcher, щоб вибрати отриманий файл `.wic.gz` і записати його на вашу SD-карту або USB-накопичувач.

Після запису вставте пристрій у DevKit і увімкніть його, щоб запустити завантаження з образу.

</TabItem>
