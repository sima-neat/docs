# Оновлення за допомогою sima-cli

Використовуйте `sima-cli update`, коли комплект розробки працює та доступний у мережі. Цей метод завантажує образ прошивки та ініціює оновлення на комплекті розробки.

Перш ніж продовжити, переконайтеся, що хост-машина може отримати доступ до комплекту розробки через мережу. Див.:

- [Налаштування мережі в автономному режимі](/uk/hardware/getting-started/standalone-mode/network)
- [Налаштування віртуальної мережі в режимі PCIe](/uk/hardware/getting-started/pcie-mode/virtual-network)

<Tabs groupId="sima-cli-source">
<TabItem value="from-devkit" label="З комплекту розробки" default>

Запустіть `sima-cli` безпосередньо на автономному комплекті розробки. Переконайтеся, що комплект розробки має активне підключення до Інтернету, а потім запустіть:

```console
modalix:~$ sima-cli update
```

На MLSoC, що працює під управлінням Yocto Linux, ви також можете вказати повну URL-адресу замість рядка версії, якщо ви раніше завантажили та розмістили образ самостійно.

```console
modalix:~$ sima-cli update http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="from-host" label="З хост-машини">

:::note
Цей метод підтримується лише на платформі MLSoC, що працює під управлінням Yocto. Для пристроїв Modalix, що працюють під управлінням eLxr Linux, виконуйте оновлення безпосередньо на комплекті розробки.
:::

Використовуйте цю команду з хост-машини:

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit}
```

Ця команда також встановлює відповідну версію драйвера Linux на хост-машині, якщо це необхідно.

Якщо ви завантажили прошивку та розмістили її у вашій мережі, надайте URL-адресу, щоб уникнути повторних завантажень з Інтернету.

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit} http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="download" label="Завантажити лише">

Щоб завантажити лише образ прошивки для ручних кроків оновлення, запустіть `sima-cli download` з URL-адресою відповідного архіву прошивки Modalix.

</TabItem>
</Tabs>

:::note
Щоб **знизити версію** комплекту розробки або встановити збірку, яка **не є останньою версією** (наприклад, попередню версію `develop` або внутрішній інженерний образ), використовуйте [відновлення через Net Boot](/uk/hardware/getting-started/firmware-update/net-boot) замість цього. Він завантажує комплект розробки з TFTP-сервера на хост-машині та безпосередньо записує цільовий образ в eMMC.
:::
