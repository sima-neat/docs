# Оновлення за допомогою sima-cli

Використовуйте `sima-cli update`, коли комплект розробки працює та доступний у мережі. Цей метод завантажує образ прошивки та ініціює оновлення на комплекті розробки.

:::note
`sima-cli update` встановлює лише офіційні збірки SiMa.ai. Якщо ви зібрали власний образ, натомість див. [Прошивання образу на eMMC](/hardware/deployment/flash-image).
:::

:::note
DevKit з прошивкою версії 2.x не може використовувати цей механізм оновлення для безпосереднього переходу на версію 3.0. Спочатку виконайте [Оновіть з версії 2.1.3 до 3.0.0.](/hardware/reference/tech-notes/convert-2-1-3-to-3-0-0). Після конвертації використовуйте `sima-cli update` для оновлення з eLxr 3.0 до новішої версії.
:::

Перш ніж продовжити, переконайтеся, що хост-машина може отримати доступ до комплекту розробки через мережу. Див.:

- [Налаштування мережі в автономному режимі](/hardware/getting-started/standalone-mode/network)
- [Налаштування віртуальної мережі в режимі PCIe](/hardware/getting-started/pcie-mode/virtual-network)

<Tabs groupId="sima-cli-source">
<TabItem value="from-devkit" label="З комплекту розробки" default>

Запустіть `sima-cli` безпосередньо на автономному комплекті розробки. Переконайтеся, що комплект розробки має активне підключення до Інтернету, а потім запустіть:

```console
modalix:~$ sima-cli update
```

На MLSoC, де працює Yocto Linux, і на Modalix, де працює eLxr версії 3.0 або новішої, ви також можете вказати повну URL-адресу замість рядка версії, якщо ви самі завантажили та розмістили образ. Це стосується також оновлення з eLxr 3.0 до новішої версії.

```console
modalix:~$ sima-cli update http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="from-host" label="З хост-машини">

:::note
Оновлення, ініційовані з хоста, підтримуються на MLSoC з операційною системою Yocto Linux, а також на Modalix з eLxr версії 3.0 або новішої, включно з оновленнями з версії 3.0 до новішої. Для Modalix з eLxr версії 2.x, виконайте оновлення безпосередньо на DevKit; перехід на версію 3.0 вимагає використання посібника з переходу, на який є посилання вище.
:::

Використовуйте цю команду з хост-машини:

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit}
```

Ця команда також встановлює відповідну версію драйвера Linux на хост-машині, якщо це необхідно.

Якщо ви завантажили прошивку та розмістили її у вашій мережі, надайте URL-адресу, щоб уникнути повторних завантажень з Інтернету.

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit} http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="download" label="Завантажити лише">

Щоб завантажити лише образ прошивки для ручних кроків оновлення, запустіть `sima-cli download` з URL-адресою відповідного архіву прошивки Modalix.

</TabItem>
</Tabs>

:::note
Щоб **знизити версію** комплекту розробки або встановити збірку, яка **не є останньою версією** (наприклад, попередню версію `develop` або внутрішній інженерний образ), використовуйте [відновлення через Net Boot](/hardware/getting-started/firmware-update/net-boot) замість цього. Він завантажує комплект розробки з TFTP-сервера на хост-машині та безпосередньо записує цільовий образ в eMMC.
:::
