# Режим PCIe

У режимі PCIe, карта Modalix PCIe встановлюється в хост-машину та забезпечує прискорення обчислень Modalix через PCIe. Хост-машина відповідає за оркестрування, зберігання даних і ввід/вивід, тоді як карта обробляє обчислювальні навантаження.

Використовуйте цей розділ, коли апаратне забезпечення Modalix встановлено як карта PCIe, а не працює як автономний DevKit.
