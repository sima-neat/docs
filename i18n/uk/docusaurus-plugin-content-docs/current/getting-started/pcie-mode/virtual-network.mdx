# Віртуальна мережа

:::note
Переконайтеся, що ваш DevKit [оновлено](/uk/hardware/getting-started/firmware-update) до останньої версії прошивки, перш ніж використовувати функцію віртуальної мережі.

Ця функція доступна лише на хостах Linux.
:::

Коли плата Modalix PCIe під’єднана через PCIe, вона створює віртуальний Ethernet-інтерфейс між хостом і платою.

Використовуйте віртуальну мережу для:

- **Secure Shell (SSH)**: Отримайте доступ до командного рядка DevKit для усунення несправностей і керування системою.
- **Протокол захищеного копіювання (SCP)**: передавайте файли журналів, файли конфігурації та інші файли між хостом і DevKit.

## Ручне призначення IP-адреси.

Під час ручного завантаження модуля за допомогою `insmod`, використовуйте наведену нижче команду. Це дозволить призначити статичну IP-адресу інтерфейсу хоста, а потім – карті Modalix PCIe.

```console
sudo insmod sima_mla_drv.ko default_ip=false
```

Для цього також потрібна утиліта `ifconfig` на хості.

```console
ifconfig <eth interface> 20.1.2.1
```

Після того, як ви призначите IP-адресу інтерфейсу хоста, до інтерфейсу SoC автоматично призначається IP + 1. Наприклад, якщо хост використовує `20.1.2.1`, то IP для MLSoC буде `20.1.2.2`.

Під час створення інтерфейсів, інтерфейс хоста використовує MAC-адресу у форматі `cardnum:S:I:m:A:0`, а інтерфейс SoC використовує `cardnum:S:I:m:A:1`. IP-адреси призначаються під час створення як `host:10.0.cardnum.1` і `soc:10.0.cardnum.2`.

   ```console

       inet6 fe80::253:49ff:fe4d:4130  prefixlen 64  scopeid 0x20<link>
       ether 00:53:49:4d:41:30  txqueuelen 1000  (Ethernet)
       RX packets 14107  bytes 4460994 (4.4 MB)
       RX errors 0  dropped 0  overruns 0  frame 0
       TX packets 818  bytes 74840 (74.8 KB)
       TX errors 0  dropped 0 overruns 0  carrier 0  collisions 0
   ```
