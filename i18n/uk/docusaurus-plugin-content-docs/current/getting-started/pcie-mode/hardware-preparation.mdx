# Підготовка апаратного забезпечення.

:::note
Будь ласка, встановіть або оновіть `sima-cli`, перш ніж продовжувати. Ця інструкція призначена для використання з останньою версією `sima-cli`.
:::

Перш ніж почати:

- Підтримувана платформа хоста: Ubuntu 22.04 LTS.
- Наразі триває бета-тестування підтримки Windows 10/11 для хосту.
- Налаштуйте параметри UEFI/BIOS вашого хост-комп’ютера для підтримки драйвера PCIe.
  - На пристроях з процесорами Intel увімкніть технології SRIOV, IOMMU та VT-D.
  - На пристроях з процесорами AMD вимкніть AMD-V і ввімкніть IOMMU.

## Підготуйте плату PCIe.

![ Modalix PCIe карта, перемикач DIP](/img/devkit/pcie-dip-switch.png)

1. На платі Modalix PCIe знайдіть чотири перемикачі DIP, зображені вище. Переконайтеся, що перемикач №1 перебуває у положенні `OFF`.
2. Переконайтеся, що перемикач «Виконати/Програма» встановлено в положення `ON`.
3. Вимкніть хост, вставте карту Modalix PCIe у слот PCIe і ввімкніть хост.
4. Залиште перемикачі DIP у їхньому заводському положенні, якщо інше не вказано в інструкції.
5. Якщо на материнській платі хоста передбачено як основний (синій), так і додатковий (чорний) слот PCIe, встановіть карту Modalix PCIe у додатковий (чорний) слот.
6. Під’єднайте послідовний роз’єм UART карти до хоста для початкового налаштування та налагодження.
7. На платі PCIe також є фізичний Ethernet-порт для безпосереднього підключення до мережі.

Для отримання детальної інформації про інтерфейси, комутатори та роз’єми плати PCIe, див. [ розділ Modalix PCIe Card](/hardware/devkit/modalix-pcie-card).

:::note
У рідкісних випадках вам може знадобитися, щоб драйвер не завантажувався автоматично під час перезавантаження хоста. Щоб вимкнути автоматичне завантаження, створіть або відредагуйте файл `/etc/modprobe.d/blacklist.conf` і додайте `blacklist sima_mla_drv`. Потім виконайте команду `update-initramfs` і перезавантажте хост. Після перезавантаження завантажте драйвери вручну за допомогою команд `insmod` або `modprobe`.
:::
