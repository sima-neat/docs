# Режим PCIe

<Tabs>
<TabItem value="prereq" label="Необхідні умови" default>

:::note
Будь ласка, встановіть або оновіть `sima-cli`, перш ніж продовжувати. Ця інструкція призначена для використання з останньою версією `sima-cli`.
:::

Перш ніж почати:

- Підтримувана платформа хоста: Ubuntu 22.04 LTS.
- Наразі триває бета-тестування підтримки Windows 10/11 для хостів.
- Налаштуйте параметри UEFI/BIOS вашого хоста для забезпечення оптимальної продуктивності та належної роботи драйверів.
  - На пристроях з процесорами Intel увімкніть технології SRIOV, IOMMU та VT-D.
  - На пристроях на базі процесорів AMD вимкніть AMD-V і ввімкніть IOMMU.

</TabItem>
<TabItem value="hardware" label="Підготовка обладнання.">

![PCIe DIP-перемикач на платі SiMa.ai MLSoC PCIe](/img/devkit/pcie-dip-switch.png)

1. На платі MLSoC PCIe є чотири перемикачі, як показано вище. Переконайтеся, що перемикач №1 знаходиться в положенні `OFF`.
2. Переконайтеся, що перемикач «Виконати/Програма» увімкнено.
3. Вимкніть хост-машину, вставте DevKit у слот PCIe і ввімкніть хост-машину.
4. На платі Modalix Early Access PCIe залиште перемикач DIP у заводському положенні за замовчуванням.
5. Якщо на материнській платі хоста передбачено як основний (синій), так і неосновний (чорний) слот PCIe, встановіть карту SiMa PCIe у неосновний (чорний) слот.
6. Рекомендується під’єднати послідовний роз’єм UART карти до хоста для початкового налаштування та налагодження.
7. На платі PCIe також є фізичний Ethernet-порт для прямого підключення до мережі.

Для отримання детальної інформації про інтерфейси, перемикачі та роз’єми DevKit, зверніться до документації [SiMa.ai DevKit: інтерфейс.](/hardware/devkit/modalix-ea-pcie).

:::note
У рідкісних випадках, якщо вам не потрібно, щоб драйвер автоматично завантажувався під час перезавантаження хост-машини, створіть (або відредагуйте, якщо він уже існує) файл `/etc/modprobe.d/blacklist.conf` і додайте рядок blacklist `sima_mla_drv`. Після цього запустіть команду `update-initramfs` і перезавантажте хост-машину. Після перезавантаження драйвери можна завантажувати вручну, використовуючи команди `insmod` або `modeprobe`.
:::

</TabItem>
<TabItem value="driver-linux" label="Встановлення драйвера (Linux)">

Виконайте наведену нижче команду на хості Linux, щоб встановити останню версію драйвера.

```console
sima-user@sima-user-machine:~$ sima-cli install drivers/linux
... ... ...
=== Driver Installation Validation ===
  Component            | Status     | Details
  ----------------------------------------------------------------
  GStreamer            | PASS       | ✅ GStreamer plugin 'pciehost' installed
  Kernel Module        | PASS       | ✅ Kernel module 'sima_mla_drv' installed
  PCI Devices          | PASS       | ✅ Detected SiMa PCIe device(s):
  - 0000:04:00.0 Modalix HHHL v2              driver=sima_mla_drv

✅ Installation complete.
```

Щоб встановити певну версію драйвера, використовуйте прапорець `-v`:

```console
sima-user@sima-user-machine:~$ sima-cli install drivers/linux -v 2.1.0
```

:::note
Після встановлення драйвера вимкніть і знову ввімкніть хост-машину перед виконанням перевірки.
:::

:::warning
Підтримка драйвера PCIe для плати MLSoC PCIe припинилася з випуском SDK 2.0.0. Драйвер, встановлений за допомогою наведеної вище команди, підтримує лише Modalix. Якщо ви використовуєте плату MLSoC PCIe, встановіть драйвер версії 2.0.0 за допомогою `sima-cli install drivers/linux -v 2.0.0`.
:::

</TabItem>

## Віртуальна мережа {#virtual-network}

:::note
Функція віртуальної мережі доступна у версії прошивки `1.5` і пізніших версіях для хоста Linux. Щоб використовувати цю функцію, переконайтеся, що ваш DevKit оновлено до останньої версії прошивки [оновлено](/hardware/getting-started/firmware-update/).

Ця функція доступна лише для хост-системи Linux.
:::

Під час підключення до хост-системи через інтерфейс PCI Express (PCIe), SiMa.ai DevKit створює віртуальний Ethernet-інтерфейс. Цей інтерфейс забезпечує пряму мережеву взаємодію між хостом і DevKit через високошвидкісну шину PCIe.

Функція віртуальної мережі в основному призначена для налагодження, що дозволяє користувачам:

- **Безпечна оболонка (SSH)**: Отримайте віддалений доступ до інтерфейсу командного рядка DevKit для усунення несправностей і керування системою.
- **Протокол захищеного копіювання (SCP)**: безпечно передавайте файли між хостом і DevKit, що полегшує переміщення журналів, конфігурацій та інших необхідних файлів під час розробки та налагодження.

Ця функція також дає користувачам змогу:

- **Оновлення прошивки**: Оновіть прошивку вручну, використовуючи утиліти `scp` та `ssh`, дотримуючись методу копіювання файлів.
- **Призначення статичної IP-адреси (Ethernet через PCIe)**: Вручну налаштуйте статичну IP-адресу для вашого хост-комп’ютера/пристрою MLSoC.

За замовчуванням адреса `10.0.cardnum.1` призначається хост-машині, а `10.0.cardnum.2` – пристрою MLSoC. Однак, для забезпечення стабільної та узгодженої роботи мережі, необхідно вимкнути автоматичне призначення IP-адреси хосту, передавши параметр модуля `default_ip=false` під час завантаження модуля.

Якщо модуль вже завантажено, видаліть його та завантажте повторно з параметром `default_ip=false`, як показано нижче:

```console
sudo modprobe -r sima_mla_drv
sudo modprobe sima_mla_drv default_ip=false
```

**Налаштування, що зберігаються**

Щоб забезпечити збереження налаштування `default_ip=false` після перезавантаження системи, виконайте такі дії:

1. Створіть файл конфігурації modprobe з необхідною опцією:

   ```console
   echo "options sima_mla_drv default_ip=false" | sudo tee /etc/modprobe.d/sima_mla_drv_options.conf
   ```

2. Оновіть початкову файлову систему RAM, щоб додати нову конфігурацію:

   ```console
   sudo update-initramfs -u
   ```

3. Перезавантажте хост-машину, щоб застосувати зміни:

   ```console
   sudo shutdown -r now
   ```

4. Після перезавантаження системи перевірте, чи правильно встановлено параметр:

   ```console
   cat /sys/module/sima_mla_drv/parameters/default_ip
   ```

**Ручне призначення IP-адреси**

Під час ручного завантаження модуля (за допомогою `insmod`), використовуйте наведену нижче команду. Це дозволяє вручну призначити статичну IP-адресу інтерфейсу хост-машини, а отже, і пристрою MLSoC.

```console
sudo insmod sima_mla_drv.ko default_ip=false
```

Для цього також необхідно, щоб на хост-машині була встановлена утиліта `ifconfig`.

```console
ifconfig <eth interface> 20.1.2.1
```

Після того, як IP-адресу буде призначено інтерфейсу хоста, IP + 1 автоматично буде призначено інтерфейсу SoC. Наприклад, якщо `20.1.2.1` призначено хост-машині, то IP-адреса MLSoC буде `20.1.2.2`.

Під час створення інтерфейсів, інтерфейс хоста матиме MAC-адресу у форматі `cardnum:S:I:m:A:0`, а інтерфейс SoC матиме MAC-адресу `cardnum:S:I:m:A:1`. IP-адреси призначаються під час створення як `host:10.0.cardnum.1` і `soc:10.0.cardnum.2`. Для цього також необхідно, щоб на хост-машині була встановлена утиліта `ifconfig`.

1. Результат виконання команди `ifconfig` на хості:

   ```console

       inet 10.0.0.1  netmask 255.255.255.0  broadcast 10.0.0.255
       inet6 fe80::253:49ff:fe4d:4130  prefixlen 64  scopeid 0x20<link>
       ether 00:53:49:4d:41:30  txqueuelen 1000  (Ethernet)

       RX errors 0  dropped 0  overruns 0  frame 0
       TX packets 818  bytes 74840 (74.8 KB)
       TX errors 0  dropped 0 overruns 0  carrier 0  collisions 0
   ```

2. Результат виконання команди `ifconfig` на SiMa.ai DevKit:

   ```console
   eth2: flags=4163<UP,BROADCAST,RUNNING,MULTICAST>  mtu 65536
       inet 10.0.0.2  netmask 255.255.255.0  broadcast 10.0.0.255

   ```

3. Підключіться до пристрою за допомогою SSH з хоста; використовуйте стандартне ім’я користувача `sima` і пароль `edgeai` для підключення.

   ```console
   sima@davinci:~#
   ```
