# Проєктування власного апаратного забезпечення

Існує два способи створити продукт на основі MLSoC Modalix. Оберіть один із них перед
початком роботи, оскільки вони потребують різної документації та різних робіт із запуску плати.

| | Плата-носій для SoM | Мікросхема на платі |
| --- | --- | --- |
| Що ви проєктуєте | Плату-носій для модуля Modalix SoM, на якому вже розміщено SoC, LPDDR5 та живлення | Плату з корпусованою мікросхемою Modalix SoC, включно з пам’яттю, живленням і тактуванням |
| Основна робота з проєктування | Розподіл контактів роз’єму, подача живлення, інтерфейси, тепловий режим | Усе перелічене вище, а також трасування й налаштування DDR та високошвидкісне трасування |
| Документація | Загальнодоступні технічні описи та посібник із запуску плати | Технічний опис SoC і пакети проєктної документації, які SiMa.ai надає на запит |
| Відправна точка для програмного забезпечення | Modalix BSP зі змінами дерева пристроїв для вашої плати-носія | Modalix BSP з адаптацією на рівні плати |

Проєктування з мікросхемою на платі також називають проєктуванням chip-on-board.

## Плата-носій для SoM {#som-carrier-board}

1. Прочитайте **Modalix SoM Carrier Board Hardware Reference** та **Modalix SoM
   Datasheet** у розділі [Довідкові документи](../reference/extra-docs.md).
2. Сплануйте розподіл контактів роз’єму, живлення та інтерфейси за допомогою розділу
   [Запуск плати-носія](./som-carrier.mdx), який описує інтерфейси роз’єму,
   відмінності від еталонної плати-носія та оверлеї для камер.
3. Перевірте призначення низькошвидкісних контактів у розділі [Низькошвидкісний ввід-вивід](../interfaces/low-speed-io.mdx).
4. Після виготовлення плати дотримуйтеся посібника **Carrier Board SoM Bring-Up Guide** для
   першого ввімкнення живлення, а потім адаптуйте дерево пристроїв за допомогою розділу
   [Збирання BSP з вихідного коду](../software/build-from-source.mdx).

## Мікросхема на платі {#chip-down}

1. Запросіть **Modalix SoC Datasheet**, **PCB Routing Guidelines**, **DDR Tuning
   Guide** та пакет еталонного проєкту в представника SiMa.ai. Опис кожного документа наведено в розділі
   [Довідкові документи](../reference/extra-docs.md).
2. Сплануйте охолодження за допомогою **Modalix SoM Thermal Design Guide**.
3. Зберіть і адаптуйте програмне забезпечення за допомогою розділу [Збирання та налаштування eLxr](../software/index.md).

Запуск плати з мікросхемою на платі, зокрема ініціалізація пам’яті та перше завантаження, ще не
описано в загальнодоступній документації. Щодо цього зверніться до представника SiMa.ai.
