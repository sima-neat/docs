# Проєктування власного апаратного забезпечення

Існує два окремі шляхи створення власної системи на основі MLSoC Modalix.
Вони потребують різних робіт із проєктування, різної документації та різного запуску плати,
тому оберіть один із них перед початком роботи.

## Порівняння двох шляхів

| | Проєктування з розміщенням мікросхеми на платі | Проєктування плати-носія |
| --- | --- | --- |
| Що ви проєктуєте | Плату з корпусованою мікросхемою Modalix SoC, включно з пам’яттю, живленням і тактуванням | Плату-носій для модуля Modalix SoM, на якому вже розміщено SoC, LPDDR5 та живлення |
| Основна робота з проєктування | Послідовність подачі живлення, тактування та скидання, трасування й налаштування LPDDR5, високошвидкісне трасування, інтерфейси, тепловий режим | Розподіл контактів роз’єму, подача живлення, інтерфейси, тепловий режим |
| Документація | Посібник із проєктування з розміщенням мікросхеми на платі, технічний опис SoC і пакети проєктної документації, які SiMa.ai надає на запит | Загальнодоступні технічні описи та посібник із запуску плати |
| Відправна точка для програмного забезпечення | Modalix BSP з адаптацією на рівні плати | Modalix BSP зі змінами дерева пристроїв для вашої плати-носія |

Щойно плата завантажується, обидва шляхи використовують однакові кроки роботи з програмним забезпеченням і виробництвом:

- [Збирання та налаштування eLxr](../software/index.md): збирання ядра, U-Boot і
  дерев пристроїв для вашої плати.
- [Інтерфейси та периферійні пристрої](../interfaces/low-speed-io.mdx): розподіл контактів і
  налаштування периферійних пристроїв.
- [Заводське збирання та тестування](../deployment/factory-build-and-test.mdx): програмування
  та тестування плат на виробництві.
