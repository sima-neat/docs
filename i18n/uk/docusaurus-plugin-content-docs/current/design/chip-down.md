# Проєктування з розміщенням мікросхеми на платі

У разі проєктування з розміщенням мікросхеми на платі корпусована мікросхема Modalix SoC встановлюється безпосередньо на вашу власну плату.
Ви самостійно проєктуєте все, що інакше забезпечував би модуль Modalix SoM, зокрема
пам’ять, живлення й тактування. Такий підхід також називають проєктуванням chip-on-board.

Якщо ви віддаєте перевагу модулю, на якому вже розміщено SoC, пам’ять і
живлення, див. розділ [Проєктування плати-носія](./carrier-board.md).

## Що ви проєктуєте

- Подачу живлення та послідовність подачі живлення для SoC
- Тактування та скидання
- Пам’ять LPDDR5, включно з трасуванням і налаштуванням
- Завантажувальний накопичувач, а також послідовний доступ для налагодження та відновлення
- Високошвидкісні інтерфейси, як-от PCIe, MIPI CSI-2 та Ethernet, і їхнє трасування
- Охолодження

## Посібник із проєктування з розміщенням мікросхеми на платі

SiMa.ai має посібник із проєктування плат із розміщенням мікросхеми Modalix на платі. Щоб отримати його, зверніться до свого представника
SiMa.ai.

## Супровідна документація

Ці документи також можна отримати в представника SiMa.ai. Опис кожного з них наведено в розділі
[Довідкові документи](../reference/extra-docs.md).

| Документ | Для чого використовувати |
| --- | --- |
| Технічний паспорт системи на кристалі Modalix | Функції виводів, лінії живлення, часові характеристики сигналів і межі робочих параметрів |
| Modalix Рекомендації щодо трасування друкованих плат | Правила трасування для PCIe, MIPI CSI-2, Ethernet та інших критичних ліній |
| Modalix Посібник з налаштування DDR | Трасування, узгодження та калібрування LPDDR5 |
| Modalix: Ранній доступ, DevKit: Набір для розробки | Еталонний проєкт із розміщенням мікросхеми на платі |
| Modalix PCIe Пакет проєктних рішень HHHL | Еталонний проєкт із розміщенням мікросхеми на платі для карти PCIe |
| Modalix Довідник з термічного проєктування SoM | Теплові бюджети та проєктування охолодження |

## Етапи проєктування

1. Отримайте посібник із проєктування з розміщенням мікросхеми на платі та наведену вище документацію.
2. Спроєктуйте плату, використовуючи пакети проєктної документації як еталонні проєкти.
3. Сплануйте охолодження за допомогою посібника з теплового проєктування.
4. Запустіть плату. Запуск плати з мікросхемою на платі, зокрема ініціалізація пам’яті та перше
   завантаження, ще не описано в загальнодоступній документації. По допомогу зверніться до представника
   SiMa.ai.
5. Адаптуйте та зберіть програмне забезпечення за допомогою розділу [Збирання та налаштування eLxr](../software/index.md).
