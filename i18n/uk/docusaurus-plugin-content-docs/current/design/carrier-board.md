# Проєктування плати-носія

Модуль Modalix SoM містить Modalix SoC, пам’ять LPDDR5 і схему живлення на модулі
з роз’ємами для з’єднання між платами. Ви проєктуєте плату-носій, до якої під’єднується SoM,
з роз’ємами, входом живлення та інтерфейсами, потрібними вашому продукту.

Якщо ж ви хочете розмістити SoC безпосередньо на власній платі, див. розділ
[Проєктування з розміщенням мікросхеми на платі](./chip-down.md).

## Що ви проєктуєте

- Розподіл контактів роз’єму між SoM і вашими інтерфейсами
- Подачу живлення на SoM
- Інтерфейси, як-от Ethernet, PCIe, USB, камери MIPI та низькошвидкісний ввід-вивід
- Послідовний доступ для налагодження та відновлення
- Охолодження

## Супровідна документація

Ці документи наведено в розділі [Довідкові документи](../reference/extra-docs.md).

| Документ | Для чого використовувати |
| --- | --- |
| Довідник з апаратного забезпечення плати-носія Modalix SoM | Розташування контактів роз’ємів, відображення інтерфейсів, подача живлення та еталонні з’єднання. Прочитайте його першим. |
| Modalix Технічний паспорт SoM | Електричні, механічні та теплові характеристики SoM |
| Посібник із введення в експлуатацію плати-носія SoM | Увімкнення живлення та перевірка нової плати-носія |
| Modalix Довідник з термічного проєктування SoM | Теплові бюджети та проєктування охолодження; можна отримати в представника SiMa.ai |

## Етапи проєктування

1. Прочитайте **Довідник з апаратного забезпечення плати-носія Modalix SoM** і **Modalix
   Технічний паспорт SoM**.
2. Сплануйте розподіл контактів роз’єму, живлення та інтерфейси за допомогою розділу
   [Запуск плати-носія](./som-carrier.mdx), який описує інтерфейси роз’єму,
   відмінності від еталонної плати-носія та оверлеї для камер.
3. Перевірте призначення низькошвидкісних контактів у розділі [Низькошвидкісний ввід-вивід](../interfaces/low-speed-io.mdx).
4. Після виготовлення плати дотримуйтеся **Посібника із введення в експлуатацію плати-носія SoM** для
   першого ввімкнення живлення.
5. Адаптуйте дерево пристроїв для вашої плати-носія за допомогою розділу
   [Збирання BSP з вихідного коду](../software/build-from-source.mdx).
