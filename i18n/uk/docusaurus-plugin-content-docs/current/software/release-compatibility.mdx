# Сумісність випусків

Кожен випуск платформи Modalix зібрано з одного коміту в загальнодоступних репозиторіях ядра та
U-Boot. Щоб перезібрати компонент, який відповідає образу на вашій платі, перед збиранням
перейдіть на коміт цього випуску. Див.
[Збирання BSP з вихідного коду](./build-from-source.mdx).

## Як читати цю таблицю

- Репозиторії не мають тегів випусків. Кожен випуск — це окремий коміт у гілці
  `master` із заголовком `SiMa.AI Release <version>`.
- Гілка `master` завжди містить найновіший випуск. Якщо зібрати її для плати зі
  старішим випуском, ви отримаєте ядро чи завантажувач, що не відповідає кореневій
  файловій системі та модулям цієї плати.
- Щоб дізнатися випуск на працюючій платі, виконайте `cat /etc/buildinfo`.

Щоб перейти на коміт випуску:

```console
root@sdk:/data/simaai-linux$ git checkout 65aba29989da
```
