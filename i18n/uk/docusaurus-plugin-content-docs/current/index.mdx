# SiMa.ai Документація щодо апаратного забезпечення.

Цей посібник охоплює налаштування апаратного забезпечення, прошивку та низькорівневі інтерфейси для продуктів SiMa.ai's MLSoC Modalix DevKit. Це спеціалізована довідка щодо апаратного забезпечення; документація щодо програмного забезпечення, машинного навчання та інструментів для конвеєра наведена окремо.

## Про MLSoC Modalix

**MLSoC Modalix** — це друге покоління системи на кристалі для машинного навчання від SiMa.ai. Вона поєднує в собі обчислювальний комплекс Arm Cortex-A65 для застосунків, високопродуктивний **апаратний прискорювач машинного навчання (MLA)**, **процесор обробки зображень (ISP)** для обробки даних з камери та **блок комп’ютерного зору (CVU)** для класичних завдань обробки зображень — і все це розміщено на одному кристалі.

Завдяки цій інтеграції розробники можуть розгортати багатомодальні, генеративні та візуальні конвеєри штучного інтелекту на периферійних пристроях, не об’єднуючи окремі прискорювачі, хост-процесори та інтерфейси для камер. Усі продукти, описані тут — DevKits, комплекти для раннього доступу та плата PCIe — створені на основі одного й того ж кремнієвого чипа MLSoC Modalix, тому застосунки, розроблені для однієї конфігурації, легко переносяться на інші.

## Архітектури розгортання

Сучасні застосунки машинного навчання та виведення інформації вимагають гнучкої архітектури для вирішення різноманітних завдань розгортання. Рішення компанії SiMa.ai розроблені для адаптації до цих потреб, пропонуючи конфігурації, які оптимізують продуктивність, ефективність і масштабованість. Незалежно від того, чи інтегровано їх у більшу систему, чи використовуються як окремий пристрій, MLSoC Modalix забезпечує безперебійну адаптацію до різних сценаріїв використання.

У цій архітектурі MLSoC Modalix працює як незалежний, самодостатній пристрій. Він особливо добре підходить для застосунків, де важливими є компактність, ефективність і мінімальне енергоспоживання.

**Основні сценарії використання**

- **Edge Застосунки зі штучним інтелектом**: Розміщуються на периферії мережі для виконання обчислень без використання центрального сервера або хмарної інфраструктури. Ідеально підходять для таких застосунків, як інтелектуальні камери, промислові пристрої Інтернету речей або автономні роботи.
- **Економічно вигідне розгортання**: зменшує потребу в додатковому обладнанні, що робить його економічно ефективним рішенням для автономних операцій.
- **Середовища з обмеженим енергоспоживанням**: Оптимізовано для сценаріїв, де першочергове значення має енергоефективність, наприклад, для віддалених систем моніторингу, що працюють від акумуляторів або сонячних панелей.

**Переваги**

- **Автономний**: Не потребує наявності хост-системи, що спрощує розгортання та зменшує складність системи.
- **Енергоефективність**: Розроблено для мінімізації споживання енергії, що робить його придатним для використання в середовищах, де важливе енергозбереження.
- **Компактний і портативний**: завдяки невеликим розмірам його можна легко використовувати в умовах обмеженого простору.

**Типовий потік даних**

1. Дані надходять безпосередньо з мережевих інтерфейсів або датчиків.
2. MLSoC Modalix містить [Застосунок NEAT](https://docs.sima-neat.com), який визначає конвеєр для виконання обчислень безпосередньо на пристрої.
3. MLSoC Modalix виконує обчислення та обробляє дані локально.
4. Результати надсилаються на інші пристрої або системи через мережеві з’єднання для подальшої обробки або візуалізації.

У цій архітектурі MLSoC Modalix функціонує як PCIe карта, яка безперешкодно інтегрується в хост-систему. Така конфігурація ідеально підходить для застосунків, де хост-система — наприклад, сервер, настільний комп’ютер або робоча станція — потребує додаткових обчислювальних ресурсів для виконання завдань, пов’язаних з обробкою даних, але вже має достатні можливості для зберігання та обробки даних.

**Основні сценарії використання**

- **Високопродуктивні системи:** підходять для центрів обробки даних або високопродуктивних робочих станцій, де критично важлива обробка та зберігання великих обсягів даних. Хост-система обробляє обчислювально інтенсивні завдання, а MLSoC Modalix виконує спеціалізовані операції виведення.
- **Розширені рішення для вводу/виводу:** Цільовій системі можуть знадобитися додаткові можливості вводу/виводу, які не є стандартними для MLSoC Modalix, наприклад, інтерфейси USB або інші сенсорні входи. Ця архітектура дозволяє системі використовувати розширені ресурси вводу/виводу хост-системи для таких застосунків, як відеоаналітика або масштабований висновок моделей штучного інтелекту.

**Переваги**

- **Розширені обчислювальні ресурси:** розширюють можливості хост-системи шляхом перенесення завдань обчислення на спеціалізоване апаратне забезпечення.
- **Гнучкість:** Ідеально підходить для середовищ, у яких можна додавати додаткові обчислювальні модулі в міру збільшення потреби.

**Типовий процес обробки даних**

1. Основна система збирає дані з датчиків, периферійних пристроїв, носіїв інформації або мережевих інтерфейсів.
2. MLSoC Modalix містить [Застосунок NEAT](https://docs.sima-neat.com), який включає в себе конвеєр для виконання обчислень і адаптовану модель штучного інтелекту.
3. Дані надсилаються до MLSoC Modalix через інтерфейс PCIe для виконання обчислень.
4. Результати обробляються хост-системою або передаються до інших систем для подальших дій.
