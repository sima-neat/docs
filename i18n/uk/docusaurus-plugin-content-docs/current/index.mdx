# Документація щодо апаратного забезпечення SiMa.ai.

Використовуйте цей сайт для отримання інформації про налаштування обладнання, робочі процеси прошивки та низькорівневі інтерфейси для продуктів SiMa.ai MLSoC Modalix. Документація щодо програмного забезпечення, машинного навчання та інструментів для створення конвеєрів наведена окремо.

## Про модальність MLSoC Modalix

**MLSoC Modalix** — це друге покоління системи на кристалі для машинного навчання від SiMa.ai. Вона поєднує в собі обчислювальний комплекс Arm Cortex-A65, високопродуктивний **прискорювач машинного навчання (MLA)**, **процесор обробки зображень (ISP)** для обробки даних з камери та **блок комп’ютерного зору (CVU)** для класичних задач обробки зображень — і все це розміщено на одному кристалі.

Ця інтеграція дозволяє запускати мультимодальні, генеративні та візуальні ШІ-процеси на периферійних пристроях без об’єднання окремих прискорювачів, центральних процесорів і камерних інтерфейсів. Модуль Modalix SoM містить MLSoC Modalix для інтеграції з материнською платою та в продукт, і кожен комплект розробника, описаний тут, використовує один і той самий чип.

## Архітектури розгортання

MLSoC Modalix підтримує дві поширені архітектури розробки: автономний режим і режим PCIe. Оберіть архітектуру, яка відповідає способу підключення вашого обладнання та місцю, де працює ваш додаток.

<Tabs>
<TabItem value="standalone" label="Standalone Mode" default>

У автономному режимі, пристрій Modalix DevKit або спеціальна система на базі модуля Modalix SoM працює як самостійний пристрій. Використовуйте цей режим, коли пристрій отримує дані безпосередньо від датчиків, камер, накопичувачів або мережевих інтерфейсів.

**Основні сценарії використання**

- **Застосування периферійного штучного інтелекту**: здійснюйте обчислення безпосередньо на пристрої, не покладаючись на центральний сервер або хмарну інфраструктуру.
- **Компактні розгортання**: зменшують потребу в додатковому апаратному забезпеченні для хостів.
- **Системи з обмеженим енергоспоживанням**: Підтримка систем віддаленого моніторингу, що працюють від акумуляторів або сонячних панелей.

**Переваги**

- **Автономний**: працює без підключення до хост-машини.
- **Енергоефективність**: підтримує роботу в середовищах, де важливе енергоспоживання.
- **Компактний**: підходить для розгортання в умовах обмеженого простору.

**Типовий потік даних**

1. DevKit отримує дані безпосередньо з мережевих інтерфейсів або датчиків.
2. DevKit завантажує застосунок [NEAT, який визначає конвеєр обчислень, що виконується безпосередньо на пристрої, та застосунок ](https://developer.sima.ai/software).
3. MLSoC Modalix виконує обчислення та обробляє дані локально.
4. Результати надсилаються на інші пристрої або системи через мережеві з’єднання для подальших дій або візуалізації.

У режимі PCIe, плата Modalix PCIe встановлюється в хост-машину. Використовуйте цей режим, коли сервер, настільний комп’ютер або робоча станція виконує оркестрування, зберігання даних і обробку вхідних/вихідних даних, а плата забезпечує прискорення обчислень Modalix.

**Основні сценарії використання**

- **Високопродуктивні системи:** використовуйте сервер або робочу станцію в центрі обробки даних для обробки та зберігання даних, а плату Modalix PCIe використовуйте для виконання обчислень.
- **Керування вводом-виводом хостом:** Використовуйте сховище, мережу або датчики хоста, передаючи при цьому обчислення на карту.

**Переваги**

- **Спеціалізоване прискорення:** Перенесіть обчислення з центрального процесора хоста на апаратне забезпечення Modalix.
- **Можливість розширення:** Додавайте обчислювальні модулі за потреби.

**Типовий процес обробки даних**

1. Основний комп’ютер збирає дані з датчиків, периферійних пристроїв, накопичувачів або мережевих інтерфейсів.
2. Карта Modalix PCIe завантажує застосунок [NEAT, який містить конвеєр висновків і адаптовану модель штучного інтелекту ](https://developer.sima.ai/software).
3. Хост-система надсилає дані на плату Modalix PCIe через інтерфейс PCIe.
4. Хост обробляє результати або передає їх до наступних систем.
