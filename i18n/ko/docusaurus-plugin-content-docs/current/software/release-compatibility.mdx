# 릴리스 호환성

각 Modalix 플랫폼 릴리스는 공개 커널 및 U-Boot 저장소의 커밋 하나에서 빌드됩니다.
보드에 설치된 이미지와 일치하는 구성 요소를 다시 빌드하려면, 빌드하기 전에 해당
릴리스의 커밋을 체크아웃하십시오.
[소스에서 BSP 빌드](./build-from-source.mdx)를 참조하십시오.

## 이 표를 읽는 방법

- 저장소에는 릴리스 태그가 없습니다. 각 릴리스는 `master`의 단일 커밋이며, 제목은
  `SiMa.AI Release <version>`입니다.
- `master`에는 항상 최신 릴리스가 있습니다. 이전 릴리스를 실행하는 보드용으로
  이를 빌드하면, 해당 보드의 루트 파일 시스템 및 모듈과 일치하지 않는 커널
  또는 부트로더가 만들어집니다.
- 실행 중인 보드의 릴리스는 `cat /etc/buildinfo`로 확인합니다.

릴리스를 체크아웃하려면 다음을 실행합니다.

```console
root@sdk:/data/simaai-linux$ git checkout 65aba29989da
```
