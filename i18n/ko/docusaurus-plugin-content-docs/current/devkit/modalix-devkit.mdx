# Modalix DevKit

**Modalix DevKit**은 임베디드 엣지 AI 애플리케이션의 빠른 프로토타입 제작 및 평가를 위해 설계된 소형 고성능 개발 플랫폼입니다. 강력한 Modalix 플랫폼을 기반으로 하는 DevKit은 고급 하드웨어 가속과 최적화된 소프트웨어 스택을 결합하여 컴퓨터 비전, 대규모 언어 모델(LLM) 및 실시간 멀티모달 처리와 같은 다양한 작업에서 효율적이고 유연하며 확장 가능한 AI 추론을 가능하게 합니다.

<TabItem value="interfaces" label="인터페이스" default>

<img src="/img/devkit/modalix-devkit.png" alt="SiMa.ai Modalix SoM 인터페이스" style={{width: '60%', display: 'block', margin: '0 auto'}} />

| 인터페이스 | 설명 |
| --- | --- |
| 이더넷 포트(end0) | RJ45, 1기가비트 이더넷 네트워크 인터페이스를 통해 원격 연결을 지원합니다. |
| COM 포트에서 호스트로 (USB-C) | 호스트 시스템에 연결하여 디버깅을 용이하게 합니다. |
| MIPI 인터페이스 (X2) | MIPI 카메라 연결용. [설정](/hardware/getting-started/standalone-mode/mipi-camera-interfaces) |
| USB 인터페이스(4개) | USB 3.0 인터페이스를 지원하며, 마이크, 스피커 및 USB 비디오 카메라와 호환됩니다. |
| HDMI 인터페이스(1개) | 외부 디스플레이를 연결하기 위한 HDMI 1.4 포트(최대 4K 해상도, 30Hz, 1080p 해상도, 60Hz). |
| 내장 저장 장치(eMMC) | 16GB |
| NVMe | M.2 512GB |
| USB | 4개의 USB 3.0 포트 |

더 자세한 제품 정보는 공식 웹사이트 [SiMa.ai](https://sima.ai/mlsoc/)에서 확인하십시오.

<TabItem value="features" label="주요 기능">

| 기능 | 자세한 내용 |
| --- | --- |
| MLA AI 성능 | INT8 신경망 연산에 대해 초당 50테라 연산을 지원합니다. 또한 bf16 정밀도를 지원합니다. |
| 전력 소비 | 작업량에 따라 8W에서 12W까지. |
| 애플리케이션 처리 장치(APU) | 최대 1.4GHz로 작동하는 8개의 [ARM Cortex-A65 CPU](https://www.arm.com/products/silicon-ip-cpu/cortex-a/cortex-a65) 듀얼 스레드 프로세서 클러스터는 최대 32K Dhrystone MIPs의 성능을 제공합니다. 8개의 코어가 1.4GHz로 작동합니다. |
| 비디오 인코더 | H.264(AVC), H.265(HEVC) 및 MJPEG 압축 표준을 지원합니다. AVC 메인/고급 프로필, HEVC 메인 프로필 및 MJPEG 기본 프로필을 지원합니다. 인코더는 최대 4KP60의 속도로 H.264/H.265를 지원합니다. |
| 비디오 디코더 | H.264(AVC), H.265(HEVC), AV1 및 MJPEG 압축 표준을 지원합니다. AVC 메인/고 프로필, HEVC 메인 프로필, AV1 메인 프로필 및 MJPEG 베이스라인 프로필을 지원합니다. 4:2:0 픽셀 및 8비트 정밀도를 지원합니다. 디코더는 최대 4KP60의 속도로 H.264/H.265를 지원합니다. |
| 컴퓨터 비전 부서(CVU) | 최대 **750개의 16비트 GOPS**를 지원하는 쿼드 코어 Synopsys [ARC EV74 비전 프로세서](https://www.synopsys.com/dw/ipdir.php?ds=ev7x-vision-processors). |
| 메모리 | 32GB LPDDR5 RAM을 사용하며, 이 중 6GB는 ARM 코어에, 16GB는 MLA에 할당됩니다. 나머지는 시스템의 다른 부분에 할당됩니다. |
| 저장 공간 | 추가 저장 공간을 위한 microSD 카드 슬롯이 있는 16GB 내장 eMMC |
| 네트워킹 | 1개의 10기가비트 이더넷 포트를 캐리어 보드를 통해 사용할 수 있습니다. |

</TabItem>
