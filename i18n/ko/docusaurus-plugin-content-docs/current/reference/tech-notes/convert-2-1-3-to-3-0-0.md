# 2.1.3에서 3.0.0으로 업그레이드합니다.

이 절차는 Modalix SoM DevKit 및 Modalix PCIe 카드에 적용됩니다. 대부분의 최신 보드에는 공장에서 2.1.x 펌웨어가 설치되어 있습니다.

2.1.x 버전은 Debian 12와 호환되는 시스템 이미지를 사용합니다. 3.0.0 버전은 Debian 13으로 변경됩니다. 또한 OverlayFS, A/B 이미지 및 SWUpdate에 대한 시스템 변경 사항이 포함됩니다.

이러한 변경으로 인해 3.0.0 시스템 이미지는 2.1 시스템 이미지와 호환되지 않습니다. 변환하려면 특별한 업데이트 절차가 필요합니다. 먼저 보드를 최신 **2.1.3** 펌웨어로 업데이트합니다. 그런 다음 **netboot**를 사용하여 네트워크를 통해 보드를 부팅하고 3.0.0 이미지를 보드의 저장 장치에 씁니다.

이 문서에서는 다음 용어를 사용합니다.

- **보드**: SoM DevKit 또는 PCIe 카드.
- **호스트**: TFTP 서버를 통해 부트 이미지를 제공하는 Ubuntu 또는 macOS 컴퓨터입니다.
- **플래시**: 시스템 이미지를 보드의 저장 장치에 기록합니다.

## 시작하기 전에

- 보드에서 필요한 파일과 설정을 백업하세요.
- 2.1.3 업데이트를 위해 보드가 인터넷에 연결되어 있는지 확인하세요.
- CLI 업데이트 및 이미지 다운로드를 위해 호스트가 인터넷에 접속할 수 있는지 확인하세요.
- 호스트에서 **sima-cli 2.1.19 버전 이상**을 사용하십시오. 인터넷에 연결되어 있으면 `sima-cli`가 최신 버전으로 자동 업데이트됩니다.
- 보드와 호스트 간에 이더넷 연결을 설정합니다.
- 가능하다면 보드를 모니터링하기 위해 시리얼 연결을 준비하십시오.

**호스트**에 최신 `sima-cli`를 설치하려면 다음 명령을 실행하세요.

```bash
curl -fsSL https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh | bash
```

## 1. 보드를 2.1.3 버전으로 업데이트합니다.

이 섹션의 명령어를 **보드에서** 실행하세요.

1. SSH 또는 시리얼을 통해 보드에 연결합니다.
2. 펌웨어 버전을 확인하세요.

   ```bash
   cat /etc/buildinfo
   ```

   보드에 최신 **2.1.3** 버전이 설치되어 있다면 2절로 이동하세요.

3. 최신 `sima-cli`를 설치하세요.

   ```bash
   curl -fsSL https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh | bash
   ```

4. 펌웨어 업데이트를 시작합니다.

   ```bash
   sima-cli update
   ```

5. 화면에 표시되는 안내에 따라 최신 **2.1.3** 버전을 설치하십시오.
6. 안내에 따라 보드를 재부팅하세요.
7. `/etc/buildinfo`를 다시 확인하여 보드가 **2.1.3** 버전으로 실행되는지 확인하십시오.

## 2. 보드를 호스트에 연결합니다.

인터넷 연결을 공유하는 직접 이더넷 연결을 권장합니다.

1. 보드의 이더넷 포트를 호스트에 연결합니다.
2. 호스트에서 인터넷 공유를 활성화합니다.
   - **Ubuntu**: [네트워크 설정](/hardware/getting-started/standalone-mode/network)에 설명된 공유 연결 절차를 따르세요.
   - **macOS**: 보드에 연결된 이더넷 인터페이스에 대해 인터넷 공유 기능을 활성화합니다.

또는 두 시스템을 동일한 네트워크에 연결합니다. 호스트는 보드에 연결할 수 있어야 합니다. 보드는 호스트의 TFTP 서버에 연결할 수 있어야 합니다.

### 보드의 IP 주소를 찾으세요.

인터넷 공유 기능이 활성화되면 호스트가 보드에 IP 주소를 할당합니다. 직렬 콘솔을 사용하여 이 주소를 확인하세요.

1. 보드의 시리얼 포트를 호스트에 연결합니다. [직렬 연결](/hardware/getting-started/setup-serial)을 참조하십시오.
2. **호스트**에서 터미널을 열고 다음 명령을 실행합니다.

   ```bash
   sima-cli serial
   ```

3. 보드에 로그인하세요.
4. 이 명령을 **보드에서** 실행하세요.

   ```bash
   /sbin/ifconfig
   ```

5. 호스트에 연결된 이더넷 인터페이스를 찾습니다.
6. `inet` 뒤에 표시되는 IPv4 주소를 기록합니다. 루프백 주소 `127.0.0.1`는 사용하지 마십시오.
7. 별도의 터미널에서 **호스트**에서 연결 상태를 확인합니다.

   ```bash
   ping {ip}
   ```

모든 명령어에서 `{ip}`를 기록된 주소로 대체합니다. 변환 과정을 모니터링하기 위해 직렬 콘솔을 계속 열어 두십시오.

### 시리얼 액세스가 없는 PCIe 카드

PCIe 카드의 시리얼 포트에 접근하기 어려울 수 있습니다. 시리얼 케이블을 연결할 수 없는 경우 아래의 정적 IP 방법을 사용하십시오.

**2.1.3** 버전을 사용하는 PCIe 카드는 IP 주소를 받지 못하면 **192.168.1.10**을 사용합니다.

1. 카드의 이더넷 포트를 호스트에 직접 연결합니다.
2. 호스트의 연결된 이더넷 인터페이스를 카드와 동일한 서브넷에 있는 **192.168.1.20**으로 설정합니다.
3. 호스트에서 연결 상태를 확인하세요.

   ```bash
   ping 192.168.1.10
   ```

4. 3절에서 `{ip}`에 대해 **192.168.1.10**을 사용하십시오.

이 주소는 카드의 이더넷 포트에 적용됩니다. [PCIe 인터페이스를 통한 이더넷 통신](/hardware/getting-started/pcie-mode/virtual-network)는 별도의 구성을 사용합니다.

## 3. 3.0.0 이미지를 플래싱합니다.

이 섹션의 명령을 **호스트**에서 실행합니다.

1. CLI 버전이 **2.1.19 이상**인지 확인하세요.
2. 시리얼 케이블을 연결했다면 시리얼 콘솔을 계속 열어 두세요.
3. 별도의 호스트 터미널에서 변환을 시작합니다.

   ```bash
   sima-cli bootimg -v 3.0.0 --netboot --devkit {ip} --autoflash
   ```

이 명령어는 호스트에서 TFTP 서버를 시작합니다. 이 명령어는 보드가 해당 서버에서 부팅하도록 지시합니다. 그런 다음 `--autoflash` 옵션이 이미지를 보드에 자동으로 기록합니다.

프로세스가 완료될 때까지 호스트 터미널을 열어두십시오. 네트워크 연결을 유지하고 보드의 전원을 켜둔 상태로 유지하십시오.

## 4. 보드를 재부팅합니다.

1. `sima-cli`가 보드를 재부팅하라는 메시지를 보낼 때까지 기다리세요.
2. 보드를 재부팅합니다.
3. 보드가 시작될 때까지 기다리세요.
4. 시리얼 또는 SSH를 통해 보드에 연결합니다.
5. **보드**에서 펌웨어 버전을 확인하세요.

   ```bash
   cat /etc/buildinfo
   ```

6. 시스템 설정을 진행하기 전에 버전이 **3.0.0**인지 확인하십시오.

PCIe 호스트 시스템의 경우, 호스트 드라이버를 설정하려면 [PCIe 드라이버 설치](/hardware/getting-started/pcie-mode/driver-installation)을 따르십시오.
