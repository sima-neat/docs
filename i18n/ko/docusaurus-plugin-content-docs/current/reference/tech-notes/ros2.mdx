# ROS 2를 Modalix SoM DevKit에 설치합니다.

ROS 2는 로봇 애플리케이션을 위한 라이브러리와 도구를 제공합니다. 이를 통해 센서, 인식, 계획 및 제어 프로세스가 데이터를 교환할 수 있습니다. Modalix SoM에서 ROS 2는 Arm 코어에서 실행됩니다. 인식 애플리케이션은 MLA를 사용하여 신경망 추론을 수행할 수 있습니다.

## 시작하기 전에

다음이 필요합니다:

- 플랫폼 버전 **3.0 이상** 또는 **2.1.x**를 사용하는 Modalix 시스템 온 모듈(SoM) DevKit가 필요합니다.
- DevKit에 설치된 `sima-cli`.
- DevKit에서 패키지를 다운로드하기 위해 인터넷에 접속합니다.
- SSH 또는 시리얼을 통해 DevKit에 연결합니다.

아래 모든 명령을 **DevKit**에서 실행하십시오.

## 1. 플랫폼 버전을 확인하세요.

펌웨어 정보를 확인하세요.

```bash
cat /etc/buildinfo
```

아래에서 사용 중인 플랫폼 버전에 맞는 설치 명령어를 사용하세요.

2.1.x에서 3.0.0으로 업그레이드하려면 먼저 [2.1.3에서 3.0.0으로 변환합니다.](./convert-2-1-3-to-3-0-0.md)을 따르세요.

## 2. ROS 2를 설치합니다.

### 플랫폼 3.0 이상 버전

실행:

```bash
sima-cli neat install ros@v3.0.0
```

화면에 표시되는 지침에 따라 설치를 완료하고 ROS 2 환경을 설정하십시오.

### 플랫폼 2.1.x

실행:

```bash
sima-cli install tools/ros2
```

설치 프로그램은 Debian Bookworm 및 ROS 2 패키지 소스를 추가합니다. 그런 다음 ROS 2, 빌드 도구 및 필요한 라이브러리를 설치합니다. 또한 향후 로그인 시 사용할 수 있도록 ROS 2 환경 설정을 `/home/sima/.bash_profile`에 추가합니다.

현재 셸에서 환경을 로드하려면 다음 명령을 실행하십시오.

```bash
source /usr/local/ros2/local_setup.bash
```

## 3. 설치 확인

이 확인에 사용되는 각 셸에서 ROS 2 환경이 로드되었는지 확인하십시오.

1. ROS 2 명령어가 사용 가능한지 확인하세요.

   ```bash
   ros2
   ```

2. 한 터미널에서 토커를 실행합니다.

   ```bash
   ros2 run demo_nodes_cpp talker
   ```

3. 동일한 DevKit에서 두 번째 셸을 엽니다.
4. 리스너를 시작합니다.

   ```bash
   ros2 run demo_nodes_py listener
   ```

수신자는 `I heard: [Hello World: 1]`와 같은 메시지를 출력해야 합니다. 이러한 메시지는 송신자와 수신자가 데이터를 교환할 수 있음을 보여줍니다.

데모를 중지하려면 각 셸에서 **Ctrl+C**를 누르십시오.
