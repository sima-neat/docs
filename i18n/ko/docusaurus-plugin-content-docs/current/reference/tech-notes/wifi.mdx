# Modalix SoM DevKit에서 USB WiFi 어댑터를 사용합니다.

Modalix SoM DevKit에는 WiFi가 내장되어 있지 않습니다. USB WiFi 어댑터를 사용하여 WiFi를 추가할 수 있습니다. 이 문서에서는 2.4 GHz 및 5 GHz에서 WiFi 6를 지원하는 MediaTek MT7921AU 칩이 탑재된 어댑터를 사용합니다. 플랫폼 3.0 커널에는 Linux 무선 스택이 포함되어 있지만 이 칩용 드라이버는 포함되어 있지 않습니다. 따라서 드라이버를 빌드하고, 칩의 펌웨어와 함께 설치한 다음, NetworkManager로 연결합니다.

## 시작하기 전에

다음이 필요합니다:

- 플랫폼 버전 **3.0**을 사용하는 Modalix SoM DevKit. 확인하려면 DevKit에서 `cat /etc/buildinfo`를 실행하십시오.
- MediaTek MT7921AU 칩이 탑재된 USB WiFi 어댑터(USB ID `0e8d:7961`).
- 패키지를 설치하기 위한 DevKit의 인터넷 연결(Ethernet 사용).
- 드라이버를 빌드하기 위한 Docker와 `git`이 설치된 Linux 호스트, 그리고 호스트에서 DevKit로의 SSH 접속.

어댑터를 DevKit의 USB 포트에 연결한 다음, DevKit가 어댑터를 인식하는지 확인하십시오:

```console
sima@modalix:~$ lsusb | grep 0e8d:7961
Bus 002 Device 003: ID 0e8d:7961 MediaTek Inc. Wireless_Device
```

## 1. 호스트에서 드라이버 빌드 {#build}

SiMa.ai 커널 소스에서 DevKit 자체의 커널 구성을 사용하여 `mt7921u` 드라이버와 이 드라이버가 의존하는 `mt76` 모듈을 빌드합니다. 빌드는 DevKit 커널과 동일한 컴파일러를 갖춘 Debian 컨테이너에서 실행됩니다.

다음 명령을 **호스트에서** 실행하십시오. `<devkit-ip>`를 DevKit의 IP 주소로 바꾸십시오.

1. 커널 소스와 DevKit의 커널 구성을 가져옵니다:

   ```bash
   git clone --depth 1 https://github.com/SiMa-ai/simaai-linux.git
   ssh sima@<devkit-ip> 'zcat /proc/config.gz' > board.config
   ```

2. 모듈을 빌드합니다:

   ```bash
   docker run --rm -v "$PWD":/w -w /w/simaai-linux debian:trixie bash -c '
     apt-get update && apt-get install -y gcc-aarch64-linux-gnu make bc flex bison libssl-dev libelf-dev python3 kmod &&
     export ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- LOCALVERSION=-modalix &&
     cp ../board.config .config &&
     scripts/config --module MT7921U &&
     make olddefconfig &&
     make -j"$(nproc)" modules_prepare &&
     make -j"$(nproc)" M=drivers/net/wireless/mediatek/mt76 KBUILD_MODPOST_WARN=1 modules'
   ```

   빌드 중에 확인되지 않은 심볼에 대한 경고가 출력됩니다. 이는 예상된 동작입니다. 해당 심볼은 DevKit에 이미 있는 `cfg80211` 및 `mac80211` 모듈에 포함되어 있습니다.

3. 빌드에서 모듈 7개가 생성되었는지 확인합니다:

   ```bash
   find simaai-linux/drivers/net/wireless/mediatek/mt76 -name '*.ko'
   ```

   `mt76.ko`, `mt76-usb.ko`, `mt76-connac-lib.ko`, `mt792x-lib.ko`, `mt792x-usb.ko`, `mt7921-common.ko` 및 `mt7921u.ko`가 생성됩니다.

4. 모듈을 DevKit로 복사합니다:

   ```bash
   scp $(find simaai-linux/drivers/net/wireless/mediatek/mt76 -name '*.ko') sima@<devkit-ip>:/tmp/
   ```

## 2. DevKit에 드라이버 및 펌웨어 설치 {#install}

아래 명령을 **DevKit에서** 실행하십시오.

1. 모듈을 설치하고 모듈 인덱스를 업데이트합니다:

   ```console
   sima@modalix:~$ sudo mkdir -p /lib/modules/$(uname -r)/updates/mt76
   sima@modalix:~$ sudo mv /tmp/mt7*.ko /lib/modules/$(uname -r)/updates/mt76/
   sima@modalix:~$ sudo depmod -a
   ```

2. 어댑터의 펌웨어와 무선 규제 데이터베이스를 설치합니다:

   ```console
   sima@modalix:~$ sudo apt-get update
   sima@modalix:~$ sudo apt-get install -y firmware-mediatek wireless-regdb
   ```

3. 드라이버를 로드합니다:

   ```console
   sima@modalix:~$ sudo modprobe mt7921u
   ```

   이제부터는 부팅 시를 포함하여 어댑터를 연결할 때마다 드라이버가 자동으로 로드됩니다.

4. 어댑터에 무선 인터페이스가 있는지 확인합니다:

   ```console
   sima@modalix:~$ nmcli device status
   DEVICE                  TYPE      STATE         CONNECTION
   end0                    ethernet  connected     end0-dhcp
   wlxe84e06afdb5e         wifi      disconnected  --
   ```

   인터페이스 이름은 `wlx`로 시작하고 그 뒤에 어댑터의 MAC 주소가 붙습니다. 인터페이스가 나타나지 않으면 `sudo dmesg | grep mt7921u`로 드라이버 메시지를 확인하십시오. 펌웨어가 로드되면 메시지에 펌웨어 버전이 표시됩니다.

## 3. WiFi 네트워크에 연결 {#connect}

DevKit에서 NetworkManager 명령줄 도구인 `nmcli`를 사용합니다.

1. 네트워크를 검색합니다:

   ```console
   sima@modalix:~$ sudo nmcli device wifi rescan
   sima@modalix:~$ nmcli device wifi list
   ```

2. 연결합니다. `<SSID>`와 `<password>`를 네트워크 이름과 비밀번호로 바꾸십시오:

   ```console
   sima@modalix:~$ sudo nmcli device wifi connect "<SSID>" password "<password>"
   ```

   NetworkManager는 연결을 저장하고 부팅할 때마다 다시 연결합니다.

3. 연결을 확인합니다:

   ```console
   sima@modalix:~$ nmcli device status
   sima@modalix:~$ ip -4 -br addr show
   sima@modalix:~$ ping -c 3 -I wlxe84e06afdb5e 8.8.8.8
   ```

   `wlxe84e06afdb5e`를 사용 중인 인터페이스 이름으로 바꾸십시오.

메뉴에서 네트워크를 선택하려면 `sudo nmtui`를 실행하고 **Activate a connection**을 선택하십시오.

DevKit가 Ethernet으로도 연결되어 있으면 Ethernet 연결이 기본 경로로 유지됩니다. NetworkManager는 WiFi에 더 낮은 우선순위를 부여합니다.

## 제한 사항 {#limitations}

- **펌웨어를 업데이트하면 드라이버가 제거됩니다.** 모듈은 실행 중인 커널용으로 빌드됩니다. DevKit 펌웨어를 업데이트한 후에는 모듈을 다시 빌드하고 설치하십시오.
- **다른 어댑터에는 해당 어댑터용 드라이버가 필요합니다.** 이 문서는 MediaTek MT7921AU를 다룹니다. 다른 칩에는 다른 커널 드라이버와 펌웨어가 필요합니다.
- **6 GHz는 지원되지 않습니다.** MT7921AU는 2.4 GHz와 5 GHz만 사용합니다.
