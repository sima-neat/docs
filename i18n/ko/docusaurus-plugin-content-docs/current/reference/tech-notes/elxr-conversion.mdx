# eLxr로 변환

이 가이드에서는 기존의 SiMa.ai 기반 Yocto **DevKit**를 새로운 **eLxr** 런타임 환경으로 변환하는 방법과 필요에 따라 Yocto로 되돌리는 방법을 설명합니다.

:::note
eLxr 플랫폼은 SDK **2.0.0** 버전부터 지원되며, **Modalix DevKit**에서 사용할 수 있습니다.

eLxr로 변환하려면 tRoot 업데이트와 eMMC 재플래싱이 필요하며, 이는 [네트워크 부팅](/hardware/getting-started/firmware-update/#netboot)를 통해 수행됩니다.
:::

**eLxr** 플랫폼은 기존 Yocto 환경을 대체하여 SiMa.ai DevKit의 새로운 기본 런타임으로 사용됩니다.
이 플랫폼은 개발자에게 상당한 이점을 제공합니다.

- **간소화된 업데이트** — 통합된 루트 파일 시스템 레이아웃과 더 큰 용량의 루트 파일 시스템.
- **표준 패키지 관리자** — 지속적인 패키지 관리를 제공하는 데비안 기반의 기본 패키지입니다.

마이그레이션하기 전에 현재 환경을 확인하려면 아래의 간단한 확인 단계를 따르세요.

현재 DevKit에 설치된 펌웨어를 확인하려면 시리얼 또는 SSH를 통해 연결하고 다음 명령을 실행하세요.

```bash
cat /etc/buildinfo | grep DISTRO
```

다음 중 하나가 표시되어야 합니다.

```text
DISTRO = poky
```

또는

```text
DISTRO = eLxr
```

`poky`를 발견하면 아래 단계를 따라 마이그레이션하세요.

<details open>
<summary><strong>1단계: 최신 tRoot 버전으로 업데이트합니다.</strong></summary>

eLxr 변환을 진행하기 전에 DevKit을 최신 **tRoot** 이미지로 업데이트하십시오.

이 업데이트는 tRoot(신뢰할 수 있는 루트)가 eLxr와 호환되도록 하기 위해 필요합니다.

호스트의 IP 주소가 `192.168.1.10`으로 고정되어 있고 DevKit에 `192.168.1.20`을 통해 접근할 수 있는지 확인하십시오(자세한 내용은 [네트워크 설정](/hardware/getting-started/standalone-mode/#network) 참조).

<img src="/img/media/host-cli.png" alt="Run on the host machine" width="55" style={{float: 'left', marginRight: '8px'}} />

```bash
sima-user@sima-user-machine:~$ sima-cli update --ip 192.168.1.20 2.0.0 --troot_only
```

업데이트가 성공적으로 완료되면 변경 사항을 적용하기 위해 **DevKit의 전원을 껐다가 다시 켜 주세요**.

</details>

<details open>
<summary><strong>2단계: eLxr 이미지를 사용하여 네트워크 부팅을 하고 eMMC에 플래싱합니다.</strong></summary>

나머지 변환 과정은 [Net Boot를 사용하여 업데이트합니다.](/hardware/getting-started/firmware-update/#netboot)에 설명된 표준 TFTP 네트워크 부팅 + 플래시 절차를 사용합니다. 다음은 eLxr에 특정한 값을 적용한 절차입니다.

- **2단계(TFTP 서버 시작):** `--boardtype modalix --fwtype elxr -v 2.0.0`을 사용합니다.
- **3단계(U-Boot 구성):** `boot`를 실행하기 전에 `boot_targets=net`와 함께 `cpio_name=simaai-image-palette-modalix.cpio.gz`를 설정합니다.
- **4단계(플래시):** `netboot>` 프롬프트에 `f`를 입력합니다.

![연결 다이어그램](/img/tech-notes/conversion-diagram.png)

*연결 다이어그램*

펌웨어 업데이트가 완료되고 DevKit의 전원을 껐다가 다시 켜면 **eLxr**가 eMMC에서 기본적으로 실행됩니다.

</details>

<details open>
<summary><strong>3단계. 선택 사항: 2.0 eLxr 기본 데모 설치</strong></summary>

버전 1.7을 실행하는 DevKit에는 버전 1.7과 호환되는 OOB(즉시 사용 가능한) 데모가 미리 설치되어 있을 수 있습니다. eLxr를 사용하여 DevKit을 버전 2.0으로 변환한 후 아래 지침에 따라 OOB 데모를 업그레이드할 수 있습니다.

계속하려면 DevKit을 인터넷에 연결하고 SSH 세션 또는 직렬 콘솔을 사용하여 접속합니다.

![독립 실행형 DevKit](/img/tech-notes/conversion-devkit-standalone.png)

*독립 실행형 DevKit*

<img src="/img/media/devkit-cli.png" alt="Run on the devkit console shell" width="55" style={{float: 'left', marginRight: '8px'}} />

```bash
modalix:~$ cd /tmp && curl -O https://tools.modalix.info/setup-oob.sh && bash setup-oob.sh
```

설치 스크립트 실행 중에 이전에 OOB(Out-of-Box) 경험의 이전 버전이 설치되어 있는 경우, 데모를 업그레이드할지 여부를 확인하는 메시지가 표시됩니다. 확인하려면 `Yes`를 입력하세요.

에셋을 설치하려면 설치를 승인해야 합니다. 설치 스크립트는 설치 명령 중에 코드를 출력하고 승인 URL을 표시합니다. 브라우저를 열고 **auth.sima.ai** 링크로 이동한 다음 **개발자 포털 계정**으로 로그인합니다. 터미널에 출력된 코드를 확인하여 설치를 승인합니다.

</details>

<details open>
<summary><strong>Yocto로 되돌립니다(선택 사항).</strong></summary>

Yocto로 다시 전환하려면 `--fwtype yocto`를 사용하여 [Net Boot를 사용하여 업데이트합니다.](/hardware/getting-started/firmware-update/#netboot)를 다시 실행합니다. `cpio_name` U-Boot 변수는 Yocto 대상에는 필요하지 않습니다. `setenv boot_targets net`, `saveenv`, `boot`만 사용하면 됩니다.

:::note
Yocto로 다시 변환할 때 **최소 tRoot 버전 요구 사항은 없습니다**. 따라서 위에서 설명한 1단계는 건너뛸 수 있습니다.

eLxr로 변환한 후 직렬 콘솔에 NFS 관련 오류 메시지가 표시되면 안전하게 무시해도 됩니다.
:::

</details>

## 요약

1. 최신 **tRoot** 이미지(≥ 2.0.0)로 업데이트하세요.
2. [Net Boot를 사용하여 업데이트합니다.](/hardware/getting-started/firmware-update/#netboot)를 실행하고, `--fwtype elxr` 및 eLxr `cpio_name`을 사용하여 eMMC에 eLxr를 플래싱합니다.
