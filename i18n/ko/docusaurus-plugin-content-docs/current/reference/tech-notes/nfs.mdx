# NFS 설정

대규모 데이터 세트 또는 모델 파일을 사용할 때 빠르고 효율적인 파일 접근은 원활한 데모 및 개발 환경을 위해 필수적입니다.

NFS(네트워크 파일 시스템)를 사용하면 Ubuntu 머신(서버)과 Modalix DevKit (클라이언트) 간에 원활한 파일 공유가 가능하며, 로컬 복사본을 필요로 하지 않고 대용량 저장 장치에 직접 접근할 수 있습니다.

:::note
NFS는 특히 DevKit에 고속, 대용량 저장 장치(예: NVMe)가 부족할 때 유용합니다. 이는 MLSoC 및 Modalix 얼리 액세스 키트(EA)와 같은 플랫폼에도 적용되며, 이들 플랫폼에서 SD 카드에만 의존하면 로딩 시간이 더 오래 걸릴 수 있습니다.
:::

NFS는 특히 다음과 같은 경우에 유용할 수 있습니다.

- 대규모 모델이나 데이터 세트는 여러 장치에서 공유해야 합니다.
- 클라이언트 측의 로컬 저장 공간은 제한적이거나 사용할 수 없습니다.
- 업데이트를 간소화하기 위해 중앙 집중식 스토리지 관리를 사용하는 것이 좋습니다.

<details open>
<summary><strong>1단계: NFS 서버 설정</strong></summary>

1. **NFS 커널 서버를 설치합니다**:

   ```bash
   sima-user@sima-user-machine:~$ sudo apt update
   sima-user@sima-user-machine:~$ sudo apt install -y nfs-kernel-server
   ```

2. **공유 디렉터리 생성**:

   Modalix DevKit와 공유할 디렉터리를 선택하세요.

   ```bash
   sima-user@sima-user-machine:~$ sudo mkdir -p /mnt/nfs_share
   sima-user@sima-user-machine:~$ sudo chmod 777 /mnt/nfs_share
   ```

3. **NFS 내보내기 파일을 편집합니다**:

   내보내기 파일을 엽니다.

   ```bash
   sima-user@sima-user-machine:~$ sudo nano /etc/exports
   ```

   다음 줄을 맨 끝에 추가하고, `<modalix_ip>`를 Modalix DevKit의 IP 주소로 바꿉니다.

   ```
   /mnt/nfs_share <modalix_ip>(rw,sync,no_subtree_check)
   ```

   네트워크의 모든 IP 주소에서 접근을 허용하려면(테스트용), 다음을 사용하세요.

   ```
   /mnt/nfs_share *(rw,sync,no_subtree_check)
   ```

4. **변경 사항을 적용하고 NFS 서비스를 다시 시작합니다**:

   ```bash
   sima-user@sima-user-machine:~$ sudo exportfs -a
   sima-user@sima-user-machine:~$ sudo systemctl restart nfs-kernel-server
   ```

</details>

<details open>
<summary><strong>2단계: NFS 클라이언트 설정</strong></summary>

1. **마운트 지점 생성**:

   ```bash
   modalix:~$ sudo mkdir -p /mnt/
   ```

2. **NFS 공유를 마운트합니다**:

   `<server_ip>`를 Ubuntu 서버의 IP 주소로 변경하세요.

   ```bash
   modalix:~$ sudo mount <server_ip>:/mnt/nfs_share /mnt/
   ```

3. **마운트 상태 확인**:

   NFS 공유가 올바르게 마운트되었는지 확인하세요.

   ```bash
   modalix:~$ df -h | grep mnt
   ```

</details>

<details open>
<summary><strong>3단계: 마운트 설정을 영구적으로 유지</strong></summary>

부팅 시 NFS 공유를 자동으로 마운트하려면 Modalix에서 다음 단계를 수행하십시오.

1. **mnt.mount 파일을 생성합니다**:

   ```bash
   modalix:~$ sudo vi /etc/systemd/system/mnt.mount
   ```

2. **이 내용을 파일에 추가하되, server_IP를 Ubuntu 서버의 IP 주소로 반드시 변경하십시오.**

   ```
   [Unit]
   Description=NFS Mount
   After=network-online.target
   Requires=network-online.target

   [Mount]
   What=<server_IP>:/mnt/nfs_share
   Where=/mnt/
   Type=nfs
   Options=defaults,_netdev

   [Install]
   WantedBy=multi-user.target
   ```

3. **저장하고 종료합니다. 그런 다음, 구성을 테스트합니다.**

   ```bash
   modalix:~$ sudo systemctl daemon-reload
   modalix:~$ sudo systemctl enable mnt.mount
   modalix:~$ sudo systemctl start mnt.mount
   ```

</details>
