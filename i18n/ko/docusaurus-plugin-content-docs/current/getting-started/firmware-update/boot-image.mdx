# 부트 이미지 생성

표준 업데이트 경로를 사용할 수 없거나 이동식 부팅 미디어가 필요한 경우 부트 이미지를 사용합니다. 일반적인 경우는 다음과 같습니다.

- DevKit의 내부 저장소가 손상되었거나 부팅되지 않습니다.
- 배포를 위해 여러 개의 부팅 가능한 SD 카드 또는 이동식 드라이브를 준비해야 합니다.

`sima-cli bootimg`를 사용하여 SD 카드 또는 NVMe 드라이브와 같은 이동식 장치에 전체 부팅 가능한 이미지를 다운로드하고 씁니다. 또한 [BalenaEtcher](https://etcher.balena.io/)와 같은 타사 도구를 사용할 수도 있습니다.

<Tabs groupId="bootimage-method">
<TabItem value="sima-cli" label="sima-cli 사용" default>

```console
sima-cli bootimg -v %platform_version% --boardtype [modalix|mlsoc]
```

이 명령은 다음 단계를 수행합니다.

1. 지정된 보드 유형(`modalix` 또는 `mlsoc`) 및 SDK 버전에 대한 부팅 가능한 이미지를 다운로드합니다.
2. 호스트 시스템에서 이동식 저장 장치를 검색합니다.
3. 쓸 장치를 확인하라는 메시지를 표시합니다.
4. 선택한 장치에 부트 이미지를 직접 씁니다.

프로세스가 완료되면 SD 카드를 분리하고 DevKit에 삽입합니다. 다음 부팅 시 DevKit은 새 이미지에서 시작됩니다.

**중요 참고 사항:**

- 이 명령은 Linux 또는 macOS 호스트에서 실행해야 합니다.
- 이미지를 다운로드하려면 인터넷 연결이 필요합니다.

</TabItem>
<TabItem value="third-party" label="타사 도구 사용">

타사 이미지 작성 도구(예: BalenaEtcher)를 사용하여 이미지를 쓸 수도 있습니다.

1. 먼저 `sima-cli`를 사용하여 이미지를 다운로드합니다.

   수동 업데이트 단계를 위해 펌웨어 이미지만 다운로드하려면 적절한 Modalix 펌웨어 아카이브의 URL로 `sima-cli download`를 실행합니다.

2. 다운로드한 아카이브의 내용을 추출합니다.

   ```console
   tar -xvf simaai-devkit-fw-modalix-yocto-1.7.0.tar.gz
   ```

3. BalenaEtcher를 사용하여 결과 `.wic.gz` 파일을 선택하고 SD 카드 또는 USB 드라이브에 플래시합니다.

작성이 완료되면 장치를 DevKit에 삽입하고 전원을 켜서 이미지에서 부팅합니다.

</TabItem>
</Tabs>
