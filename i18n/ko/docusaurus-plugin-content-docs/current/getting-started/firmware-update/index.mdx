# 펌웨어 업데이트

DevKit 펌웨어를 최신 상태로 유지하고, 부팅되지 않는 장치를 복구하거나 특정 펌웨어 릴리스를 설치하십시오.

이 섹션은 플랫폼 릴리스 %platform_version%에 적용됩니다.

:::note
이 섹션의 가이드는 SiMa.ai가 제공하는 이미지를 설치합니다. 직접 빌드한 이미지를 기록하려면 [eMMC에 이미지 플래싱](/hardware/deployment/flash-image)을 참조하십시오.
:::

:::note
계속하기 전에 `sima-cli`를 설치하거나 최신 버전으로 업데이트하십시오. 이 설명서는 최신 `sima-cli` 버전을 사용하는 것을 기준으로 작성되었습니다.
:::

:::warning
다음 펌웨어 버전 간에 Modalix DevKit를 업그레이드하려면 특별한 변환 절차가 필요합니다.

- **1.7에서 2.0으로:** [eLxr로 변환](/hardware/reference/tech-notes/elxr-conversion) 지침을 따라 Yocto Linux에서 eLxr로 전환합니다.
- **2.x(2.0 포함)에서 3.0으로:** [2.1.3에서 3.0.0으로 변환합니다.](/hardware/reference/tech-notes/convert-2-1-3-to-3-0-0) 기술 문서를 따르십시오. 먼저 2.1.3으로 업데이트한 다음, netboot를 사용하여 3.0.0을 설치합니다. 2.x에서 3.0으로 직접 펌웨어를 업데이트하는 것은 지원되지 않습니다.
:::

## 운영 체제 {#os}

SiMa.ai Modalix DevKit은 Debian 기반 배포판인 eLxr Linux를 실행합니다. **2025년 12월 중순 이후**에 출하되는 장치에는 eLxr가 미리 설치되어 있습니다. 이보다 먼저 출하된 Modalix 장치(2025년 12월 중순 이전에 출하)에는 Yocto가 미리 설치되어 있으며, [eLxr로 변환](/hardware/reference/tech-notes/elxr-conversion) 기사를 참고하여 eLxr로 변환할 수 있습니다.

eLxr는 Modalix 플랫폼에서 개발을 위해 사용되는 Debian 기반 운영 체제입니다. 다음과 같은 기능을 제공합니다.

- 완전한 Debian 패키지 관리 (`apt`)
- 개발 및 디버깅을 위한 더욱 폭넓은 사용자 환경
- 기기에서 직접 도구를 빌드하고 설치할 수 있는 능력
- 크로스 컴파일 없이 더 빠른 반복 작업
- 더욱 폭넓은 라이브러리 및 프레임워크 생태계

아래 펌웨어 업데이트 방법을 사용하여 DevKit의 펌웨어를 업데이트하고, 부팅 가능한 복구 미디어를 생성하거나, 네트워크를 통해 펌웨어를 다시 설치하십시오.

:::tip
DevKit에 인터넷 연결이 없는 경우, 호스트 기반 워크플로를 사용하십시오. **네트워크 부팅 복구**를 사용하여 호스트에서 부팅하고 eMMC를 플래싱하거나, **부트 이미지 생성**을 사용하여 이동식 부팅 미디어를 준비하십시오. 호스트 장치는 펌웨어 이미지를 다운로드하기 위해 인터넷 연결이 필요하며, 이미 로컬에 이미지가 있는 경우에는 예외입니다.
:::
