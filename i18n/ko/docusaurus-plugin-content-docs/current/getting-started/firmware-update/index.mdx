# 펌웨어 업데이트

DevKit 펌웨어를 최신 상태로 유지하고, 부팅되지 않는 장치를 복구하거나 특정 펌웨어 버전을 설치하십시오.

:::note
계속하기 전에 `sima-cli`를 설치하거나 최신 버전으로 업데이트하십시오. 이 설명서는 최신 `sima-cli` 버전을 사용하는 것을 기준으로 작성되었습니다.
:::

:::warning
Modalix DevKit을 SDK 1.7에서 2.0으로 업그레이드하려면 추가 단계가 필요합니다. 변환 절차에 대해서는 [eLxr로 변환](/ko/hardware/reference/tech-notes/elxr-conversion) 가이드 문서를 참조하십시오.
:::

## 운영 체제 {#os}

SiMa.ai와 Modalix DevKit는 eLxr Linux를 실행하며, 이는 Debian 기반 배포판입니다. **2025년 12월 중순 이후**에 출하되는 장치에는 eLxr가 미리 설치되어 있습니다. 이보다 먼저 출하된 Modalix 장치(2025년 12월 중순 이전에 출하)에는 Yocto가 미리 설치되어 있으며, [eLxr로 변환](/ko/hardware/reference/tech-notes/elxr-conversion) 기사를 참고하여 eLxr로 변환할 수 있습니다.

eLxr는 Modalix 플랫폼에서 개발을 위해 사용되는 Debian 기반 운영체제입니다. 다음과 같은 기능을 제공합니다.

- 완전한 Debian 패키지 관리 (`apt`)
- 개발 및 디버깅을 위한 더욱 폭넓은 사용자 환경
- 기기에서 직접 도구를 제작하고 설치할 수 있는 능력
- 크로스 컴파일 없이 더 빠른 반복 작업
- 더욱 폭넓은 라이브러리 및 프레임워크 생태계

아래 펌웨어 업데이트 방법을 사용하여 DevKit의 펌웨어를 업데이트하고, 부팅 가능한 복구 미디어를 생성하거나, 네트워크를 통해 펌웨어를 다시 설치하십시오.

:::tip
DevKit에 인터넷 연결이 없는 경우, 호스트 기반 워크플로를 사용하십시오. **Net Boot Recovery**를 사용하여 호스트에서 부팅하고 eMMC를 플래싱하거나, **Create Boot Image**를 사용하여 이동식 부팅 미디어를 준비하십시오. 호스트 장치는 펌웨어 이미지를 다운로드하기 위해 인터넷 연결이 필요하며, 이미 로컬에 이미지가 있는 경우에는 예외입니다.
:::
