# sima-cli를 사용하여 업데이트

DevKit이 실행 중이고 네트워크를 통해 접근할 수 있을 때 `sima-cli update`를 사용합니다. 이 방법은 펌웨어 이미지를 다운로드하고 DevKit에서 업데이트를 트리거합니다.

:::note
`sima-cli update`는 SiMa.ai 공식 빌드만 설치합니다. 직접 빌드한 이미지를 사용하는 경우에는 [eMMC에 이미지 플래싱](/hardware/deployment/flash-image)을 참조하십시오.
:::

:::note
DevKit에서 2.x 펌웨어를 실행 중인 경우, 이 업데이트 메커니즘을 사용하여 3.0으로 직접 업데이트할 수 없습니다. 먼저 [2.1.3에서 3.0.0으로 변환합니다.](/hardware/reference/tech-notes/convert-2-1-3-to-3-0-0)을 수행하십시오. 변환 후에는 `sima-cli update`를 사용하여 eLxr 3.0에서 최신 릴리스로 업데이트하십시오.
:::

계속하기 전에 호스트가 네트워크를 통해 DevKit에 접근할 수 있는지 확인하십시오. 다음을 참조하십시오.

- [독립 모드 네트워크 설정](/hardware/getting-started/standalone-mode/network)
- [PCIe 모드 가상 네트워크 설정](/hardware/getting-started/pcie-mode/virtual-network)

<Tabs groupId="sima-cli-source">
<TabItem value="from-devkit" label="DevKit에서" default>

독립 DevKit에서 `sima-cli`를 직접 실행합니다. DevKit에 활성 인터넷 연결이 있는지 확인한 다음 다음을 실행합니다.

```console
modalix:~$ sima-cli update
```

MLSoC에서 Yocto Linux를 실행하거나, Modalix에서 eLxr 3.0 이상을 실행하는 경우, 이미지 파일을 직접 다운로드하여 호스트에 배포했다면 버전 문자열 대신 전체 URL을 지정할 수도 있습니다. 이는 eLxr 3.0에서 최신 버전으로 업데이트하는 경우를 포함합니다.

```console
modalix:~$ sima-cli update http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="from-host" label="호스트 시스템에서">

:::note
호스트에서 시작하는 업데이트는 MLSoC에서 Yocto Linux를 실행할 때, 그리고 Modalix에서 eLxr 3.0 이상을 실행할 때 지원됩니다. 여기에는 3.0에서 최신 릴리스로의 업데이트가 포함됩니다. Modalix에서 eLxr 2.x를 실행하는 경우, DevKit에서 직접 업데이트를 수행하십시오. 3.0으로 업그레이드하려면 위에 링크된 변환 가이드를 참조하십시오.
:::

호스트 시스템에서 다음 명령을 사용합니다.

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit}
```

이 명령은 해당되는 경우 호스트에 적절한 Linux 드라이버 버전을 설치합니다.

펌웨어를 다운로드하여 네트워크에 호스팅한 경우 반복적인 인터넷 다운로드를 피하기 위해 URL을 제공합니다.

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit} http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="download" label="다운로드만">

수동 업데이트 단계를 위해 펌웨어 이미지만 다운로드하려면 적절한 Modalix 펌웨어 아카이브의 URL로 `sima-cli download`를 실행합니다.

</TabItem>
</Tabs>

:::note
DevKit을 **다운그레이드**하거나 **최신 릴리스가 아닌** 빌드(예: 사전 릴리스 `develop` 빌드 또는 내부 엔지니어링 이미지)를 설치하려면 대신 [Net Boot Recovery](/hardware/getting-started/firmware-update/net-boot)를 사용하십시오. 이 방법은 호스트의 TFTP 서버에서 DevKit을 부팅하고 대상 이미지를 eMMC에 직접 플래시합니다.
:::
