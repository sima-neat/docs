# DevKit을(를) 설정하세요.

Modalix DevKit을 바로 사용할 수 있도록 하려면 [빠른 시작 안내서](pathname:///tools/qsg/index.html)부터 시작하세요.

이 섹션에서는 DevKit을 다양한 배포 시나리오(예: 독립 실행 모드 및 PCIe 모드)에서 설정하는 방법에 대한 단계별 고급 지침을 제공합니다. 또한 최신 소프트웨어 버전에 대한 호환성을 보장하기 위해 DevKit 펌웨어를 업데이트하는 방법도 설명합니다.

아래 링크를 사용하여 각 설정 옵션 및 펌웨어 업데이트 프로세스에 대한 자세한 지침을 확인하세요.

- [직렬 연결 구성](./setup-serial)
- [독립 실행형 모드](./standalone-mode/)
- [PCIe 모드](./pcie-mode)
