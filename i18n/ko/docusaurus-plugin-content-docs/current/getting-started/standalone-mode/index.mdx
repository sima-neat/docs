# 독립 실행 모드

DevKit을 독립 모드로 설정하려면 안정적이고 신뢰할 수 있는 연결을 보장하기 위해 직렬 연결과 네트워크 설정을 모두 구성해야 합니다. 직렬 인터페이스는 중요한 통신 링크 역할을 하며, 네트워크 연결 상태와 관계없이 DevKit과의 지속적인 상호 작용을 가능하게 합니다.

DevKit의 IP 주소는 다음 방법 중 하나를 사용하여 할당할 수 있습니다.

- 네트워크를 통해 자동 구성합니다.
- 개발자의 컴퓨터를 통해 자동 구성합니다.
- 수동으로 고정 IP 주소 설정.

적절한 방법을 선택하는 것은 특정 네트워크 환경과 연결 요구 사항에 따라 달라집니다.

## 구성 DevKit 네트워크 {#network}

기본적으로 DevKit 네트워크 인터페이스는 DHCP를 사용합니다.

- 컴퓨터에 DevKit을 직접 연결하려면 컴퓨터의 네트워크 인터페이스를 정적 IP 주소로 구성한 다음 DevKit에 직접 연결하세요.
- DevKit이 네트워크에서 IP 주소를 자동으로 얻도록 하려면 인터페이스 설정을 변경하여 DHCP를 사용하도록 해야 합니다.

**현재 IP 주소 확인**

시리얼 콘솔에서 다음 명령을 실행합니다.

```console
sima@modalix:~$ ip a | grep inet
   inet 127.0.0.1/8 scope host lo
   inet6 ::1/128 scope host noprefixroute
   inet 192.168.91.181/22 brd 192.168.91.255 scope global dynamic noprefixroute end0
   inet6 fe80::ab34:b995:9f6e:160e/64 scope link noprefixroute
```

<TabItem value="linux-shell" label="Network Setup In The Linux Shell" default>

:::note
장치를 재부팅하지 않고 정적 IP 주소와 DHCP 간에 설정을 전환하려면 다음 지침을 따르세요.
:::

DevKit에 `sima-cli`가 설치되어 있고, 재부팅 없이 DHCP와 정적 구성 간을 동적으로 전환하려는 경우 다음 명령을 실행하세요.

```console
davinci:~$ sima-cli network
```

정적 및 DHCP 네트워크 구성 간 전환을 위해 대화형 메뉴가 표시됩니다.

`sima-cli`가 사용할 수 없는 경우, 미리 구성된 연결 프로필인 `end0-static` 및 `end0-dhcp` 간 전환에 `nmcli`를 사용하십시오.

:::note
다음 지침에서는 `NetworkManager` 프로필을 사용하여 네트워크 인터페이스를 구성하고, eLxr 2.1 이상을 실행하는 DevKit 시스템에 적용합니다. 시스템에서 이전 버전을 실행 중인 경우, [v2.0.0 버전 문서](https://docs.sima.ai/v2.0.0/pages/overview/setup_standalone_mode/setup_network.html#network-setup-in-the-linux-shell)을 참조하십시오.
:::

**고정 IP로 전환**

네트워크 인터페이스를 DHCP에서 고정 IP로 변경하려면 다음 명령을 실행합니다.

```console
davinci:~$ sudo nmcli connection up end0-static
davinci:~$ nmcli -f NAME,DEVICE,STATE connection show --active
davinci:~$ networkctl status
```

**DHCP로 전환**

네트워크 인터페이스를 고정 IP에서 DHCP로 변경하려면 다음 명령을 실행합니다.

```console
davinci:~$ sudo nmcli connection up end0-dhcp
davinci:~$ nmcli -f NAME,DEVICE,STATE connection show --active
davinci:~$ networkctl status
```

:::note
- DevKit에서 이더넷 연결을 사용할 수 없는 개발자 네트워크 환경에 적합합니다.
- DevKit을 개발자 컴퓨터의 이더넷 포트에 연결합니다. 개발자 컴퓨터에 이더넷 포트가 없는 경우 USB-이더넷 어댑터를 사용하십시오.
- 컴퓨터는 DevKit와 인터넷을 공유할 수 있으며, 이를 통해 `pip`를 사용하여 Python 패키지를 설치할 수 있습니다.
- 호스트 컴퓨터에서 인터넷 연결 공유 기능을 활성화해야 합니다.
:::

1. 다음은 Ubuntu 시스템에 대한 지침입니다. 다른 플랫폼에서는 지침이 다를 수 있으므로, 네트워크 연결을 공유하는 방법에 대한 관련 지침을 온라인에서 찾아보시기 바랍니다.

   - 오른쪽 상단에서 `Settings`를 열고, `Network` 섹션으로 이동합니다.
   - `Wired`에서, 보드에 대한 기존 설정 프로필이 없는 경우 더하기 기호를 클릭하여 새 설정 프로필을 만들거나, 기존 프로필이 있는 경우 해당 프로필을 수정합니다.
   - 새 프로필을 만들고 있다면, 이름을 "공유" 또는 원하는 다른 이름으로 지정하세요.
   - `IPv4` 탭에서 `Shared to other computers`를 선택합니다. 적용을 클릭합니다.
   - 기존 연결이 되어 있다면, 연결을 껐다가 다시 켜서 변경 사항을 적용하세요.
   - 이제 컴퓨터가 AP와 네트워크로 연결되어 있어야 합니다. `10.42.0.0/24`는 Ubuntu에서 이 설정을 위해 사용하는 기본 서브넷이지만, 컴퓨터는 다른 서브넷을 사용할 수도 있습니다.
   - 다음 단계에서 결과가 나오지 않으면 `ifconfig`를 실행하고 이더넷 인터페이스(일반적으로 `eth0`)의 IP 주소를 확인합니다.

2. Ubuntu 시스템에서 터미널을 엽니다. 다음 명령을 입력하여 해당 IP 범위 내의 장치를 검색합니다.

   ```console
   sima-user@sima-user-machine:~$ nmap -sn 10.42.0.0/24 | grep report
      Nmap scan report for sima-user-machine (10.42.0.1)
      Nmap scan report for 10.42.0.241
   ```

   이 목록은 이 서브넷에서 사용되는 IP 주소를 보여줍니다. `.1`로 끝나는 주소는 호스트 머신입니다. `.1`로 끝나지 않는 주소는 SiMa DevKit의 IP 주소입니다. 위의 예에서 보드 주소는 `10.42.0.241`이고 호스트 주소는 `10.42.0.1`입니다.

3. 다음 명령을 실행하여 연결을 테스트합니다.

   ```console
   sima-user@sima-user-machine:~$ ssh sima@10.42.0.241
   ...
   Last login: Mon Nov 27 19:58:33 2023
   davinci:~$
   ```

4. 보드에서 호스트에 연결할 수 있는지 확인하려면 보드에서 `10.42.0.1`으로 핑을 보내세요. 호스트에서 SSH 서버를 실행 중인 경우 SSH를 통해서도 연결할 수 있습니다.

   ```console
   davinci:~$ ping 10.42.0.1
      PING 10.42.0.1 (10.42.0.1): 56 data bytes
      64 bytes from 10.42.0.1: seq=0 ttl=64 time=0.598 ms
      64 bytes from 10.42.0.1: seq=1 ttl=64 time=0.703 ms
      64 bytes from 10.42.0.1: seq=2 ttl=64 time=0.639 ms
      ^C
      --- 10.42.0.1 ping statistics ---
      3 packets transmitted, 3 packets received, 0% packet loss
      round-trip min/avg/max = 0.598/0.646/0.703 ms
   ```

5. 보드에 핑을 보내거나 SSH로 접속할 수 없는 경우, 고정 IP 구성 방법을 사용하십시오.

<TabItem value="uboot" label="Network Setup In The U-Boot Shell">

:::note
이 절차는 DevKit 펌웨어 버전 2.0 이하에만 적용됩니다. 버전 2.1 이상에서는 사용자가 Linux 측 설정을 활용할 수 있습니다. U-Boot에서 네트워크를 구성하면 펌웨어 업그레이드 시에도 네트워크 설정이 유지됩니다.
:::

1. UART를 통해 DevKit에 연결하고, [시리얼 터미널](/hardware/getting-started/setup-serial)을 사용하세요.
2. DevKit을 재부팅하십시오.
3. 메시지가 표시되면 아무 키나 눌러 U-Boot로 들어가십시오. 메시지는 다음과 같습니다: `Hit any key to stop autoboot`.

4. 고정 IP 주소로 전환하려면 다음 명령을 입력하세요.

   ```console
   sima:~$ env set forcenetcfg static; saveenv
   sima:~$ boot
   ```

5. 보드는 재부팅되며 첫 번째 및 두 번째 이더넷 포트에 대해 각각 `192.168.1.20` 및 `192.168.2.20`를 사용합니다.
6. 보드의 고정 IP 주소를 변경하려면 네트워크 파일을 사용하여 수정하십시오. `vi` 장치가 부팅된 후.

   ```console
   davinci:~$ sudo vi /etc/systemd/network/20-end0-static.network
   ```

7. **네트워크** 섹션에서 필요에 따라 IP 주소를 업데이트하세요.
8. DHCP 모드를 구성하려면 아래 명령을 입력하고 보드를 재부팅하십시오.

   ```console
   sima:~$ env set forcenetcfg dhcp; saveenv
   sima:~$ boot
   ```

## NVMe 스토리지를 구성합니다. {#nvme}

**Modalix DevKit**에는 500GB NVMe (비휘발성 메모리 익스프레스) 드라이브가 포함되어 있습니다.
더 많은 용량이 필요한 개발자는 기본적으로 설치된 드라이브를 호환되는 M.2 NVMe 모듈로 교체하여 캐리어 보드에 직접 설치할 수 있습니다.

:::note
계속하기 전에 `sima-cli`를 설치하거나 최신 버전으로 업데이트하십시오. 이 설명서는 최신 버전의 `sima-cli`와 함께 사용하기 위한 것입니다.
:::

:::note
이 명령어는 Modalix DevKit에서 직접 실행해야 합니다.
:::

`sima-cli`를 설치한 후에는 다음 명령어를 사용하여 NVMe 드라이브를 포맷할 수 있습니다.

```console
modalix:~$ sima-cli nvme format
```

포맷 후 NVMe 드라이브가 `/media/nvme`에 자동으로 마운트됩니다.

마운트 상태를 확인하고 저장 공간 사용량을 보려면 다음 명령을 실행하세요.

```console
modalix:~$ df -h
```

이 명령어는 모든 마운트된 파일 시스템의 사용 가능한 디스크 공간을 표시하며, 여기에는 NVMe 드라이브가 포함됩니다.

NVMe 드라이브를 다시 마운트해야 하는 경우, 다음 명령을 실행합니다.

```console
modalix:~$ sima-cli nvme remount
```

`format` 및 `remount` 명령은 모두 `/etc/fstab` 파일에 항목을 자동으로 추가하므로, NVMe 드라이브는 항상 자동으로 마운트됩니다.

## MIPI 인터페이스를 구성합니다. {#mipi}

:::note
계속하기 전에 `sima-cli`를 설치하거나 최신 버전으로 업데이트하십시오. 이 설명서는 최신 버전의 `sima-cli`와 함께 사용하기 위한 것입니다.
:::

:::note
이 절차를 수행하려면 최신 버전의 sima-cli가 설치된 호스트 머신이 필요합니다. 또한 **Modalix 개발 키트**의 펌웨어 버전은 `1.7.0_master_B1965` 이상이어야 합니다. 이는 해당 빌드에 MIPI를 지원하는 데 필요한 `.dtbo` 파일이 포함되어 있기 때문입니다.
:::

**Modalix DevKit**에는 장치에 입력으로 연결할 MIPI 카메라를 연결하기 위한 두 개의 MIPI 인터페이스가 포함되어 있습니다. MIPI 포트는 캐리어 보드에 직접 위치하며, 개발자는 이를 활성화하기 위해 아래 절차를 따라야 합니다.

시작하기 전에 **Modalix Devkit**가 꺼진 상태에서 MIPI 카메라를 MIPI 포트 중 하나에 연결했는지 확인하십시오.

연결되면 호스트 장치에서 직렬 케이블을 **Modalix Devkit**에 연결합니다. 그 후 **Modalix Devkit**를 켭니다.

다음으로, `sima-cli`를 사용하여 직렬 터미널을 설정하고 3초 카운트다운 중에 아무 키나 눌러 즉시 `uboot`로 들어갑니다.

```console
sima-cli serial -b 115200
...
Hit any key to stop autoboot:  0
sima$
```

uboot 환경에서 `dtbos` 변수를 적절한 **장치 트리 블롭 오버레이**(`.dtbo`) 파일로 설정합니다. 올바른 파일은 **캐리어 보드**, **카메라 제조업체**, **센서 유형** 및 **카메라 포트**에 따라 달라집니다. 그 후 환경을 저장하고 운영 체제로 부팅합니다.

파일 이름은 다음 패턴을 따릅니다.

```text
modalix-som-<carrier_board>-<camera_manufacturer>-<sensor_type>-<port>CAM.dtbo
```

하드웨어에 따라 각 구성 요소를 선택하세요.

| 구성 요소 | 가치 | 설명 |
| --- | --- | --- |
| 캐리어 보드 | `connectech`, `seeedstudio`, `waveshare` | 캐리어 보드 모델 |
| 카메라 제조업체 | `ARDU`, `ECON`, `LI` | Arducam, e-con Systems 또는 Leopard Imaging |
| 센서 유형 | `IMX477`, `IMX568`, `IMX678`, `AR0234`, `OG05C10` | 카메라 센서 모델 |
| 포트 | `0CAM`, `1CAM`, `2CAM`, `3CAM`, `DUAL` | 카메라가 연결된 MIPI 포트 번호 |

예를 들어, Leopard Imaging의 IMX477 센서가 포트 0에 연결된 Connectech 캐리어 보드를 생각해 볼 수 있습니다.

```console
sima$ setenv dtbos modalix-som-connectech-LI-IMX477-0CAM.dtbo ; saveenv ; boot
```
