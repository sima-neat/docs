# 독립 실행 모드

독립 모드에서 Modalix DevKit은 자체적으로 작동하는 엣지 장치로 실행됩니다. 센서, 카메라, 스토리지 또는 네트워크 인터페이스에서 데이터를 수신하고, 로컬에서 처리한 다음 결과를 네트워크를 통해 전송합니다.

DevKit이 PCIe 카드로 호스트 장치에 설치되지 않은 경우 이 섹션을 사용하십시오.
