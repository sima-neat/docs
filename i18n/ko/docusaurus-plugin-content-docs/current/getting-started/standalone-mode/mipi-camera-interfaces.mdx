# MIPI 카메라 인터페이스

:::note
계속하기 전에 `sima-cli`를 설치하거나 최신 버전으로 업데이트하십시오. 이 설명서는 최신 `sima-cli` 버전을 사용하는 것을 기준으로 작성되었습니다.
:::

:::note
이 절차를 수행하려면 최신 버전의 `sima-cli`가 설치된 호스트가 필요합니다. 또한 MIPI 지원을 위한 `.dtbo` 파일이 포함된 **Modalix DevKit** 펌웨어 버전이 필요합니다.
:::

**Modalix DevKit**에는 카메라 입력을 위한 두 개의 MIPI 인터페이스가 포함되어 있습니다. MIPI 포트는 캐리어 보드에 있습니다.

시작하기 전에 **Modalix DevKit**의 전원을 끄고 MIPI 카메라를 MIPI 포트 중 하나에 연결합니다.

호스트에서 **Modalix DevKit**에 시리얼 케이블을 연결한 다음, DevKit의 전원을 켭니다.

`sima-cli`를 사용하여 시리얼 터미널을 열고 3초 카운트다운 중에 아무 키나 눌러 U-Boot로 들어갑니다.

```console
sima-cli serial -b 115200
...
Hit any key to stop autoboot:  0
sima$
```

U-Boot에서 `dtbos` 변수를 적절한 **장치 트리 블롭 오버레이**(`.dtbo`) 파일로 설정합니다. 올바른 파일은 **캐리어 보드**, **카메라 제조업체**, **센서 유형** 및 **카메라 포트**에 따라 달라집니다. 그런 다음 환경을 저장하고 운영 체제로 부팅합니다.

파일 이름은 다음 패턴을 따릅니다.

```text
modalix-som-<carrier_board>-<camera_manufacturer>-<sensor_type>-<port>CAM.dtbo
```

하드웨어에 따라 각 구성 요소를 선택하세요.

| 구성 요소 | 가치 | 설명 |
| --- | --- | --- |
| 캐리어 보드 | `connectech`, `seeedstudio`, `waveshare` | 캐리어 보드 모델 |
| 카메라 제조업체 | `ARDU`, `ECON`, `LI` | 아듀캠, 이콘 시스템즈 또는 레오파드 이미징 |
| 센서 유형 | `IMX477`, `IMX568`, `IMX678`, `AR0234`, `OG05C10` | 카메라 센서 모델 |
| 포트 | `0CAM`, `1CAM`, `2CAM`, `3CAM`, `DUAL` | 카메라에 연결된 MIPI 포트 번호 |

예를 들어, Leopard Imaging의 IMX477 센서가 포트 0에 연결된 Connectech 캐리어 보드는 다음과 같습니다.

```console
sima$ setenv dtbos modalix-som-connectech-LI-IMX477-0CAM.dtbo ; saveenv ; boot
```

인터페이스를 확인하려면 Modalix DevKit을 디스플레이에 연결하고 로그인합니다. 그런 다음 libcamera를 사용하여 카메라 연결을 확인합니다.

1. 사용 가능한 카메라 목록:

   ```console
   sima@modalix:~$ cam -l
   ```

2. 카메라 1에 대해 다른 카메라 형식을 표시합니다.

   ```console
   sima@modalix:~$ cam -c 1 -I
   ```

3. 카메라 1에서 이미지를 캡처합니다.

   ```console
   sima@modalix:~$ rm -rf frame* && cam -c 1 --capture=1 -F -s pixelformat=NV12
   ```
