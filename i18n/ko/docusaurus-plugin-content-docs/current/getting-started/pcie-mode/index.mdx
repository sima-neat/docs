# PCIe 모드

PCIe 모드에서는 Modalix PCIe 카드를 호스트 머신에 설치하고 Modalix 추론 가속을 PCIe를 통해 제공합니다. 호스트는 오케스트레이션, 스토리지 및 I/O를 처리하고, 카드는 추론 워크로드를 처리합니다.

Modalix 하드웨어가 독립 실행형 DevKit로 실행되는 대신 PCIe 카드로 설치된 경우 이 섹션을 사용하십시오.
