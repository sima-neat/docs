# 하드웨어 준비

:::note
계속하기 전에 `sima-cli`를 설치하거나 최신 버전으로 업데이트하십시오. 이 설명서는 최신 `sima-cli` 버전을 사용하는 것을 기준으로 작성되었습니다.
:::

시작하기 전에:

- 지원되는 호스트 플랫폼: Ubuntu 22.04 LTS.
- Windows 10/11 호스트 지원은 현재 베타 테스트 단계에 있습니다.
- 호스트 시스템의 UEFI/BIOS 설정을 구성하여 PCIe 드라이버를 지원하도록 합니다.
  - 인텔 기반 시스템에서는 SRIOV, IOMMU 및 VT-D를 활성화하십시오.
  - AMD 기반 시스템에서는 AMD-V를 비활성화하고 IOMMU를 활성화하십시오.

## PCIe 카드를 준비합니다.

![ Modalix PCIe 카드 DIP 스위치](/img/devkit/pcie-dip-switch.png)

1. Modalix PCIe 카드에서 위 그림에 표시된 네 개의 DIP 스위치를 찾으세요. 스위치 #1이 `OFF` 위치에 있는지 확인하세요.
2. 실행/프로그램 스위치가 `ON`으로 설정되어 있는지 확인하십시오.
3. 호스트의 전원을 끄고, Modalix PCIe 카드를 PCIe 슬롯에 장착한 다음, 호스트의 전원을 켭니다.
4. 특별한 지시가 없는 한 DIP 스위치를 공장 기본 설정 위치에 그대로 두십시오.
5. 호스트 마더보드가 주 슬롯(파란색)과 보조 슬롯(검은색) PCIe 슬롯을 모두 제공하는 경우, Modalix PCIe 카드를 보조(검은색) 슬롯에 설치하십시오.
6. 카드의 시리얼/UART 커넥터를 호스트에 연결하여 시스템을 부팅하고 디버깅합니다.
7. PCIe 카드는 네트워크에 직접 연결할 수 있는 물리적인 이더넷 포트도 갖추고 있습니다.

PCIe 카드 인터페이스, 스위치 및 커넥터에 대한 자세한 내용은 [ Modalix PCIe 카드](/hardware/devkit/modalix-pcie-card)를 참조하십시오.

:::note
드물게 호스트가 재부팅될 때 드라이버가 자동으로 로드되지 않도록 하려는 경우가 있을 수 있습니다. 자동 로드를 비활성화하려면 `/etc/modprobe.d/blacklist.conf` 파일을 생성하거나 편집하고 `blacklist sima_mla_drv`를 추가합니다. 그런 다음 `update-initramfs`를 실행하고 호스트를 재부팅합니다. 재부팅 후에는 `insmod` 또는 `modprobe`를 사용하여 드라이버를 수동으로 로드합니다.
:::
