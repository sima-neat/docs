# 서드파티 캐리어 보드

Modalix SoM은 NVIDIA Jetson Orin NX 및 Orin Nano와 동일한 260핀 SODIMM 폼 팩터를
사용합니다. 따라서 이들 모듈용으로 제작된 캐리어 보드는 제품의 출발점이나 자체 설계의
참고 자료로 활용할 수 있습니다. 이 페이지에서는 그중 8개 보드의 인터페이스를 비교합니다.

:::warning 폼 팩터가 같다고 검증된 것은 아닙니다
SiMa.ai가 Modalix SoM 브링업을 수행한 보드는 Waveshare 보드뿐입니다. 나머지 보드는
폼 팩터를 기준으로 수록했으며 Modalix SoM으로 테스트하지 않았습니다. 연결하기 전에
SoM과 캐리어 보드 간의 전기적 핀 호환성을 확인하고, 디바이스 트리를 적응시켜야 한다는 점을
염두에 두십시오. [캐리어 보드 브링업](./som-carrier.mdx)을 참조하십시오.
:::

## 사양 읽는 방법

- 값은 각 벤더가 자사 보드에 대해 공개한 내용입니다. 보드 리비전은 변경되므로
  구매하기 전에 벤더의 최신 문서를 확인하십시오.
- 비교표의 대시(—) 또는 보드 사양에 항목이 없는 경우는 이 페이지에 해당 항목의
  값이 없음을 의미합니다. 보드에 해당 인터페이스가 없다는 뜻은 아닙니다.
- 캐리어 보드에 커넥터가 있다고 해서 해당 인터페이스가 Modalix SoM에서 동작하는 것은
  아닙니다. 어떤 인터페이스가 동작하는지는 SoM이 커넥터로 내보내는 신호와 디바이스 트리에
  따라 달라집니다.
  [캐리어 보드 브링업](./som-carrier.mdx) 및
  [저속 I/O](../interfaces/low-speed-io.mdx)를 참조하십시오.
- **Modalix SoM** 열은 각 인터페이스에 대해 SoM이 지원하는 내용을 보여 줍니다.
  *지원*은 SoM이 해당 인터페이스를 커넥터로 내보낸다는 뜻입니다.
  *캐리어 보드에 따라 다름*은 보드에 맞게 구성이나 소프트웨어를 변경해야 할 수
  있다는 뜻입니다. *지원되지 않음*은 캐리어 보드의 구성과 관계없이 해당 인터페이스가
  Modalix SoM에서 동작하지 않는다는 뜻입니다.
  *확인되지 않음*은 이 페이지에 정보가 없다는 뜻입니다.

## 사용 가능한 보드

보드 이름을 선택하면 해당 사양을 볼 수 있습니다. 주문 정보 열에는 이 페이지가 보유한
벤더 부품 번호와 벤더의 제품 페이지가 나와 있습니다.

수록된 보드는 Waveshare JETSON-ORIN-IO-BASE-H, AVerMedia D131L, Auvidea JNX40S, Connect Tech Boson-22, D3 Embedded DesignCore Jetson Orin NX 8-Camera GMSL2 Carrier Board, Diamond Systems JAX-BB01 (Jackson), Leopard Imaging LI-ONX-CB-4CAM-FP, Seeed Studio reComputer J401입니다.

Waveshare 보드는 레퍼런스 캐리어 보드입니다. 전체 구성 요소 목록은
[캐리어 보드 브링업](./som-carrier.mdx)에 있습니다.

:::caution 지원되는 모듈을 확인하십시오
Leopard Imaging은 LI-ONX-CB-4CAM-FP를 Jetson Orin NX 전용으로 명시하며, Jetson Orin Nano
모듈이 손상될 수 있다고 경고합니다. Modalix SoM을 연결하기 전에 벤더에 문의하십시오.
:::

## 보드 사양

보드를 추가하면 해당 사양을 볼 수 있습니다. 최대 4개의 보드를 추가하여 나란히 비교할 수 있으며,
×로 제거할 수 있습니다.

<CarrierBoardSpecs />

Modalix SoM Rev 2는 각각 2레인인 MIPI CSI 인터페이스 4개를 제공합니다.
독립된 2레인 컨트롤러 경로 두 개를 하나의 4레인 경로로 합칠 수 없으므로
4레인 MIPI CSI 연결은 지원하지 않습니다.
카메라 지원 여부는 센서 드라이버와 오버레이에도 좌우됩니다.
[MIPI 카메라 인터페이스](../getting-started/standalone-mode/mipi-camera-interfaces.mdx)를 참조하십시오.
