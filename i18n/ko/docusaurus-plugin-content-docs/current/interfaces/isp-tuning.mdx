# ISP 튜닝

MLSoC Modalix의 이미지 신호 프로세서(ISP)는 카메라 센서의 원시 데이터를 애플리케이션이
받는 영상으로 변환합니다. 카메라에서 프레임을 받는 것과 좋은 영상을 얻는 것은 별개의
단계입니다. 이 페이지에서는 튜닝이 무엇인지, 어떤 카메라가 이미 튜닝되어 있는지, 튜닝
가이드를 받는 방법을 설명합니다.

:::caution[하드웨어에서 아직 검증되지 않음]
이 페이지는 이 사이트의 다른 카메라 페이지와 플랫폼 릴리스 2.1.3의 커널 소스를 요약한
것입니다. 카메라 및 ISP 담당자의 검토는 아직 이루어지지 않았습니다.
:::

## 캡처와 튜닝 {#capture-and-tuning}

| | 캡처 | 화질 튜닝 |
| --- | --- | --- |
| 결과 | 보드가 카메라를 인식하고 카메라가 프레임을 출력함 | 프레임의 노출, 화이트 밸런스, 색상이 올바름 |
| 필요한 것 | 센서 드라이버와 디바이스 트리 오버레이 | 센서와 렌즈에 맞는 튜닝 데이터 |
| 시작 위치 | [MIPI 카메라 인터페이스](../getting-started/standalone-mode/mipi-camera-interfaces.mdx) | 「Modalix 카메라 및 ISP 튜닝 가이드」 |

ISP는 Arm Mali-C71입니다.

## 이미 튜닝된 카메라 {#tuned-cameras}

플랫폼 릴리스는 [지원되는 MIPI 카메라](./supported-cameras.mdx)에 있는 카메라, 즉
Arducam IMX477, e-con Systems IMX568 및 IMX678, Leopard Imaging AR0234 및 OG05C10에
맞게 튜닝되어 있습니다. 이 카메라 중 하나를 사용한다면 시작하기 위해 ISP를 튜닝할 필요가
없습니다.

## 튜닝이 필요한 경우 {#when}

- 위 목록에 없는 센서를 사용하는 경우.
  [자체 카메라 통합](./custom-camera.mdx)을 참조하십시오.
- 지원되는 센서를 다른 렌즈 또는 카메라 모듈과 함께 사용하는 경우.
- 지원되는 카메라의 화질이 애플리케이션의 요구 사항을 충족하지 못하는 경우.

## 튜닝 가이드 받기 {#tuning-guide}

「Modalix 카메라 및 ISP 튜닝 가이드」는 카메라에 맞게 ISP를 튜닝하는 방법을 설명합니다. 이 가이드는
요청 시 제공됩니다.
[참고 자료](../reference/extra-docs.md)를 참조하십시오.

카메라 튜닝에 대해 SiMa.ai에 문의하려면 SiMa.ai 담당자에게 연락하거나
[SiMa.ai 문의 페이지](https://sima.ai/contact/)를 이용하십시오.
