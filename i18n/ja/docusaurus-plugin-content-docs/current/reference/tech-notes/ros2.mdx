# Modalix SOM Devkit に ROS2 をインストールします。

この技術資料では、[ロボットオペレーティングシステム 2 (ROS 2)](https://docs.ros.org/)をModalix SOM DevKitにインストールする方法と、なぜROS 2が、物理的なAIワークロードのためのSiMa.aiシリコンにとって貴重なパートナーとなるのかを説明します。

## ROS 2とは何ですか？

ROS 2 は、第 2 世代のロボットオペレーティングシステムであり、ロボットおよび物理的な AI アプリケーションを構築するためのオープンソースのソフトウェアライブラリとツールのセットです。 単一のオペレーティングシステムではなく、ROS 2 は、Linux 上で動作するミドルウェア層であり、ロボット内の多数の独立したプロセス（センサー、アクチュエーター、知覚モデル、プランナー、コントローラーなど）が互いを見つけ、データを交換するための標準的な方法を提供します。

主な機能は次のとおりです。

- **ノードベースのアーキテクチャ。** 各機能（カメラドライバ、検出器、モーターコントローラ、SLAMスタックなど）は、独立した*ノード*として実行されます。ノードはランタイム時に構成されるため、同じ認識ノードを、非常に異なるロボット間で再利用できます。
- **DDSベースの通信。** ROS 2 は、リアルタイムのピアツーピアのパブリッシュ/サブスクライブメッセージングを実現するために、Data Distribution Service（DDS）標準を基盤として構築されており、Quality-of-Service（信頼性、持続性、期限、生存性）を構成可能にすることで、安全性が重要で時間的制約のあるロボット工学において必須となる要件を満たします。
- **標準メッセージタイプ。** 一般的なメッセージ定義を多数収録したカタログ（`sensor_msgs`、`geometry_msgs`、`nav_msgs`、`vision_msgs`など）により、異なるベンダーの知覚、計画、制御コンポーネントが、カスタムの連携コードなしで相互運用できるようになります。
- **クロスプラットフォームに対応し、リアルタイム処理に適している。** ROS 2 は Linux 上で動作し、ARM64 および x86_64 をサポートしており、リアルタイムカーネルやマイクロコントローラースタック（micro-ROS）と連携して動作するように設計されています。
- **充実したツール群のエコシステム。** 3D可視化のための`rviz2`、システムの状態確認のための`rqt`、センサーデータの記録と再生のための`rosbag2`、そして宣言的なシステム起動のための`ros2 launch`。

## なぜ、ROS 2をModalix SOM上で実行するのか？

物理的なAI、つまり自律移動ロボット、ドローン、ロボットアーム、AMR（自律移動ロボット）、アクチュエーターを備えたスマートカメラには、**高い処理能力を持つニューラル推論**と、センサー、制御、安全のための**決定論的で、十分に理解されたソフトウェア基盤**の両方が必要です。Modalix SOMは、まさにその組み合わせを実現するために開発されました。

- **知覚処理をMLAにオフロードし、ROS 2をArmコア上で実行します。** 知覚ノード（物体検出、セグメンテーション、深度、姿勢、BEVフュージョン）は、MLSoCのMLAを呼び出すことができ、ROS 2パブリッシャーは、その結果を標準の`vision_msgs`または`sensor_msgs`として転送します。独自のIPCは不要です。
- **1つのボードで、フルスタックを実現。** カメラからの画像入力、機械学習による推論、ROS 2ミドルウェア、計画、モーター制御など、これらすべてを同じModalix SOM上で実行することで、別途用意する必要がある補助コンピューティングボードによる遅延や部品コストを削減できます。
- **電力効率の高いエッジ デプロイ。** Modalix のワットあたりの性能により、バッテリー駆動のプラットフォーム（ドローン、AMR、携帯型検査装置）は、熱による性能低下なしに、最新の検知および追跡モデルをリアルタイムで実行できます。
- **eLxr Debianベース。** Modalix SOMは、eLxr Debianをベースとしたランタイムで動作するため、標準のROS 2 `apt`パッケージを問題なくインストールできます。一般的なケースでは、クロスコンパイルやカスタムのYoctoレイヤーは必要ありません。

## 前提条件

:::info
Modalix SOM に ROS 2 をインストールするには、eLxr ランタイム上で動作する SDK バージョン **2.1.0** 以降が必要です。ランタイムの確認または変換については、[eLxr に変換](./elxr-conversion) を参照してください。
:::

また、以下のものも必要になります。

- A Modalix SOM DevKit 電源が投入され、ネットワークまたはシリアルコンソール経由でアクセスできる状態。
- `sima-cli` が DevKit にインストールされました。
- パッケージのダウンロードには、DevKit がインターネットに接続されている必要があります。

## ROS 2 をインストールします。

`sima-cli` は、Modalix SOM に適したバージョンの ROS 2 をダウンロードし、apt ソースを設定し、基本的なパッケージと標準ツールをインストールする、ワンステップのインストーラーを提供します。

<details open>
<summary><strong>ステップ1：sima-cliを使用して、ROS 2をインストールします。</strong></summary>

Modalix シェルから、次のコマンドを実行します。

```console
sima@modalix:~$ sima-cli install tools/ros2
```

インストーラーは次の処理を行います。

- 必要な Debian `bookworm` および ROS 2 の apt リポジトリと、ROS の署名キーを追加します。
- SOM上でROS 2ノードをビルドおよび実行するために必要な、ビルド依存関係（`cmake`、`colcon`、`vcstool`）、QtおよびOpenCVの開発パッケージ、GStreamerプラグインセット、およびその他のライブラリをインストールします。
- `ros2`と`colcon`のパッケージをインストールしてください。
- `source /usr/local/ros2/local_setup.bash` を `/home/sima/.bash_profile` に追加し、ログインするたびに ROS 2 環境が自動的に読み込まれるようにします。そして、現在のシェルでそれを実行します。

</details>

<details open>
<summary><strong>手順2：インストールを確認します。</strong></summary>

`sima-cli install tools/ros2` の実行が完了すると、現在のシェルで既に ROS 2 環境が設定されます。`ros2` CLI がパスに含まれていることを確認してください。

```console
sima@modalix:~$ ros2
```

次に、2つのシェルにまたがって標準の「発信者/受信者」デモを実行し、DDSミドルウェアがエンドツーエンドで正常に機能することを確認します。

```console
sima@modalix:~$ ros2 run demo_nodes_cpp talker
```

同じデバイス上で、別のシェルを起動します。

```console
sima@modalix:~$ ros2 run demo_nodes_py listener
```

リスナーは、トークがメッセージを公開するたびに、`I heard: [Hello World: N]` メッセージを出力する必要があります。ROS 2 は、Modalix SOM上で、SiMa.ai の機械学習パイプラインとともに、知覚、計画、制御ノードをホストする準備が整いました。

</details>
