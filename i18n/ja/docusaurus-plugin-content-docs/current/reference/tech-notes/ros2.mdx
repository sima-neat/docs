# ROS 2 を Modalix SoM DevKit にインストールします。

ROS 2は、ロボットアプリケーション用のライブラリとツールを提供します。これにより、センサー、知覚、計画、制御の各プロセス間でデータの交換が可能になります。Modalix SoMでは、ROS 2がArmコア上で実行されます。知覚アプリケーションは、ニューラルネットワーク推論にMLAを使用できます。

## 始める前に

必要なもの：

- プラットフォームバージョン **3.0 以降**、または **2.1.x** の Modalix SoM DevKit。
- DevKit にインストールされた `sima-cli`。
- DevKitでパッケージをダウンロードするために、インターネットに接続してください。
- SSHまたはシリアル接続を介して、DevKitに接続します。

以下のすべてのコマンドを**DevKit**上で実行してください。

## 1. プラットフォームのバージョンを確認してください。

ファームウェア情報を確認してください。

```bash
cat /etc/buildinfo
```

以下のプラットフォームバージョンに対応したインストールコマンドを使用してください。

バージョン2.1.xから3.0.0に移行するには、まず[2.1.3 から 3.0.0 にバージョンアップします。](./convert-2-1-3-to-3-0-0.md)の手順に従ってください。

## 2. ROS 2 をインストールします。

### プラットフォーム 3.0 以降

実行：

```bash
sima-cli neat install ros@v3.0.0
```

画面の指示に従ってインストールを完了し、ROS 2 環境を設定してください。

### プラットフォーム 2.1.x

実行：

```bash
sima-cli install tools/ros2
```

インストーラーは、Debian BookwormとROS 2のパッケージソースを追加します。ROS 2、ビルドツール、および必要なライブラリをインストールします。また、将来のログインのために、ROS 2の環境設定を`/home/sima/.bash_profile`に追加します。

現在のシェルで環境を読み込むには、次を実行します。

```bash
source /usr/local/ros2/local_setup.bash
```

## 3. インストール状況を確認してください。

このチェックで使用する各シェルで、ROS 2 環境が読み込まれていることを確認してください。

1. ROS 2 コマンドが利用可能かどうかを確認してください。

   ```bash
   ros2
   ```

2. 1つのシェルでトーカーを開始します。

   ```bash
   ros2 run demo_nodes_cpp talker
   ```

3. 同じ DevKit 上で、別のシェルを開きます。
4. リスナーを開始します。

   ```bash
   ros2 run demo_nodes_py listener
   ```

リスナーは、「`I heard: [Hello World: 1]`」のようなメッセージを出力します。これらのメッセージは、発話者とリスナーがデータを交換できることを示します。

デモを停止するには、各シェルで**Ctrl+C**を押してください。
