# eLxr に変換

このガイドでは、既存の SiMa.ai **Yocto ベースの DevKit** を **eLxr** ランタイム環境に変換し、必要に応じて Yocto に戻す方法を説明します。

:::note
eLxrプラットフォームは、SDK **2.0.0** 以降のバージョンから、**Modalix DevKit** で利用できます。

eLxr への変換には、tRoot の更新と eMMC の再フラッシュが必要であり、これらは [ネットワークブートによる復旧](/hardware/getting-started/firmware-update/net-boot) によって行われます。

Windows ホストでは、**Windows Subsystem for Linux (WSL)** 上の Ubuntu に `sima-cli` をインストールして実行します。ネイティブ Windows での NetBoot には対応していません。[WSL のネットワーク設定](/hardware/getting-started/firmware-update/net-boot#windows-hosts)を参照してください。
:::

**eLxr** プラットフォームは、従来の Yocto 環境に代わり、SiMa.ai DevKit のデフォルトのランタイムとして機能します。このプラットフォームは、以下の機能を提供します。

- **簡素化されたアップデート** — より大きなルートファイルシステムを備え、統一されたルートファイルシステムレイアウトに変更。
- **標準パッケージマネージャー** — Debianをベースとした、継続的なパッケージ管理機能を提供する基盤。

移行する前に、DevKit がどのファームウェアで動作しているかを確認してください。シリアルポートまたは SSH を介して接続し、次のコマンドを実行します。

```bash
cat /etc/buildinfo | grep DISTRO
```

以下のいずれかの表示になるはずです。

```text
DISTRO = poky
```

または

```text
DISTRO = eLxr
```

`poky` が表示された場合は、以下の手順に従って移行してください。

<details open>
<summary> <strong> ステップ1：最新のtRootに更新 </strong> </summary>

eLxr に変換する前に、DevKit を最新の **tRoot** イメージに更新してください。

この更新により、tRoot（信頼されたルート）が eLxr と互換性を持つようになります。

ホストのIPアドレスを静的IPアドレス `192.168.1.10` に設定し、DevKit が `192.168.1.20` でアクセスできるようにします（[ ネットワーク設定 ](/hardware/getting-started/standalone-mode/network) を参照）。

<img src={useBaseUrl('/img/media/host-cli.png')} alt="ホストマシンで実行" width="55" style={{float: 'left', marginRight: '8px'}} />

```bash
sima-user@sima-user-machine:~$ sima-cli update --ip 192.168.1.20 %platform_version% --troot_only
```

アップデートが正常に完了したら、変更を適用するために **DevKit の電源を入れ直します**。

</details>

<details open>
<summary><strong>手順2：Netboot を使用して eLxr eMMC にイメージを書き込み、フラッシュを実行します。</strong></summary>

変換の残りの手順では、[ネットワークブートによる復旧](/hardware/getting-started/firmware-update/net-boot)に記載されている標準の TFTP ネットブートおよびフラッシュ手順を使用します。以下に示す eLxr 固有の値を使用して、その手順に従ってください。

- **手順2（TFTPサーバーの起動）：** `--boardtype modalix --fwtype elxr -v %platform_version%` を使用します。
- **手順 3（U-Boot の設定）:** リモートで設定できない場合は、復旧ガイドに従ってシリアルコンソールからブートスクリプトを読み込みます。
- **手順 4（書き込み）:** 手動で書き込む場合は、`netboot>` プロンプトで `f` と入力し、書き込みが完了したら再起動を承認します。

![接続図](/img/tech-notes/conversion-diagram.png)

*接続図*

DevKit の再起動後は、eMMC から **eLxr** が起動します。

</details>

<details open>
<summary><strong>ステップ3：Palette SDKをインストールし、アプリケーションを試す</strong></summary>

DevKitでeLxrを実行している状態で、Palette SDKをインストールし、サンプルアプリケーションを実行します。インストールとアプリケーションの実行については、[Palette SDK ドキュメント](https://developer.sima.ai/software)を参照してください。

</details>

<details open>
<summary><strong>Yoctoに戻す（オプション）</strong></summary>

Yocto に戻すには、`--fwtype yocto` と対象の Yocto ファームウェアバージョンを指定し、[ネットワークブートによる復旧](/hardware/getting-started/firmware-update/net-boot)の手順をもう一度実行します。

:::note
Yocto に戻して変換する際に、**tRoot の最小バージョン要件はありません**。したがって、上記のステップ 1 は省略できます。

eLxr に変換した後、シリアルコンソールに NFS 関連のエラーメッセージが表示された場合、それらは無視しても問題ありません。
:::

</details>

## 要約

1. 最新の **tRoot** イメージ（バージョン 2.0.0 以上）に更新してください。
2. `--fwtype elxr` を指定し、[ネットワークブートによる復旧](/hardware/getting-started/firmware-update/net-boot)に従って eLxr を eMMC に書き込みます。
3. Palette SDKをインストールし、[Palette SDK ドキュメント](https://developer.sima.ai/software)を参照して、アプリを試してみてください。
