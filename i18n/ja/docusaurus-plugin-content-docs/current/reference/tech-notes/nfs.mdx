# NFS を設定する

大規模なデータセットやモデルファイルを使用する場合、スムーズなデモや開発体験を実現するためには、高速かつ効率的なファイルアクセスが不可欠です。

NFS（ネットワークファイルシステム）を使用すると、Ubuntuマシン（サーバー）とModalix DevKit（クライアント）間でシームレスなファイル共有が可能になり、ローカルコピーを必要とせずに、大規模なストレージに直接アクセスできます。

:::note
NFS は、特に DevKit に高速かつ大容量のストレージ（NVMe など）が搭載されていない場合に役立ちます。これは、MLSoC や Modalix Early Access Kit (EA) などのプラットフォームにも当てはまり、SD カードのみに依存すると、読み込み時間が遅くなる可能性があります。
:::

NFS は、特に次のような場合に役立ちます。

- 大規模なモデルやデータセットは、複数のデバイス間で共有する必要があります。
- クライアント側のローカルストレージには制限があるか、利用できません。
- 集中型のストレージ管理を行うことで、更新作業を簡素化できます。

<details open>
<summary><strong>ステップ1：NFSサーバーのセットアップ</strong></summary>

1. **NFSカーネルサーバーをインストールします**：

   ```bash
   sima-user@sima-user-machine:~$ sudo apt update
   sima-user@sima-user-machine:~$ sudo apt install -y nfs-kernel-server
   ```

2. **共有ディレクトリを作成する**:

   Modalix DevKit と共有するディレクトリを選択してください。

   ```bash
   sima-user@sima-user-machine:~$ sudo mkdir -p /mnt/nfs_share
   sima-user@sima-user-machine:~$ sudo chmod 777 /mnt/nfs_share
   ```

3. **NFS エクスポートファイルを編集します**：

   エクスポートファイルを**開く**：

   ```bash
   sima-user@sima-user-machine:~$ sudo nano /etc/exports
   ```

   次の行を末尾に追加し、`<modalix_ip>` を Modalix DevKit の IP アドレスに置き換えてください。

   ```
   /mnt/nfs_share <modalix_ip>(rw,sync,no_subtree_check)
   ```

   ネットワーク内のすべての IP からのアクセスを許可したい場合（テスト目的の場合）、次のように設定します。

   ```
   /mnt/nfs_share *(rw,sync,no_subtree_check)
   ```

4. **変更を適用し、NFSサービスを再起動します**:

   ```bash
   sima-user@sima-user-machine:~$ sudo exportfs -a
   sima-user@sima-user-machine:~$ sudo systemctl restart nfs-kernel-server
   ```

</details>

<details open>
<summary><strong>ステップ2：NFSクライアントの設定</strong></summary>

1. **マウントポイントを作成する**:

   ```bash
   modalix:~$ sudo mkdir -p /mnt/
   ```

2. **NFS共有をマウントする**:

   `<server_ip>` を Ubuntu マシンの IP アドレスに置き換えてください。

   ```bash
   modalix:~$ sudo mount <server_ip>:/mnt/nfs_share /mnt/
   ```

3. **マウントの状態を確認してください**：

   NFS共有が正しくマウントされているか確認してください。

   ```bash
   modalix:~$ df -h | grep mnt
   ```

</details>

<details open>
<summary><strong>ステップ3：マウントを永続化する</strong></summary>

起動時に NFS 共有を自動的にマウントするには、Modalix で以下の手順を実行してください。

1. **mnt.mount ファイルを作成します**:

   ```bash
   modalix:~$ sudo vi /etc/systemd/system/mnt.mount
   ```

2. **この内容をファイルに追加し、必ず server_IP を Ubuntu マシンの IP アドレスに置き換えてください。**

   ```
   [Unit]
   Description=NFS Mount
   After=network-online.target
   Requires=network-online.target

   [Mount]
   What=<server_IP>:/mnt/nfs_share
   Where=/mnt/
   Type=nfs
   Options=defaults,_netdev

   [Install]
   WantedBy=multi-user.target
   ```

3. **保存して終了します。次に、設定をテストします。**

   ```bash
   modalix:~$ sudo systemctl daemon-reload
   modalix:~$ sudo systemctl enable mnt.mount
   modalix:~$ sudo systemctl start mnt.mount
   ```

</details>
