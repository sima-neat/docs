# 2.1.3から3.0.0にバージョンアップしてください。

この手順は、Modalix SoM DevKit および Modalix PCIe カード に適用されます。 ほとんどの新しいボードには、工場出荷時に 2.1.x ファームウェアがインストールされています。

リリース 2.1.x は、Debian 12 と互換性のあるシステムイメージを使用します。 リリース 3.0.0 では、Debian 13 に移行します。 また、OverlayFS、A/B イメージ、および SWUpdate のシステム変更も含まれます。

これらの変更により、3.0.0 システムイメージは 2.1 システムイメージと互換性がなくなります。 変換には、特別な更新手順が必要です。 まず、ボードを最新の **2.1.3** ファームウェアに更新します。 次に、**netboot** を使用してネットワーク経由でボードを起動し、3.0.0 イメージをストレージに書き込みます。

このドキュメントでは、以下の用語を使用します。

- **ボード**: SoM DevKit または PCIe カード。
- **ホスト**: TFTPサーバーを通じてブートイメージを提供する、UbuntuまたはmacOSコンピューター。
- **フラッシュ**: システムイメージをボードのストレージに書き込みます。

## 始める前に

- ボードから必要なファイルと設定をバックアップしてください。
- 2.1.3のアップデートを行う前に、ボードがインターネットに接続されていることを確認してください。
- CLIのアップデートやイメージのダウンロードのために、ホストがインターネットに接続されていることを確認してください。
- ホスト上で、**sima-cli 2.1.19 以降のバージョン**を使用してください。インターネットに接続されている環境であれば、`sima-cli` は自動的に最新バージョンに更新されます。
- ボードとホストの間にイーサネット接続を確立してください。
- 可能であれば、ボードを監視するためのシリアル接続を準備してください。

最新の `sima-cli` を **ホスト** にインストールするには、次を実行します。

```bash
curl -fsSL https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh | bash
```

## 1. ボードをバージョン2.1.3にアップデートしてください。

このセクションのコマンドは、**ボード上で**実行してください。

1. SSHまたはシリアル接続を使用してボードに接続します。
2. ファームウェアのバージョンを確認してください。

   ```bash
   cat /etc/buildinfo
   ```

   ボードに最新の **2.1.3** バージョンがインストールされている場合は、セクション 2 に進んでください。

3. 最新の `sima-cli` をインストールしてください。

   ```bash
   curl -fsSL https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh | bash
   ```

4. ファームウェアのアップデートを開始します。

   ```bash
   sima-cli update
   ```

5. 画面の指示に従って、最新の **2.1.3** バージョンをインストールしてください。
6. 指示されたらボードを再起動してください。
7. `/etc/buildinfo` を再度確認し、ボードがバージョン **2.1.3** で動作していることを確認してください。

## 2. ボードをホストに接続します。

インターネット共有機能を備えた有線イーサネット接続を推奨します。

1. ボードのイーサネットポートをホストに接続します。
2. ホストでインターネット共有を有効にします。
   - **Ubuntu**: [ネットワーク設定](/hardware/getting-started/standalone-mode/network) に記載されている、共有接続の手順に従ってください。
   - **macOS**: ボードに接続されているイーサネットインターフェースに対して、インターネット共有機能を有効にします。

あるいは、両方のシステムを同じネットワークに接続します。ホストはボードにアクセスできる必要があります。また、ボードはホストのTFTPサーバーにアクセスできる必要があります。

### ボードのIPアドレスを検索します。

インターネット共有が有効になっている場合、ホストはボードに IP アドレスを割り当てます。シリアルコンソールを使用して、このアドレスを確認してください。

1. ボードのシリアルポートをホストに接続します。[シリアル接続](/hardware/getting-started/setup-serial) を参照してください。
2. ホスト上でターミナルを開き、次のコマンドを実行します。

   ```bash
   sima-cli serial
   ```

3. ボードにログインしてください。
4. このコマンドを**ボード上で実行**してください。

   ```bash
   /sbin/ifconfig
   ```

5. ホストに接続されているイーサネットインターフェースを見つけてください。
6. `inet` の後に表示される IPv4 アドレスを記録してください。ループバックアドレス `127.0.0.1` は使用しないでください。
7. 別のターミナルで、**ホスト**上で接続を確認してください。

   ```bash
   ping {ip}
   ```

すべてのコマンドで、`{ip}` を記録されたアドレスに置き換えてください。変換の状況を確認するために、シリアルコンソールを開いたままにしてください。

### シリアルアクセス機能のないPCIeカード

PCIe カードのシリアルポートは、アクセスしにくい場合があります。シリアルケーブルを接続できない場合は、以下に示す固定 IP アドレス方式を使用してください。

バージョン **2.1.3** の PCIe カードは、IP アドレスを受信しない場合、**192.168.1.10** を使用します。

1. カードのイーサネットポートをホストに直接接続します。
2. ホストの接続されているイーサネットインターフェースを、カードと同じサブネットにある **192.168.1.20** に設定します。
3. ホストからの接続を確認してください。

   ```bash
   ping 192.168.1.10
   ```

4. セクション3では、`{ip}`として**192.168.1.10**を使用してください。

これらのアドレスは、カードのイーサネットポートに適用されます。[PCIeインターフェース経由のイーサネット](/hardware/getting-started/pcie-mode/virtual-network)は、別の設定を使用します。

## 3. 3.0.0のイメージファイルを書き込みます。

このセクションのコマンドは、**ホスト**上で実行してください。

1. CLIのバージョンが**2.1.19以降**になっていることを確認してください。
2. シリアルケーブルを接続した場合は、シリアルコンソールを開いたままにしておいてください。
3. 別のホスト端末で、変換を開始します。

   ```bash
   sima-cli bootimg -v 3.0.0 --netboot --devkit {ip} --autoflash
   ```

このコマンドは、ホスト上でTFTPサーバーを起動します。これにより、ボードがそのサーバーからブートするように指示されます。その後、`--autoflash`オプションが、イメージをボードに自動的に書き込みます。

手順が完了するまで、ホストのターミナルを開いたままにしてください。ネットワークに接続した状態を維持し、ボードの電源を入れ続けます。

## 4. ボードを再起動します。

1. `sima-cli` から再起動の指示があるまで待ってください。
2. ボードを再起動してください。
3. ボードが開始されるまでお待ちください。
4. シリアルまたはSSH経由でボードに接続します。
5. **ボード上の**ファームウェアバージョンを確認してください。

   ```bash
   cat /etc/buildinfo
   ```

6. システム設定を進める前に、バージョンが**3.0.0**であることを確認してください。

PCIe ホストシステムの場合、ホストドライバーを設定するには、[PCIe ドライバーのインストール](/hardware/getting-started/pcie-mode/driver-installation) の手順に従ってください。
