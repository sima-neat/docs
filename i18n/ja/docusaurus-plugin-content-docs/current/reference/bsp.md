# ボードサポートパッケージ

ボードサポートパッケージ（BSP）は、SiMa.aiボードの電源投入から、使用可能なLinuxユーザー空間までを動作させるための、低レベルのソフトウェアの集合です。これは、より高レベルのワークロード（知覚パイプライン、ROS 2ノード、カスタムC/C++アプリケーションなど）が動作する基盤となります。

SiMa.ai BSPには、以下のものが含まれます。

- **ブートローダー** (U-Boot) — DRAMを初期化し、ブートメディアを読み込み、カーネルをロードします。
- **カーネル** — SoC 上の MLA、CVU、ISP、PCIe、ネットワーク、およびストレージ IP 用の SiMa.ai ドライバを搭載した Linux カーネル。
- **デバイスツリー** — ボード固有の周辺機器（MIPIカメラ、GMSL2デシリアライザ、GPIOヘッダー、M.2スロットなど）を記述し、カーネルが起動時にそれらを検出し、使用できるようにします。
- **ルートファイルシステム** — ユーザー空間ツール、システムサービス、およびオンチップアクセラレータと通信する SiMa.ai ランタイムライブラリ。
- **ファームウェアのバイナリファイル** — セキュリティプロセッサ（tRoot）およびその他のコプロセッサ用。

## Modalix BSP

Modalix BSPは、Modalix DevKit、Modalix早期アクセス版キット、およびModalix PCIeカードを対象としています。これは、Debianをベースとしたディストリビューションである[eLxr](https://elxr.org/)上に構築されています。ユーザー空間は`apt`で管理されるため、Modalixイメージをカスタマイズすることは、Yoctoレシピを作成するよりも、Debianソフトウェアをパッケージングするに近い操作となります。既存のYocto DevKitをeLxrに変換するユーザーは、[eLxr に変換](./tech-notes/elxr-conversion)を参照してください。

ソースレイヤー：[swsoc-simaai-elxr-doc](https://github.com/SiMa-ai/swsoc-simaai-elxr-doc)

## BSPソースを使ってできること

上記のレポジトリは、次のような場合に役立ちます。

- **カスタムペリフェラルを追加する** — 新しい MIPI カメラ、GMSL2センサー、またはHATボード用のデバイスツリーオーバーレイを作成します。
- **カーネル機能を有効にする** — 標準イメージに含まれていないカーネルオプション（例：ファイルシステム、ネットワークプロトコル、またはUSBガジェットドライバー）を有効にします。
- **ルートファイルシステムを置き換えるか拡張する** — 独自のアプリケーション、ライブラリ、またはシステムサービスを組み込むことができます。
- **ローカル環境でリリースを再現する** — 監査または変更のために、DevKit に搭載されているのと同じイメージを再構築します。

カスタムイメージを作成したら、[ファームウェアの更新](/hardware/getting-started/firmware-update/) のいずれかの方法を使用して、DevKit に書き込みます。
