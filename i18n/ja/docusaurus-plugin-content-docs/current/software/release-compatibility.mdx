# リリースの互換性

各 Modalix プラットフォームリリースは、公開されているカーネルリポジトリと U-Boot リポジトリの
1 つのコミットからビルドされています。ボード上のイメージと一致するコンポーネントを再ビルドするには、
ビルドする前にそのリリースのコミットをチェックアウトしてください。
[BSP をソースからビルドする](./build-from-source.mdx)を参照してください。

## この表の読み方

- リポジトリにはリリースタグがありません。各リリースは `master` 上の 1 つのコミットで、
  タイトルは `SiMa.AI Release <version>` です。
- `master` には常に最新のリリースが含まれています。古いリリースを実行しているボード向けに
  これをビルドすると、そのボードのルートファイルシステムやモジュールと一致しないカーネルや
  ブートローダーができてしまいます。
- 実行中のボードのリリースは `cat /etc/buildinfo` で確認できます。

リリースをチェックアウトするには、次のようにします。

```console
root@sdk:/data/simaai-linux$ git checkout 65aba29989da
```
