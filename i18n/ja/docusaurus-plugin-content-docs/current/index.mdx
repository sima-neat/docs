# SiMa.ai ハードウェアに関するドキュメント

このガイドでは、SiMa.aiのMLSoC Modalix DevKit製品のハードウェア設定、ファームウェア、および低レベルインターフェイスについて説明します。これは専用のハードウェアリファレンスであり、ソフトウェア、機械学習、およびパイプラインツールについては別途ドキュメントで説明します。

## MLSoCとModalixについて

**MLSoC Modalix**は、SiMa.aiの第2世代機械学習システムオンチップです。Arm Cortex-A65アプリケーションコンプレックス、高スループットの**機械学習アクセラレータ（MLA）**、カメラからの画像入力用の**画像信号プロセッサ（ISP）**、および従来の画像処理ワークロード用の**コンピュータビジョンユニット（CVU）**を1つのチップに統合しています。

この統合により、開発者は、個別のアクセラレータ、ホストCPU、およびカメラブリッジを組み合わせて使用することなく、エッジでマルチモーダル、生成、および画像AIのパイプラインをデプロイできます。ここに記載されているすべての製品（DevKit、早期アクセスキット、およびPCIeカード）は、同じMLSoC Modalixシリコンをベースに構築されているため、あるフォームファクタ用に記述されたアプリケーションは、他のフォームファクタに簡単に移植できます。

## デプロイメントアーキテクチャ

最新の機械学習および推論アプリケーションでは、多様なデプロイシナリオに対応するために、柔軟なアーキテクチャが求められます。SiMa.aiのソリューションは、これらのニーズに対応できるように設計されており、パフォーマンス、効率、およびスケーラビリティを最適化する構成を提供します。大規模なシステムに統合する場合でも、スタンドアロンデバイスとして使用する場合でも、MLSoC Modalixは、多様なユースケースに対してシームレスな適応性を保証します。

<Tabs>
<TabItem value="standalone" label="MLSoCとModalixをスタンドアロンデバイスとして。" default>

このアーキテクチャでは、MLSoC Modalix は、独立した単体デバイスとして機能します。特に、小型化、高効率、および最小限の消費電力が必要とされるアプリケーションに最適です。

**主な用途**

- **Edge AIアプリケーション**: エッジに展開することで、中央サーバーやクラウドインフラストラクチャに依存することなく推論を実行できます。スマートカメラ、産業用IoTデバイス、自律型ロボットなどのアプリケーションに最適です。
- **コストを考慮したデプロイ**: 追加のハードウェアの必要性を低減し、スタンドアロン環境での運用において、費用対効果の高いソリューションとなります。
- **電力制約のある環境**: バッテリーやソーラーパネルで駆動されるリモート監視システムなど、エネルギー効率が最も重要な要素となる状況向けに最適化されています。

**利点**

- **自己完結型**: ホストシステムを必要とせず、デプロイを簡素化し、システムの複雑さを軽減します。
- **省エネルギー**: 低消費電力で設計されており、電力供給が不安定な環境での使用に適しています。
- **コンパクトで持ち運び可能**: 小型設計により、設置スペースが限られた場所でも容易に設置できます。

**一般的なデータフロー**

1. データは、ネットワークインターフェースまたはセンサーから直接受信されます。
2. MLSoC Modalix には、デバイス上での推論パイプラインを定義する [NEATアプリケーション](https://docs.sima-neat.com) が搭載されています。
3. MLSoCとModalixは、推論を実行し、データをローカルで処理します。
4. 結果は、ネットワーク接続を介して他のデバイスやシステムに送信され、さらなる処理や可視化が行われます。

<a className="docs-button" href="/hardware/getting-started/standalone-mode">DevKit を使用して、スタンドアロンモードシステムをセットアップします。</a>

</TabItem>
<TabItem value="pcie" label="MLSoCを、Modalixとして、PCIeカードとして。">

このアーキテクチャでは、MLSoC Modalix は、ホストシステムにシームレスに統合される PCIe カードとして機能します。この構成は、サーバー、デスクトップ、ワークステーションなどのホストシステムが、推論タスクのために追加の計算リソースを必要とする一方で、データストレージと処理には十分な能力を備えている場合に最適なソリューションです。

**主なユースケース**

- **高性能システム:** 大量のデータ処理とストレージが重要なデータセンターやハイエンドワークステーションに最適です。ホストシステムがCPU負荷の高いタスクを処理し、MLSoC Modalix は専用の推論処理を実行します。
- **拡張されたI/Oソリューション:** ターゲットシステムでは、MLSoC Modalixに標準で搭載されていない、追加のI/O機能が必要となる場合があります。例えば、USBインターフェースやその他のセンサー入力などです。このアーキテクチャにより、システムはホストシステムの拡張されたI/Oリソースを活用し、ビデオ分析や大規模なAIモデル推論などのアプリケーションを実現できます。

**利点**

- **強化された計算リソース:** 専用ハードウェアに推論タスクをオフロードすることで、ホストシステムの機能を拡張します。
- **柔軟性:** 需要の増加に応じて、追加の推論カードを組み込むことができる環境に最適です。

**一般的なデータ処理の流れ**

1. ホストシステムは、センサー、周辺機器、ストレージ、またはネットワークインターフェースからデータを収集します。
2. MLSoC Modalix には、推論パイプラインと調整された AI モデルをパッケージ化した [NEATアプリケーション](https://docs.sima-neat.com) が搭載されています。
3. データは、推論のためにPCIeインターフェースを介してMLSoCのModalixに送信されます。
4. 結果は、ホストシステムによって処理されるか、後続のシステムに転送され、そこでさらに処理されます。
