# ISP のチューニング

Modalix MLSoC の画像信号プロセッサ（ISP）は、カメラセンサーの RAW データを、
アプリケーションが受け取る画像に変換します。カメラからフレームを取得することと、良好な画像を
得ることは、別々のステップです。このページでは、チューニングとは何か、ISP ドライバーが
どのカメラに対応しているか、チューニングガイドの入手方法を説明します。

:::caution[ハードウェアでは未検証]
このページは、このサイトのほかのカメラ関連ページと、プラットフォームリリース 2.1.3 の
カーネルソースを要約したものです。カメラおよび ISP の担当者によるレビューは、まだ行われていません。
:::

## キャプチャとチューニング {#capture-and-tuning}

| | キャプチャ | 画質チューニング |
| --- | --- | --- |
| 結果 | ボードがカメラを認識し、カメラがフレームを出力する | フレームの露出、ホワイトバランス、色が適切になる |
| 必要なもの | センサードライバーとデバイスツリーオーバーレイ | センサーとそのレンズに合わせたチューニングデータ |
| 出発点 | [MIPI カメラインターフェース](../getting-started/standalone-mode/mipi-camera-interfaces.mdx) | 「Modalix カメラおよび ISP のチューニングガイド」 |

ISP は Arm Mali-C71 です。

## ISP ドライバーにエントリーがあるカメラ {#tuned-cameras}

プラットフォームリリース 2.1.3 では、カーネルの ISP ドライバーに、
[対応 MIPI カメラ](./supported-cameras.mdx)に掲載されているカメラのうち 4 つ、すなわち
Arducam の IMX477、e-con Systems の IMX568 および IMX678、Leopard Imaging の OG05C10 の
センサーエントリーがあります。一覧は [ISP ドライバーのソース](https://github.com/SiMa-ai/simaai-linux/blob/65aba29989da02d7612da5484dbbcd50643fdd60/drivers/media/isp/sensor/driver/common/sensor_driver_common.c)にあります。
これらのカメラを使用する場合、使い始めるにあたって ISP をチューニングする必要はありません。

Leopard Imaging の AR0234 には、同じリリースにセンサードライバーとデバイスツリーオーバーレイが
ありますが、ISP ドライバーにはこのカメラのセンサーエントリーはありません。

## チューニングが必要になる場合 {#when}

- 上記の一覧にないセンサーを使用する場合。
  [独自のカメラを統合する](./custom-camera.mdx)を参照してください。
- 対応センサーを、異なるレンズまたはカメラモジュールで使用する場合。
- 対応カメラの画質が、アプリケーションの要件を満たさない場合。

## ISP チューニングガイドを入手する {#tuning-guide}

「Modalix カメラおよび ISP のチューニングガイド」には、カメラに合わせて ISP をチューニングする方法が記載されています。
このガイドは依頼により提供されます。
[参考文献](../reference/extra-docs.md)を参照してください。

カメラのチューニングについて SiMa.ai に問い合わせるには、SiMa.ai の担当者に連絡するか、
[SiMa.ai のお問い合わせページ](https://sima.ai/contact/)をご利用ください。
