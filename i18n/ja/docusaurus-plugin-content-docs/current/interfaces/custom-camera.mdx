# 独自のカメラを統合する

お使いのカメラが[対応 MIPI カメラ](./supported-cameras.mdx)に
ない場合は、このページを使用してください。カメラが Modalix ボードでフレームを出力できるように
なるための条件、作成が必要なもの、各ステップの確認方法を説明します。その一覧にないカメラは
サポート対象外です。ドライバーとデバイスツリーの作業に加えて、画質に関する別の作業が必要になります。

:::caution[ハードウェアでは未検証]
このページは、プラットフォームリリース 2.1.3 のカーネルソースをもとに作成しています。
このページの手順に従って新しいカメラを統合した実績は、まだありません。
:::

## まず適合性を確認する {#check-fit}

| 確認項目 | プラットフォームが提供するもの |
| --- | --- |
| MIPI CSI-2 のレーン | Modalix SoM の各 CSI インターフェースには、データレーンが 2 本あります。1 つのインターフェースで 4 レーンを必要とするカメラは動作しません。 |
| インターフェース | SoM には CSI0 から CSI3 までの 4 つの CSI インターフェースがあります。キャリアボードは、そのうちの一部を接続します。Modalix DevKit は CSI1 と CSI2 を接続しています。 |
| コネクターとケーブル | カメラ側のコネクターを、キャリアボード側のコネクターに接続できる必要があります。アダプターが必要になる場合があります。 |
| 制御バス、クロック、電源、リセット | センサーには、I2C バス、リファレンスクロック、電源、そして通常はリセットまたはパワーダウンのピンが必要です。どのピンがそれらを提供するかは、キャリアボードによって決まります。 |

キャリアボードのカメラコネクターと信号については、
[キャリアボードの立ち上げ](../design/som-carrier.mdx)を参照してください。

## ドライバーを確認する {#driver}

カーネルにセンサー用のドライバーが必要です。プラットフォームリリース 2.1.3 では、次のカメラ
センサーのドライバーが有効になっています。Sony IMX219、IMX415、IMX477、IMX568、IMX678、
onsemi AR0234、OmniVision OG05C10。また、GMSL のシリアライザーおよびデシリアライザーの
ドライバー MAX96714、MAX96717、MAX96724、MAX9296A も有効になっています。一覧は
[`simaai_modalix_defconfig`](https://github.com/SiMa-ai/simaai-linux/blob/65aba29989da02d7612da5484dbbcd50643fdd60/arch/arm64/configs/simaai_modalix_defconfig)
にあります。

ほかのセンサーを使用する場合は、そのドライバーをカーネルに追加します。
[BSP をソースからビルドする](../software/build-from-source.mdx)を参照してください。

カーネルにドライバーがあるからといって、そのカメラがサポートされているわけではありません。
オーバーレイがあるカメラは、[対応 MIPI カメラ](./supported-cameras.mdx)に掲載されています。

## オーバーレイを作成する {#overlay}

お使いのキャリアボードとポート向けの、対応カメラのオーバーレイを出発点にして、
センサーに合わせて変更します。例として、
[`modalix-som-waveshare-ARDU-IMX477-1CAM.dtso`](https://github.com/SiMa-ai/simaai-linux/blob/65aba29989da02d7612da5484dbbcd50643fdd60/arch/arm64/boot/dts/simaai/overlays/modalix-som-waveshare-ARDU-IMX477-1CAM.dtso)
を参照してください。オーバーレイでは、次のことを行う必要があります。

1. センサーのリファレンスクロックを提供する。
2. センサーが接続されている I2C バスを有効にする。
3. カメラのパワーダウンピンまたはリセットピンを設定する。
4. ポートの CSI インターフェースを、その D-PHY およびビデオノードとともに有効にする。
   ポート 1 の場合は、`csi1`、`mipi_dphy_rx1`、`axi_vdma1`、`v4l2video1`、
   `v4l2vdma1` です。
5. センサーを記述する。`compatible` 文字列、I2C アドレス、クロックを指定します。
6. `data-lanes = <1 2>` とセンサーモードのリンク周波数を指定して、センサーを CSI
   インターフェースに接続する。

オーバーレイのビルド、インストール、確認については、
[デバイスツリーとオーバーレイ](../software/device-tree.mdx)を参照してください。

## キャプチャを検証する {#validate}

1. カメラを一覧表示します。お使いのカメラが一覧に含まれている必要があります。

   ```console
   sima@modalix:~$ cam -l
   ```

2. カメラが提供するフォーマットとサイズを一覧表示します。

   ```console
   sima@modalix:~$ cam -c 1 -I
   ```

3. フレームをキャプチャします。

   ```console
   sima@modalix:~$ cam -c 1 --capture=1 -F -s pixelformat=NV12
   ```

カメラが一覧にない場合は、
[うまくいかない場合](../software/device-tree.mdx#if-it-fails)を参照してください。

## 画質は別のステップです {#image-quality}

フレームをキャプチャできても、それだけで良好な画像が得られるわけではありません。ISP には、
センサーとレンズごとのチューニングデータが必要です。プラットフォームリリース 2.1.3 では、
カーネルの ISP ドライバーにセンサーのエントリがあるのは IMX477、IMX568、IMX678、OG05C10 のみです。
ほかのセンサーを使用する場合は、ISP のチューニングを計画してください。チューニングについては、
[参考文献](../reference/extra-docs.md)に掲載されている「Modalix カメラおよび ISP のチューニングガイド」で
説明されています。このガイドは SiMa.ai の担当者から入手できます。

チューニングの内容とガイドの入手方法については、[ISP のチューニング](./isp-tuning.mdx)を参照してください。

## サポートを受ける {#help}

カメラの統合について SiMa.ai に問い合わせるには、SiMa.ai の担当者に連絡するか、
[SiMa.ai のお問い合わせページ](https://sima.ai/contact/)をご利用ください。その際、センサーと
カメラモジュールの型番、キャリアボードとポート、プラットフォームリリース、および各検証ステップの
結果をお知らせください。
