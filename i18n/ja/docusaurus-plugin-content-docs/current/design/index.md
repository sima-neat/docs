# ハードウェアを設計する

MLSoC Modalix を中心に独自のシステムを構築する方法は 2 つあります。
設計作業、資料、立ち上げ作業がそれぞれ異なるため、
着手する前にどちらかを選択してください。

<div className="card-grid">
  <a className="card" href="/hardware/design/chip-down">
    <h4>チップダウン設計</h4>
    <p>Modalix SoC を独自のボードに直接実装し、メモリ、電源、クロックを自分で設計します。</p>
  </a>
  <a className="card" href="/hardware/design/carrier-board">
    <h4>キャリアボード設計</h4>

  </a>
</div>

## 2 つの方法を比較する

| | チップダウン設計 | キャリアボード設計 |
| --- | --- | --- |
| 設計対象 | パッケージ化された Modalix SoC を搭載するボード。メモリ、電源、クロックも含みます | Modalix SoM 用のキャリアボード。SoM には SoC、LPDDR5、電源がすでに搭載されています |
| 主な設計作業 | 電源シーケンス、クロックとリセット、LPDDR5 の配線とチューニング、高速信号のレイアウト、インターフェース、熱設計 | コネクターのマッピング、電源供給、インターフェース、熱設計 |
| 資料 | チップダウン設計ガイド、SoC データシート、設計パッケージ（SiMa.ai にご依頼いただければ提供します） | 公開されているデータシートと立ち上げガイド |
| ソフトウェアの出発点 | Modalix BSP と、ボードレベルの適合作業 | Modalix BSP と、キャリアボードに合わせたデバイスツリーの変更 |

ボードが起動した後は、どちらの方法でも同じソフトウェアと量産の手順を使用します。

- [eLxr のビルドとカスタマイズ](../software/index.md)：ボード用のカーネル、U-Boot、
  デバイスツリーをビルドします。
- [インターフェースと周辺機器](../interfaces/low-speed-io.mdx)：ピンマッピングと
  周辺機器のセットアップ。
- [工場でのビルドとテスト](../deployment/factory-build-and-test.mdx)：量産時の
  ボードへの書き込みとテスト。
