# キャリアボード設計

Modalix SoM は、Modalix SoC、LPDDR5 メモリ、電源を、ボード間コネクターを備えた
モジュールに搭載しています。SoM はキャリアボードに差し込んで使用します。キャリアボードには、製品に必要なコネクター、
電源入力、インターフェースを搭載します。キャリアボードは、購入することも独自に設計することもできます。

SoC を独自のボードに直接実装したい場合は、
[チップダウン設計](./chip-down.md)を参照してください。


:::warning 入力電圧は推論性能に影響します
Modalix SoM の VDD_IN は 5.0～20 V DC を受け付けます。MLA の周波数低下を避けるため、5.4 V DC 以上を供給してください。5.4 V DC 未満では MLA が 600 MHz に固定され、推論性能が低下します。SoM に 5 V DC しか供給しないキャリアボードは推奨しません。キャリアボードで入力を VDD_IN の前に降圧する場合は、レギュレーターの出力を 5.4 V DC 以上に設計してください。[Modalix SoM データシート](https://docs.sima.ai/pkg_downloads/datasheets_product_briefs/Modalix_SOM_Board_v2_Data_Sheet_Rev2.3_10-12-2026.pdf#page=40)の第 4 章を参照してください。
:::

## SoM が提供するもの {#som-provides}

以下の部品は Modalix SoM に搭載されており、260 ピンコネクターの割り当てに従う
キャリアボードであれば、どのボードでも動作します。

- Modalix MLSoC
- LPDDR5 メモリ
- eMMC および SPI フラッシュストレージ
- USB コントローラー、ギガビットイーサネット PHY、HDMI ビデオプロセッサー
- リアルタイムクロック

## キャリアボードが提供するもの {#carrier-provides}

- SoM とインターフェースの間のコネクターのマッピング
- SoM への電源供給：VDD_IN に 5.4 V DC 以上
- イーサネット、PCIe、USB、MIPI カメラ、低速 I/O などのインターフェース
- デバッグおよびリカバリー用のシリアルアクセス
- 冷却

## キャリアボードを選ぶか設計する {#choose-or-design}

キャリアボードは、購入することも独自に設計することもできます。

- 購入する場合は、[サードパーティー製キャリアボード](./third-party-carriers.mdx)でボードを比較してください。
  Modalix DevKit は、リファレンスキャリアボードである Waveshare 製キャリアボードを
  採用しています。
- 独自に設計する場合は、以下の関連資料と設計手順を使用してください。

## 関連資料

以下のドキュメントは[参考文献](../reference/extra-docs.md)に掲載されています。

| ドキュメント | 用途 |
| --- | --- |
| Modalix SoM キャリアボードのハードウェアに関する技術資料 | コネクターのピン配置、インターフェースのマッピング、電源供給、参照接続。最初にこれを読んでください。 |
| Modalix SoM データシート | SoM の電気的、機械的、熱的仕様 |
| キャリアボード用SoMの立ち上げガイド | 新しいキャリアボードへの電源投入と動作検証 |
| Modalix SoM 熱設計ガイド | 熱バジェットと冷却設計。SiMa.ai の担当者から入手できます |

## 設計手順

1. **Modalix SoM キャリアボードのハードウェアに関する技術資料** と **Modalix
   SoM データシート** を読みます。
2. VDD_IN に 5.4 V DC 以上が供給されるように電源を計画します。
3. [キャリアボードの立ち上げ](./som-carrier.mdx)を参考に、コネクターのマッピングとインターフェースを計画します。
   このページでは、コネクターのインターフェース、リファレンスキャリアボードからの変更点、カメラのオーバーレイについて説明しています。
4. [低速 I/O](../interfaces/low-speed-io.mdx) で低速ピンの割り当てを確認します。
5. ボードが完成したら、**キャリアボード用SoMの立ち上げガイド** に従って
   最初の電源投入を行います。
6. [BSP をソースからビルドする](../software/build-from-source.mdx)を参考に、
   キャリアボードに合わせてデバイスツリーを適合させます。
