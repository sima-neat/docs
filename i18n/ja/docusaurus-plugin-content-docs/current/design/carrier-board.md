# キャリアボード設計

Modalix SoM は、Modalix SoC、LPDDR5 メモリ、電源を、ボード間コネクターを備えた
モジュールに搭載しています。SoM を差し込むキャリアボードを、製品に必要なコネクター、
電源入力、インターフェースとともに設計します。

SoC を独自のボードに直接実装したい場合は、
[チップダウン設計](./chip-down.md)を参照してください。

## 設計する内容

- SoM とインターフェースの間のコネクターのマッピング
- SoM への電源供給
- Ethernet、PCIe、USB、MIPI カメラ、低速 I/O などのインターフェース
- デバッグおよびリカバリー用のシリアルアクセス
- 冷却

## 関連資料

以下のドキュメントは[参考文献](../reference/extra-docs.md)に掲載されています。

| ドキュメント | 用途 |
| --- | --- |
| Modalix SoM キャリアボードのハードウェアに関する技術資料 | コネクターのピン配置、インターフェースのマッピング、電源供給、参照接続。最初にこれを読んでください。 |

| Modalix SoM 熱設計ガイド | 熱バジェットと冷却設計。SiMa.ai の担当者から入手できます |

## 設計手順

1. **Modalix SoM キャリアボードのハードウェアに関する技術資料** と **Modalix
   SoM データシート** を読みます。
2. [キャリアボードの立ち上げ](./som-carrier.mdx)を参考に、コネクターのマッピング、電源、インターフェースを計画します。
   このページでは、コネクターのインターフェース、リファレンスキャリアボードからの変更点、カメラのオーバーレイについて説明しています。
3. [低速 I/O](../interfaces/low-speed-io.mdx) で低速ピンの割り当てを確認します。
4. ボードが完成したら、**キャリアボード用SoMの初期設定ガイド** に従って
   最初の電源投入を行います。
5. [BSP をソースからビルドする](../software/build-from-source.mdx)を参考に、
   キャリアボードに合わせてデバイスツリーを適合させます。
