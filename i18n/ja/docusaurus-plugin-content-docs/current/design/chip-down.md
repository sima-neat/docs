# チップダウン設計

チップダウン設計では、パッケージ化された Modalix SoC を独自のボードに直接実装します。
メモリ、電源、クロックなど、本来 Modalix SoM が提供するものをすべて自分で設計します。
チップダウン設計は、チップオンボード設計とも呼ばれます。

SoC、メモリ、電源をすでに搭載したモジュールをベースに構築したい場合は、
[キャリアボード設計](./carrier-board.md)を参照してください。

## 設計する内容

- SoC への電源供給と電源シーケンス
- クロックとリセット
- LPDDR5 メモリ（配線とチューニングを含む）
- ブートストレージと、デバッグおよびリカバリー用のシリアルアクセス
- PCIe、MIPI CSI-2、イーサネットなどの高速インターフェースとそのレイアウト
- 冷却

## 設計パッケージの入手 {#design-package}

SiMa.ai は、チップダウン設計ガイドと以下の関連資料を設計パッケージとして提供しています。
設計パッケージの入手には、SiMa.ai との秘密保持契約（NDA）が必要です。入手を希望する場合は、
SiMa.ai の担当者にお問い合わせください。担当者がいない場合は、
[SiMa.ai のお問い合わせページ](https://sima.ai/contact/)をご利用ください。

## 設計手順

1. 設計パッケージを依頼します。NDA が必要です。
2. 設計パッケージをリファレンス設計として使用し、ボードを設計します。
3. 熱設計ガイドを使用して冷却を計画します。
4. ボードを立ち上げます。メモリの初期化や最初のブートを含むチップダウンの立ち上げ手順は、
   まだ一般公開されていません。サポートについては SiMa.ai の担当者にお問い合わせください。
5. [カスタムシステムソフトウェアのビルドとデプロイ](../software/index.md)を参考に、ソフトウェアを適合させてビルドします。
