# チップダウン設計

チップダウン設計では、パッケージ化された Modalix SoC を独自のボードに直接実装します。
メモリ、電源、クロックなど、本来 Modalix SoM が提供するものをすべて自分で設計します。
チップダウン設計は、チップ・オン・ボード設計とも呼ばれます。

SoC、メモリ、電源をすでに搭載したモジュールをベースに構築したい場合は、
[キャリアボード設計](./carrier-board.md)を参照してください。

## 設計する内容

- SoC への電源供給と電源シーケンス
- クロックとリセット
- LPDDR5 メモリ（配線とチューニングを含む）
- ブートストレージと、デバッグおよびリカバリー用のシリアルアクセス
- PCIe、MIPI CSI-2、Ethernet などの高速インターフェースとそのレイアウト
- 冷却

## チップダウン設計ガイド

SiMa.ai では、Modalix のチップダウン設計ガイドを用意しています。入手するには、
SiMa.ai の担当者にお問い合わせください。

## 関連資料

以下のドキュメントも SiMa.ai の担当者から入手できます。各ドキュメントの説明については、
[参考文献](../reference/extra-docs.md)を参照してください。

| ドキュメント | 用途 |
| --- | --- |
| Modalix SoC データシート | ピン機能、電源レール、信号タイミング、動作範囲 |
| Modalix プリント基板配線に関するガイドライン | PCIe、MIPI CSI-2、Ethernet、その他の重要なネットのレイアウトルール |
| Modalix DDR チューニングガイド | LPDDR5 の配線、終端、キャリブレーション |
| Modalix早期アクセス版 DevKitデザインパッケージ | チップダウンのリファレンス設計 |
| Modalix PCIe HHHL デザインパッケージ | PCIe カード向けのチップダウンのリファレンス設計 |
| Modalix SoM 熱設計ガイド | 熱バジェットと冷却設計 |

## 設計手順

1. チップダウン設計ガイドと上記の関連資料を入手します。
2. 設計パッケージをリファレンス設計として使用し、ボードを設計します。
3. 熱設計ガイドを使用して冷却を計画します。
4. ボードを立ち上げます。メモリの初期化や最初のブートを含むチップダウンの立ち上げ手順は、
   まだ一般公開されていません。サポートについては SiMa.ai の担当者にお問い合わせください。
5. [eLxr のビルドとカスタマイズ](../software/index.md)を参考に、ソフトウェアを適合させてビルドします。
