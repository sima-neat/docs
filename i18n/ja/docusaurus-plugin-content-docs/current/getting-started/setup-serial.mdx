# シリアル接続を設定する

開発の初期段階では、システムがスタンドアロン構成で使用される場合でも、ホストシステム内の PCIe デバイスとして使用される場合でも、シリアルインターフェースを介して DevKit に接続することを強くお勧めします。

スタンドアロン構成では、シリアル接続は、IPアドレスの取得方法に関係なく、DevKit への信頼性の高いアクセスを提供します。これにより、ネットワーク接続が利用できない場合や、誤って構成されている場合でも、開発者はシステムの構成、監視、および復旧タスクを制御できるようになります。

PCIe 構成では、シリアルインターフェースは、起動時に PCIe カードのシェルおよびデバッグコンソールへの直接アクセスを提供します。これは、ホストシステムまたは PCIe リンクが完全に動作していない場合の、低レベルの制御やトラブルシューティングに特に役立ちます。

シリアルインターフェースは、主に開発および起動を目的としています。システムが完全に構成および展開されると、継続的な操作には通常、シリアル接続は必要ありません。

開発者のコンピューターのオペレーティングシステムによって、シリアルインターフェースを介して DevKit に接続するためのさまざまな方法が利用できます。

付属のシリアルケーブルを使用して、DevKit をコンピューターに接続してください。

- **DevKit の接続:** 筐体に記載されているように、付属の USB-A - USB-C ケーブルを使用して、DevKit の **UART** ポートに接続してください。
- **コンピューター側：** **USB Type-A** ポートに接続します。必要に応じて、USB ハブを使用してください。

付属のシリアルケーブルを使用して、DevKit をコンピューターに接続してください。

- **DevKit の接続:** フラットコネクタ上の三角形のマークが、DevKit の一番右側のピンと一致するようにしてください。
- **コンピューター側：** **USB Type-A** ポートに接続します。必要に応じて、USB ハブを使用してください。

<TabItem value="windows" label="Windows">

**Windows** 上のシリアルターミナルを使用して **DevKit** に接続するには、次の手順に従ってください。

1. COMポートを特定します。
   - **デバイスマネージャー**を開く → **ポート（COM & LPT）**を展開する。
   - 「**USB シリアルポート（COMx）**」という項目を探してください。

2. **シリアルターミナルのインストールと起動**:
   - [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html) または **Tera Term** を使用してください。
   - 接続タイプを**シリアル**に設定します。
   - 正しい**COMポート**を入力してください（例：`COM3`）。
   - **ボーレート**を`115200`に設定します。

3. **「開く」**をクリックして、接続を開始します。

</TabItem>
<TabItem value="mac-linux" label="MacOSとLinuxのデスクトップ">

:::note
続行する前に、`sima-cli` をインストールまたはアップグレードしてください。このガイドは、最新バージョンの `sima-cli` での使用を想定しています。
:::

MacおよびLinuxで、`sima-cli serial`コマンドを使用して、SiMaハードウェアのシリアルポートに接続します。

```console
sima-cli serial
```

このコマンドを実行すると、シリアルポートにアクセスするために必要な依存関係がコンピューターにインストールされます。シリアルターミナルを終了するには、Ctrl + A を押してから Ctrl + X を押します。

一部の古いファームウェアバージョンでは、システムがシリアルコンソールに対して異なるボーレートを使用する場合があります。ターミナルに文字化けした出力が表示される場合は、ボーレートが一致していないことが原因である可能性があります。より高いボーレートを指定してみてください。

```console
sima-cli serial -b 921600
```
