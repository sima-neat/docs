# ネットワーク設定

Modalix DevKit をネットワークに接続するか、ホストコンピューターに直接接続します。デフォルトでは、DevKit は DHCP を使用して IP アドレスを取得します。

:::tip シリアルアクセスを維持してください。
[シリアル接続](/hardware/getting-started/setup-serial) を使用すると、ネットワーク経由で接続できない場合に、IPアドレスを確認したり、ネットワーク設定を修正したりできます。
:::

## 1. DevKit を接続します。

お客様の環境に最適な接続方法をお選びください。

- **DHCP を使用したネットワーク接続:** DevKit をルーターまたはネットワークスイッチに接続します。IP アドレスは自動的に割り当てられます。
- **ホストへの直接接続:** DevKitのイーサネットポートをホストに接続します。必要に応じて、USB-to-イーサネットアダプターを使用してください。ファームウェア3.0では、通常、固定IPアドレスを設定しなくても接続できます。詳細については、以下のヒントを参照してください。
- **ホスト経由でのインターネットアクセス:** DevKit をホストに接続し、インターネット共有を有効にします。[ホストのインターネット接続を共有する](#share-the-hosts-internet-connection) を参照してください。

:::tip ファームウェア3.0における直接接続
起動時にDHCPサーバーが利用できない場合、ファームウェア3.0はDevKitに、`169.254.x.x`範囲（`169.254.0.0/16`）のリンクローカルアドレスを割り当てます。

DHCPを使用する直接接続されたホストは、IPv4リンクローカルフォールバックが有効になっている場合、通常、同じ範囲のアドレスを自身に割り当てます。これにより、ホストとDevKitは、静的IP構成なしで通信できるようになります。

この接続はローカルアクセスのみを提供します。インターネットアクセスが必要な場合は、インターネットに接続されたネットワークを使用するか、ホストのインターネット共有機能を有効にします。
:::

:::tip ファームウェア 2.1.3 での直接接続
DHCPが利用できない場合、DevKitはデフォルトで`192.168.1.20`を使用します。ホストの接続されているイーサネットインターフェースを、同じサブネット内の別の静的アドレス（例：`192.168.1.10/24`）に設定し、ローカルネットワーク経由でDevKitに接続します。
:::

## 2. DevKitのIPアドレスを調べます。 {#check-the-current-ip-address}

もし、お使いの DevKit がファームウェア 3.0 を実行していることがわかっている場合は、同じローカルネットワーク上で、**ホスト**上で次のコマンドを実行してください。

```console
sima-user@sima-user-machine:~$ sima-cli device discover
```

このコマンドは、検出された Modalix DevKit の IP アドレスを出力します。

他のファームウェアバージョンを使用する場合、または検出機能で DevKit が見つからない場合は、シリアルコンソールを開き、次のコマンドを DevKit 上で実行してください。

```console
modalix:~$ ip -4 addr
```

接続されているイーサネットインターフェース（例：`end0`）で、`inet` の後のアドレスを見つけます。たとえば、`192.168.91.181/22` は、IPアドレスが `192.168.91.181` であることを意味します。ループバックアドレス `127.0.0.1` は使用しないでください。

## 3. 接続をテストします。

これらのコマンドを**ホスト**上で実行し、`<devkit-ip>` を、先ほど確認したアドレスに置き換えてください。

```console
sima-user@sima-user-machine:~$ ping <devkit-ip>
sima-user@sima-user-machine:~$ ssh sima@<devkit-ip>
```

:::tip 接続に失敗した場合
イーサネットケーブルと、両方のデバイスのIPアドレスを確認してください。直接接続の場合、両方のIPアドレスは同じサブネット内にある必要があります。ホストがリンクローカルフォールバックをサポートしていない場合は、それを有効にするか、両方のデバイスで静的IPアドレスを設定してください。

シリアルコンソールを使用して、DevKitのネットワーク設定を確認または変更します。
:::

## DHCPまたは固定IPの設定を変更する

次のコマンドを**DevKit**で実行して、ネットワーク設定メニューを開きます。

```console
modalix:~$ sima-cli network
```

メニューを使用して、再起動せずに DHCP と固定 IP アドレスを切り替えてください。

### NetworkManager で設定する

`sima-cli` が利用できない場合は、eLxr 2.1 以降で、以下のコマンドを使用してください。これらのコマンドは、事前に設定された `end0-dhcp` および `end0-static` プロファイルを使用します。

DHCPを有効にするには：

```console
modalix:~$ sudo nmcli connection up end0-dhcp
```

固定IPアドレスを設定して有効にするには：

```console
modalix:~$ sudo nmcli connection modify end0-static ipv4.addresses 192.168.1.20/24
modalix:~$ sudo nmcli connection up end0-static
```

`192.168.1.20/24` を、ご自身の環境に合わせてアドレスとネットワークプレフィックスに置き換えてください。同じサブネット内の別のアドレスでホストを構成します。

アクティブな接続とIPアドレスを確認するには：

```console
modalix:~$ nmcli -f NAME,DEVICE,STATE connection show --active
modalix:~$ ip -4 addr
```

:::caution ネットワーク設定の変更
IPアドレスを変更すると、SSHセッションが切断される可能性があります。シリアルコンソールを使用するか、新しいアドレスで再接続してください。
:::

## ホストのインターネット接続を共有する {#share-the-hosts-internet-connection}

DevKit が Ubuntu ホストを介してインターネットにアクセスする必要がある場合に、このオプションを使用します。

1. DevKitのイーサネットポートをホストに接続します。ホストがインターネットにアクセスできることを確認してください。
2. ホストで、**[設定] → [ネットワーク] → [有線]** を開き、そのイーサネットポートの接続を作成または編集します。
3. **IPv4**タブで、**他のコンピューターと共有**を選択し、変更を適用します。
4. 接続を一度オフにしてから再度オンにすることで、設定を適用します。
5. DevKit が DHCP を使用するように設定し、次に [そのIPアドレスを調べます。](#check-the-current-ip-address) を実行して、接続をテストします。

Ubuntu は通常、共有ネットワークに `10.42.0.0/24` を使用します。ホストが異なるサブネットを使用している場合があります。必要に応じて、`ip -4 addr` を使用してホストのイーサネットアドレスを確認し、そのサブネットをスキャンしてください。

```console
sima-user@sima-user-machine:~$ nmap -sn 10.42.0.0/24
```

ディスカバリー機能またはシリアルコンソールを使用して、どのアドレスがDevKitに割り当てられているかを確認してください。

## 古いファームウェア：U-Boot ネットワーク設定

<details>
<summary>ファームウェア 2.0 以前</summary>

これらの手順は、バージョン2.0以下のファームウェアにのみ適用されます。バージョン2.1以降のファームウェアの場合は、上記に示すLinuxコマンドを使用してください。旧バージョンの詳細については、[v2.0.0 ドキュメント](https://docs.sima.ai/v2.0.0/pages/overview/setup_standalone_mode/setup_network.html#network-setup-in-the-linux-shell)を参照してください。

1. [シリアルターミナル](/hardware/getting-started/setup-serial)を使って DevKit に接続します。
2. DevKit を再起動します。`Hit any key to stop autoboot` と表示されたら、キーを押して U-Boot に入ります。
3. 静的IP設定を有効にするには、次のコマンドを実行してください。

   ```console
   sima:~$ env set forcenetcfg static; saveenv
   sima:~$ boot
   ```

   最初のイーサネットポートと2番目のイーサネットポートは、それぞれ`192.168.1.20`と`192.168.2.20`を使用します。

4. Linux の起動後に静的アドレスを変更するには、このファイルの「**ネットワーク**」セクションを編集してください。

   ```console
   modalix:~$ sudo vi /etc/systemd/network/20-end0-static.network
   ```

   このファイルは、バージョン2.0以下のファームウェアでのみ使用されます。バージョン2.1以降のファームウェアでは、NetworkManagerプロファイルが使用されます。

5. 代わりに DHCP を有効にするには、U-Boot で次のコマンドを実行します。

   ```console
   sima:~$ env set forcenetcfg dhcp; saveenv
   sima:~$ boot
   ```

</details>
