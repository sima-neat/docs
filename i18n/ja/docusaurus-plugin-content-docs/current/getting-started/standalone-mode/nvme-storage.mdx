# NVMe ストレージ

**Modalix DevKit** には、500GBのNVMeドライブが含まれています。より多くの容量が必要な場合は、事前にインストールされているドライブを、キャリアボード上の互換性のあるM.2 NVMeモジュールに交換してください。

:::note
続行する前に、`sima-cli` をインストールまたはアップグレードしてください。このガイドは、最新の `sima-cli` バージョンで使用することを目的としています。
:::

:::note
このコマンドは、Modalix DevKit 上で直接実行する必要があります。
:::

NVMe ドライブをフォーマットするには、次のコマンドを実行します。

```console
modalix:~$ sima-cli nvme format
```

フォーマット後、NVMe ドライブが `/media/nvme` にマウントされます。

マウントされていることを確認し、ストレージの使用状況を確認するには、次のコマンドを実行します。

```console
modalix:~$ df -h
```

このコマンドは、すべてのマウントされたファイルシステム上の利用可能なディスクスペースを表示します。これには、NVMeドライブも含まれます。

NVMeドライブを再マウントするには、次のコマンドを実行します。

```console
modalix:~$ sima-cli nvme remount
```

`format`コマンドと`remount`コマンドは、`/etc/fstab`にエントリを追加し、その結果、NVMeドライブが起動時に自動的にマウントされるようになります。
