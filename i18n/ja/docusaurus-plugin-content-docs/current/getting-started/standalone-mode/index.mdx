# スタンドアロンモード

スタンドアロンモードでは、Modalix DevKit は、独立したエッジデバイスとして動作します。センサー、カメラ、ストレージ、またはネットワークインターフェースからデータを受信し、ローカルで処理し、結果をネットワーク経由で送信します。

DevKit が PCIe カードとしてホストマシンにインストールされていない場合に、このセクションを使用します。
