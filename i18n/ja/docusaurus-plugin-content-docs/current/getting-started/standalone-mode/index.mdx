# スタンドアロンモード

DevKit をスタンドアロンモードで設定するには、シリアル接続とネットワーク設定の両方を構成し、安定した信頼性の高いアクセスを確保する必要があります。シリアルインターフェースは、ネットワークの可用性に関係なく、DevKit との継続的な通信を可能にする重要な通信リンクとして機能します。

DevKit の IP アドレスは、以下のいずれかの方法で割り当てることができます。

- ネットワークを通じて自動的に設定を行います。
- 開発者のコンピューターを介した自動設定。
- 手動による固定IPアドレスの設定。

適切な方法の選択は、特定のネットワーク環境と接続要件によって異なります。

## 設定する DevKit ネットワーク {#network}

デフォルトでは、DevKit のネットワークインターフェースは DHCP を使用します。

- もし、DevKitをコンピューターに直接接続したい場合は、コンピューターのネットワークインターフェースに固定IPアドレスを設定し、DevKitに直接接続してください。
- DevKit がネットワークから IP アドレスを自動的に取得するようにするには、インターフェースを DHCP を使用するように設定する必要があります。

**現在のIPアドレスを確認する**

シリアルコンソールから、次のコマンドを実行します。

```console
sima@modalix:~$ ip a | grep inet
   inet 127.0.0.1/8 scope host lo
   inet6 ::1/128 scope host noprefixroute
   inet 192.168.91.181/22 brd 192.168.91.255 scope global dynamic noprefixroute end0
   inet6 fe80::ab34:b995:9f6e:160e/64 scope link noprefixroute
```

<Tabs groupId="network-method">
<TabItem value="linux-shell" label="Network Setup In The Linux Shell" default>

:::note
デバイスを再起動せずに、固定 IP アドレスと DHCP の切り替えを行いたい場合は、以下の手順に従ってください。
:::

DevKit に `sima-cli` がインストールされており、再起動せずに DHCP と静的設定を動的に切り替えたい場合は、次のコマンドを実行してください。

```console
davinci:~$ sima-cli network
```

静的および DHCP ネットワーク構成を切り替えるためのインタラクティブなメニューが表示されます。

`sima-cli` が利用できない場合は、あらかじめ設定された接続プロファイル（`end0-static` と `end0-dhcp`）を切り替えるために、`nmcli` を使用してください。

:::note
以下の手順では、`NetworkManager`のプロファイルを使用してネットワークインターフェースを構成し、eLxr 2.1以降を実行しているDevKitシステムに適用します。システムでそれより前のバージョンを実行している場合は、[バージョン 2.0.0 のドキュメント](https://docs.sima.ai/v2.0.0/pages/overview/setup_standalone_mode/setup_network.html#network-setup-in-the-linux-shell)を参照してください。
:::

**固定IPアドレスへの切り替え**

ネットワークインターフェースをDHCPから固定IPアドレスに変更するには、次のコマンドを実行します。

```console
davinci:~$ sudo nmcli connection up end0-static
davinci:~$ nmcli -f NAME,DEVICE,STATE connection show --active
davinci:~$ networkctl status
```

**DHCPへの切り替え**

ネットワークインターフェースを固定IPからDHCPに変更するには、次のコマンドを実行します。

```console
davinci:~$ sudo nmcli connection up end0-dhcp
davinci:~$ nmcli -f NAME,DEVICE,STATE connection show --active
davinci:~$ networkctl status
```

<TabItem value="auto-config" label="Auto Config Through Dev Computer">

:::note
- 開発者ネットワークが、DevKit からのイーサネット接続に使用できない場合に適しています。
- DevKit を開発用コンピューターの Ethernet ポートに接続します。開発用コンピューターに Ethernet ポートがない場合は、USB-to-Ethernet ドングルを使用してください。
- コンピューターは、DevKitとインターネットを共有でき、`pip`を使用してPythonパッケージをインストールできます。
- ホストコンピューターでインターネット接続の共有を有効にする必要があります。
:::

1. 以下の手順は、Ubuntu 環境で使用する場合に適用されます。他のプラットフォームでは手順が異なる場合があります。ネットワーク接続を共有する方法については、オンラインで関連する手順をお探しください。

   - 画面の右上にある「`Settings`」を開き、次に「`Network`」セクションに移動します。
   - `Wired` の下にあるプラス記号をクリックして、ボードに既存のプロファイルがない場合は新しい設定プロファイルを作成するか、既存のプロファイルがある場合はそれを変更します。
   - 新しいプロファイルを作成する場合は、「共有」または任意の名前を付けてください。
   - 「`IPv4`」タブで、「`Shared to other computers`」を選択します。そして、「適用」をクリックしてください。
   - 既存の接続がある場合は、一度切断してから再度接続し直すと、変更が反映されます。
   - お使いのコンピューターは、現在APとネットワーク接続されているはずです。`10.42.0.0/24`は、この設定でUbuntuが使用するデフォルトのサブネットですが、お使いのコンピューターでは異なるサブネットが使用されている場合があります。
   - 次のステップで何も結果が得られない場合は、`ifconfig` を実行し、イーサネットインターフェース（通常は `eth0`）の IP アドレスを確認してください。

2. Ubuntuマシンでターミナルを開きます。次に、指定されたIP範囲内のデバイスをスキャンするために、以下のコマンドを入力します。

   ```console
   sima-user@sima-user-machine:~$ nmap -sn 10.42.0.0/24 | grep report
      Nmap scan report for sima-user-machine (10.42.0.1)
      Nmap scan report for 10.42.0.241
   ```

   これは、このサブネットで使用される IP アドレスのリストです。末尾が `.1` で終わるものが、ホストマシンです。末尾が `.1` で終わらないものが、SiMa DevKit の IP アドレスです。上記の例では、ボードが `10.42.0.241` で、ホストが `10.42.0.1` です。

3. 次のコマンドを実行して、接続をテストしてください。

   ```console
   sima-user@sima-user-machine:~$ ssh sima@10.42.0.241
   ...
   Last login: Mon Nov 27 19:58:33 2023
   davinci:~$
   ```

4. ボードからホストに接続できるかどうかをテストするには、pingを実行します。 `10.42.0.1` ボードから。ホストでSSHサーバーが実行されている場合は、SSHを使用することもできます。

   ```console
   davinci:~$ ping 10.42.0.1
      PING 10.42.0.1 (10.42.0.1): 56 data bytes
      64 bytes from 10.42.0.1: seq=0 ttl=64 time=0.598 ms
      64 bytes from 10.42.0.1: seq=1 ttl=64 time=0.703 ms
      64 bytes from 10.42.0.1: seq=2 ttl=64 time=0.639 ms
      ^C
      --- 10.42.0.1 ping statistics ---
      3 packets transmitted, 3 packets received, 0% packet loss
      round-trip min/avg/max = 0.598/0.646/0.703 ms
   ```

5. ボードに ping を送信したり、SSH で接続したりできない場合は、固定 IP アドレスの設定方法を使用してください。

</TabItem>
<TabItem value="uboot" label="Network Setup In The U-Boot Shell">

:::note
この手順は、DevKit ファームウェアのバージョン 2.0 以前にのみ適用されます。バージョン 2.1 以降では、ユーザーは Linux 側の設定を利用できます。U-Boot でネットワークを設定することで、ファームウェアのアップグレード後もネットワーク設定が維持されます。
:::

1. UARTを介してDevKitに接続し、[シリアルターミナル](/hardware/getting-started/setup-serial)を使用します。
2. DevKit を再起動してください。
3. メッセージが表示されたら、任意のキーを押してU-Bootを起動します。メッセージは「`Hit any key to stop autoboot`」です。

4. 固定IPアドレスに切り替えるには、次のコマンドを入力してください。

   ```console
   sima:~$ env set forcenetcfg static; saveenv
   sima:~$ boot
   ```

5. ボードは再起動し、最初のイーサネットポートと2番目のイーサネットポートには、それぞれ`192.168.1.20`と`192.168.2.20`を使用します。
6. ボードの固定IPアドレスを変更するには、ネットワークファイルを編集して `vi` デバイスが起動した後。

   ```console
   davinci:~$ sudo vi /etc/systemd/network/20-end0-static.network
   ```

7. **ネットワーク**セクションで、必要に応じてIPアドレスを更新してください。
8. DHCPモードを設定するには、以下のコマンドを入力し、ボードを起動してください。

   ```console
   sima:~$ env set forcenetcfg dhcp; saveenv
   sima:~$ boot
   ```

## NVMe ストレージの設定を行います。{#nvme}

**Modalix DevKit** には、500GBのNVMe（Non-Volatile Memory Express）ドライブが含まれています。
より多くの容量が必要な開発者は、プリインストールされているドライブを、キャリアボードに直接取り付けられる互換性のあるM.2 NVMe モジュールに交換できます。

:::note
続行する前に、`sima-cli` をインストールまたはアップグレードしてください。このガイドは、最新バージョンの `sima-cli` での使用を想定しています。
:::

:::note
このコマンドは、Modalix DevKit 上で直接実行する必要があります。
:::

`sima-cli` をインストールすると、次のコマンドを使用して NVMe ドライブのフォーマットを実行できます。

```console
modalix:~$ sima-cli nvme format
```

フォーマット後、NVMe ドライブは自動的に `/media/nvme` にマウントされます。

マウントされていることを確認し、ストレージの使用状況を確認するには、次のコマンドを実行してください。

```console
modalix:~$ df -h
```

このコマンドは、すべてのマウントされたファイルシステム上の利用可能なディスクスペースを表示します。これには、NVMe ドライブも含まれます。

NVMe ドライブを再マウントする必要がある場合は、次のコマンドを実行してください。

```console
modalix:~$ sima-cli nvme remount
```

`format` コマンドと `remount` コマンドはどちらも、`/etc/fstab` ファイルにエントリを自動的に追加するため、NVMe ドライブは常に自動的にマウントされます。

## MIPIインターフェースを設定します{#mipi}

:::note
続行する前に、`sima-cli` をインストールまたはアップグレードしてください。このガイドは、最新バージョンの `sima-cli` での使用を想定しています。
:::

:::note
この手順では、最新バージョンの sima-cli がインストールされたホストマシンが必要です。また、**Modalix Devkit** のファームウェアバージョンが `1.7.0_master_B1965` 以上である必要があります。これは、このビルドに MIPI をサポートするために必要な `.dtbo` ファイルが含まれているためです。
:::

**Modalix DevKit** には、デバイスへの入力として MIPI カメラを接続するための 2 つの MIPI インターフェースが含まれています。MIPI ポートはキャリアボードに直接配置されており、開発者はそれらを有効にするために、以下の手順に従う必要があります。

開始する前に、**Modalix Devkit** がオフになっている状態で、MIPI カメラを MIPI ポートのいずれかに接続していることを確認してください。

接続したら、ホストマシンからシリアルケーブルを **Modalix Devkit** に接続します。その後、**Modalix Devkit** をオンにします。

次に、`sima-cli` を使用してシリアルターミナルを確立し、3 秒のカウントダウン中に任意のキーを押して、すぐに `uboot` に入ります。

```console
sima-cli serial -b 115200
...
Hit any key to stop autoboot:  0
sima$
```

uboot に入ったら、適切な **デバイスツリーブロブオーバーレイ** (`.dtbo`) ファイルを `dtbos` 変数に設定します。正しいファイルは、**キャリアボード**、**カメラメーカー**、**センサータイプ**、および**カメラポート**によって異なります。その後、環境を保存してオペレーティングシステムを起動します。

ファイル名は、次のパターンに従います。

```text
modalix-som-<carrier_board>-<camera_manufacturer>-<sensor_type>-<port>CAM.dtbo
```

ハードウェアに合わせて、各コンポーネントを選択してください。

| コンポーネント | 価値観 | 説明 |
| --- | --- | --- |
| キャリアボード | `connectech`, `seeedstudio`, `waveshare` | キャリアボードのモデル |
| カメラメーカー | `ARDU`, `ECON`, `LI` | Arducam、e-con Systems、またはLeopard Imaging |
| センサーの種類 | `IMX477`, `IMX568`, `IMX678`, `AR0234`, `OG05C10` | カメラセンサーのモデル |
| ポート | `0CAM`, `1CAM`, `2CAM`, `3CAM`, `DUAL` | カメラが接続されているMIPIポート番号 |

たとえば、ポート0に接続されたLeopard ImagingのIMX477センサーを備えたConnectechのキャリアボードです。

```console
sima$ setenv dtbos modalix-som-connectech-LI-IMX477-0CAM.dtbo ; saveenv ; boot
```

1. 利用可能なカメラの一覧：

   ```console
   sima@modalix:~$ cam -l
   ```

2. カメラ1で利用可能なさまざまなカメラ形式を表示します。

   ```console
   sima@modalix:~$ cam -c 1 -I
   ```

3. カメラ1から画像をキャプチャします：

   ```console
   sima@modalix:~$ rm -rf frame* && cam -c 1 --capture=1 -F -s pixelformat=NV12
   ```
