# 仮想ネットワーク

:::note
仮想ネットワーク機能を使用する前に、DevKit を最新のファームウェアバージョンに [アップデート](/ja/hardware/getting-started/firmware-update) してください。

この機能は、Linux ホストでのみ利用可能です。
:::

Modalix PCIeカードをPCIe経由で接続すると、ホストとカードの間に仮想イーサネットインターフェースが作成されます。

以下の目的で仮想ネットワークを使用してください。

- **セキュアシェル（SSH）**：トラブルシューティングやシステム管理のために、DevKitのコマンドラインにアクセスします。
- **セキュアコピープロトコル（SCP）**: ホストとDevKitの間で、ログ、設定ファイル、その他のファイルを転送します。

## 手動によるIPアドレスの割り当て

`insmod` を使用してモジュールを手動でロードする場合は、以下のコマンドを使用してください。これにより、ホストインターフェースに静的なIPアドレスを割り当て、その後、Modalix PCIe カードに割り当てることができます。

```console
sudo insmod sima_mla_drv.ko default_ip=false
```

また、ホストに `ifconfig` ユーティリティも必要です。

```console
ifconfig <eth interface> 20.1.2.1
```

ホストインターフェースにIPアドレスを割り当てた後、SoCインターフェースには自動的にIP + 1が割り当てられます。たとえば、ホストが`20.1.2.1`を使用する場合、MLSoCのIPは`20.1.2.2`になります。

インターフェースが作成される際、ホストインターフェースは`cardnum:S:I:m:A:0`の形式のMACアドレスを使用し、SoCインターフェースは`cardnum:S:I:m:A:1`を使用します。IPアドレスは、作成時にそれぞれ`host:10.0.cardnum.1`と`soc:10.0.cardnum.2`として割り当てられます。

1. ホストマシンにおける`ifconfig`コマンドの出力：

   ```console

       inet 10.0.0.1  netmask 255.255.255.0  broadcast 10.0.0.255
       inet6 fe80::253:49ff:fe4d:4130  prefixlen 64  scopeid 0x20<link>
       ether 00:53:49:4d:41:30  txqueuelen 1000  (Ethernet)
       RX packets 14107  bytes 4460994 (4.4 MB)
       RX errors 0  dropped 0  overruns 0  frame 0
       TX packets 818  bytes 74840 (74.8 KB)
       TX errors 0  dropped 0 overruns 0  carrier 0  collisions 0
   ```

   ```console

       inet 10.0.0.2  netmask 255.255.255.0  broadcast 10.0.0.255
   ```
