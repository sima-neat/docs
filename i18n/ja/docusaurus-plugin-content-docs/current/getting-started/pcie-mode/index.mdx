# PCIe モード

PCIeモードでは、Modalix PCIeカードをホストマシンにインストールし、Modalix推論をPCIe経由で加速します。ホストはオーケストレーション、ストレージ、およびI/Oを処理し、カードは推論ワークロードを処理します。

ModalixハードウェアをスタンドアロンのDevKitとしてではなく、PCIeカードとしてインストールする場合に、このセクションを使用します。
