# sima-cli を使用したアップデート

DevKit が実行中で、ネットワーク経由でアクセスできる場合に、`sima-cli update` を使用します。この方法では、ファームウェアイメージをダウンロードし、DevKit でアップデートをトリガーします。

:::note
`sima-cli update` がインストールするのは SiMa.ai の公式ビルドのみです。独自にビルドしたイメージを使用する場合は、代わりに [イメージを eMMC に書き込む](/hardware/deployment/flash-image) を参照してください。
:::

:::note
DevKitで2.xファームウェアを実行している場合、この更新メカニズムを使用して直接3.0に移行することはできません。まず、[2.1.3 から 3.0.0 にバージョンアップします。](/hardware/reference/tech-notes/convert-2-1-3-to-3-0-0)の手順に従ってください。変換後、`sima-cli update`を使用して、eLxr 3.0から新しいリリースに更新します。
:::

続行する前に、ホストがネットワーク経由で DevKit にアクセスできることを確認してください。以下を参照してください。

- [スタンドアロンモードのネットワーク設定](/hardware/getting-started/standalone-mode/network)
- [PCIe モードの仮想ネットワーク設定](/hardware/getting-started/pcie-mode/virtual-network)

<Tabs groupId="sima-cli-source">
<TabItem value="from-devkit" label="DevKit から" default>

スタンドアロン DevKit 上で `sima-cli` を直接実行します。DevKit がアクティブなインターネット接続を持っていることを確認し、次を実行します。

```console
modalix:~$ sima-cli update
```

MLSoC上でYoctoLinuxを実行している場合、またはModalix上でeLxr 3.0以降を実行している場合、ご自身でイメージをダウンロードしてホストしている場合は、バージョン文字列の代わりに完全なURLを指定することもできます。これには、eLxr 3.0から新しいリリースへの更新も含まれます。

```console
modalix:~$ sima-cli update http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="from-host" label="ホストマシンから">

:::note
ホストから開始されるアップデートは、MLSoC上でYocto Linuxを実行している場合、およびModalix上でeLxr 3.0以降を実行している場合にサポートされます。これには、3.0から新しいリリースへのアップデートも含まれます。Modalix上でeLxr 2.xを実行している場合は、DevKit上で直接アップデートを実行してください。3.0への移行には、上記にリンクされている変換ガイドが必要です。
:::

ホストマシンから次のコマンドを使用します。

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit}
```

このコマンドは、該当する場合、ホストに適切な Linux ドライバーバージョンもインストールします。

ファームウェアをダウンロードしてネットワーク上にホストしている場合は、URL を指定して、繰り返しインターネットからダウンロードすることを回避します。

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit} http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="download" label="ダウンロードのみ">

ファームウェアイメージをダウンロードして、手動のアップデート手順を実行する場合は、適切な Modalix ファームウェアアーカイブの URL を指定して、`sima-cli download` を実行します。

</TabItem>
</Tabs>

:::note
DevKit を **ダウングレード** するか、**最新リリースではない**ビルド (例: プレリリース版の `develop` ビルドまたは内部エンジニアリングイメージ) をインストールするには、代わりに [Net Boot Recovery](/hardware/getting-started/firmware-update/net-boot) を使用してください。これにより、DevKit がホスト上の TFTP サーバーから起動し、ターゲットイメージが eMMC に直接フラッシュされます。
:::
