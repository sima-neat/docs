# DevKit のセットアップを行います。

Modalix DevKit を箱から出してすぐに使用できるようにするには、まず [クイックスタートガイド](pathname:///tools/qsg/index.html) を参照してください。

このセクションでは、DevKit をさまざまなデプロイ環境でセットアップするための、段階的な詳細な手順を説明します。これには、**スタンドアロンモード**と**PCIeモード**が含まれます。また、最新のソフトウェアリリースとの互換性を確保するために、DevKit のファームウェアを更新する方法についても説明します。

以下のリンクを使用して、各セットアップオプションとファームウェアの更新手順の詳細な説明にアクセスしてください。

- [DevKit 3.0 クイックスタートガイド](pathname:///tools/qsg/index.html)
- [シリアル接続の設定](./setup-serial)
- [スタンドアロンモード](./standalone-mode/)
- [PCIe モード](./pcie-mode)
- [ファームウェア更新](./firmware-update/)
