# Modalix DevKit

**Modalix DevKit** は、組み込み型エッジAIアプリケーションの迅速なプロトタイピングと評価を目的とした、コンパクトで高性能な開発プラットフォームです。強力なModalix プラットフォーム上に構築されたDevKit は、高度なハードウェアアクセラレーションと最適化されたソフトウェアスタックを組み合わせることで、コンピュータービジョン、大規模言語モデル（LLM）、リアルタイムのマルチモーダル処理などのワークロードにおいて、効率的で柔軟かつスケーラブルなAI推論を実現します。

| インターフェース | 説明 |
| --- | --- |
| イーサネットポート（end0） | RJ45、1ギガビットイーサネットのネットワークインターフェース。リモート接続に使用。 |
| COMポートからホストへ（USB-C） | ホストシステムに接続することで、デバッグ作業を容易にします。 |
| MIPI インターフェース（X2） | MIPIカメラの接続用。[セットアップ](/ja/hardware/getting-started/standalone-mode/mipi-camera-interfaces) |
| USB インターフェース（4つ） | USB 3.0インターフェースを搭載し、マイク、スピーカー、およびUSBビデオカメラに対応。 |
| HDMIインターフェース（1つ） | 外部ディスプレイを接続するための HDMI 1.4（最大解像度：4K、30Hz、1080p @ 60Hz）。 |
| 内蔵ストレージ（eMMC） | 16GB |
| NVMe | M.2 512GB |
| USB | 4倍 USB 3.0ポート |

製品の詳細については、公式サイトをご覧ください：[SiMa.ai](https://sima.ai/mlsoc/)。

<TabItem value="features" label="主な機能">

| 機能 | 詳細 |
| --- | --- |
| MLA AIのパフォーマンス | INT8ニューラルネットワーク計算において、1秒あたり50テラ演算を処理可能。また、bf16の精度にも対応。 |
| 消費電力 | 作業負荷に応じて、8Wから12Wまで。 |
| アプリケーション処理ユニット（APU） | 最大1.4 GHzで動作する8個のデュアルスレッド [Arm Cortex-A65 CPU](https://www.arm.com/products/silicon-ip-cpu/cortex-a/cortex-a65) コア。 |
| ビデオエンコーダー | H.264（AVC）、H.265（HEVC）、およびMJPEGの圧縮規格に対応しています。AVCのメイン/ハイプロファイル、HEVCのメインプロファイル、およびMJPEGのベースラインプロファイルをサポートします。エンコーダーは、最大4KP60のレートでH.264/H.265をサポートします。 |
| ビデオデコーダー | H.264（AVC）、H.265（HEVC）、AV1、およびMJPEGの圧縮規格に対応しています。AVCのメイン/ハイプロファイル、HEVCのメインプロファイル、AV1のメインプロファイル、およびMJPEGのベースラインプロファイルをサポートします。4:2:0ピクセルと8ビットの精度に対応しています。デコーダーは、最大4KP60のレートでH.264/H.265をサポートします。 |
| コンピュータビジョンユニット（CVU） | 最大で**750の16ビットGOPS**をサポートする、4コアのSynopsys [ARC EV74 ビジョンプロセッサ](https://www.synopsys.com/dw/ipdir.php?ds=ev7x-vision-processors)。 |
| メモリ | 32GBのLPDDR5 RAMを搭載し、そのうち6GBはARMコアに、16GBはMLAに割り当てられます。残りの容量は、システムの他の部分に割り当てられます。 |
| 保存 | 16GBの内蔵eMMCに加えて、microSDカードスロットを搭載し、ストレージ容量を拡張可能 |
| ネットワーキング | 1つの10ギガビットイーサネットポートが、キャリアボード経由で利用可能 |

</TabItem>
