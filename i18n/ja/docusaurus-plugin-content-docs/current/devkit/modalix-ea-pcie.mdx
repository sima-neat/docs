# Modalix 早期アクセス版 PCIe カード

Modalix PCIe HHHL（ハーフハイト/ハーフレングス）早期アクセス版ボードは、高性能で、組み込み型エッジアプリケーション向けの機械学習推論を容易にするModalixデバイスを統合しています。

<Tabs>
<TabItem value="interfaces" label="インターフェース" default>

<img src="/img/devkit/modalix-ea-pcie-interfaces.jpg" alt="SiMa.ai Modalix EA PCIe カードインターフェース" style={{width: '100%', display: 'block', margin: '0 auto'}} />

| インターフェース | 説明 |
| --- | --- |
| イーサネットポート（eth0、eth1） | RJ45、ギガビットイーサネット（GigE）ネットワークインターフェース。リモート接続に使用。 |
| PCI Express 5.0 x4インターフェース | ホストシステムへの統合に使用される高速 PCIe インターフェースです。ホストの構成によっては、アダプターが必要になる場合があります。 |
| COMポートからホストへ | ホストシステムへの接続を通じて、デバッグ作業を容易にします。付属のケーブルにある矢印のマークが、正しい位置に接続されるように、最も左側のピンに接続してください。 |
| SDカードスロット | SDカードスロットは、Modalix EA PCIe カードの背面側にあります。 |
| カメラ用 GMSL2 FAKRA ポート | ギガビット・マルチメディア・シリアル・リンクは、安定した大容量のビデオ伝送を保証します。 |

</TabItem>
<TabItem value="features" label="主な機能">

| 機能 | 詳細 |
| --- | --- |
| PCIe インターフェース | 1 PCIe Gen 5.0 x4 リンクインターフェース、標準的なボードエッジコネクター搭載。 |
| システムメモリ | 高帯域幅かつ低遅延を実現するための、16GBまたは32GBのLPDDR5 DRAMインターフェース。 |
| eMMCフラッシュストレージ | 起動およびシステムストレージ用に、32GBのeMMCフラッシュメモリインターフェースを1つ搭載。 |
| QSPI NORフラッシュ | ファームウェアおよびブートローダーの保存用に、1つの128MビットQSPI NORフラッシュインターフェースを搭載。 |
| イーサネット | RJ45コネクタを介した1つの10Gbpsイーサネットインターフェース。 |
| JTAGインターフェース | ハードウェアのデバッグおよび初期設定を行うための、オプションの JTAG インターフェースが 1 つあります。 |
| マイクロSDインターフェース | 取り外し可能なストレージおよびシステム復旧用の 1 つの Micro SD カードインターフェース。 |
| デバッグ：UART（Troot） | Trootの診断およびデバッグ専用の1つのUARTインターフェース。 |
| UART のデバッグ（Linux） | Linux コンソールへのアクセスおよびデバッグ専用の UART インターフェースを1つ搭載。 |
| カメラインターフェース | シリアルリンクを介してリモートカメラを接続するための、2つのGMSL2 FAKRAポート。 |
| ステータス表示 | システムの電源状態を示すための、1つの電源LED。 |

</TabItem>
