# PCIe 模式

在 PCIe 模式下，Modalix PCIe 卡安裝在主機機器上，並透過 PCIe 提供 Modalix 推論加速功能。主機負責協調、儲存和 I/O，而卡則負責處理推論工作負載。

當 Modalix 硬體以 PCIe 卡的形式安裝，而不是作為獨立的 DevKit 運行時，請使用本節。
