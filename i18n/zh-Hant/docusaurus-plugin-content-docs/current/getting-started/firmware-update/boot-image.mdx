# 建立啟動映像

當標準更新路徑不可用或需要可移動啟動媒體時，請使用啟動映像檔。常見情況包括：

- DevKit 的內部儲存損壞或無法啟動。
- 您需要準備多個可啟動的 SD 卡或可移動磁碟以進行部署。

:::note
本指南會寫入 SiMa.ai 提供的映像檔。若要寫入您自行建置的映像檔，請參閱[將映像檔燒錄到 eMMC](/hardware/deployment/flash-image)。
:::

使用 `sima-cli bootimg` 命令來下載並將完整的開機映像檔寫入可移除裝置，例如 SD 卡或 NVMe 固態硬碟。

```console
sima-cli bootimg -v 3.0.0 --boardtype modalix
```

此命令執行以下步驟：

1. 下載適用於 Modalix 韌體 3.0.0 的可啟動映像檔。
2. 掃描您的主機，以查找可移動儲存裝置。
3. 提示您確認要寫入哪個裝置。
4. 將啟動映像檔直接寫入選定的裝置。

完成此過程後，取出 SD 卡並將其插入 DevKit。下次啟動時，DevKit 將從新的映像檔啟動。

**重要注意事項：**

- 必須在 Linux 或 macOS 主機上執行此命令。
- 需要網路連線才能下載映像檔。
