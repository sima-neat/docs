# 使用 sima-cli 更新

當 DevKit 正在執行且可透過網路存取時，請使用 `sima-cli update`。此方法會下載韌體映像，並在 DevKit 上觸發更新。

:::note
`sima-cli update` 只會安裝 SiMa.ai 官方建置版本。如果您使用自行建置的映像檔，請改為參閱[將映像檔燒錄到 eMMC](/hardware/deployment/flash-image)。
:::

:::note
執行 2.x 韌體的 DevKit 無法使用此更新機制直接升級到 3.0。請先按照 [從 2.1.3 升級到 3.0.0](/hardware/reference/tech-notes/convert-2-1-3-to-3-0-0) 的步驟進行轉換。轉換完成後，使用 `sima-cli update` 從 eLxr 3.0 升級到更新的版本。
:::

在繼續之前，請確認主機可以透過網路存取 DevKit。請參閱：

- [獨立模式網路設定](/hardware/getting-started/standalone-mode/network)
- [PCIe 模式虛擬網路設定](/hardware/getting-started/pcie-mode/virtual-network)

<Tabs groupId="sima-cli-source">
<TabItem value="from-devkit" label="從 DevKit" default>

直接在獨立 DevKit 上執行 `sima-cli`。請確保 DevKit 具有有效的網際網路連線，然後執行：

```console
modalix:~$ sima-cli update
```

在執行 Yocto Linux 的 MLSoC 主機上，以及在執行 eLxr 3.0 或更高版本的 Modalix 主機上，如果您已自行下載並託管映像檔，您可以指定完整的 URL，而不是版本字串。這包括從 eLxr 3.0 更新到更新的版本。

```console
modalix:~$ sima-cli update http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="from-host" label="從主機">

:::note
在執行 Yocto Linux 的 MLSoC 上，以及在執行 eLxr 3.0 或更高版本的 Modalix 上，都支援主機發起的更新，包括從 3.0 更新到更新的版本。對於執行 eLxr 2.x 的 Modalix，請直接在 DevKit 上執行更新；升級到 3.0 需要參考上述連結中的轉換指南。
:::

從主機執行以下命令：

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit}
```

如果適用，此命令還會在主機上安裝適當的 Linux 驅動程式版本。

如果您已下載韌體並在您的網路中託管，請提供 URL 以避免重複下載。

```console
sima-user@sima-user-machine:~$ sima-cli update --ip {ip_address_of_the_devkit} http://your-server/image.tar.gz
```

</TabItem>
<TabItem value="download" label="僅下載">

若要僅下載韌體映像以進行手動更新步驟，請使用適當的 Modalix 韌體檔案的 URL 執行 `sima-cli download`。

</TabItem>
</Tabs>

:::note
若要**降級** DevKit 或安裝**非最新版本**的建置（例如，預發布的 `develop` 建置或內部工程映像），請改用 [網路啟動恢復](/hardware/getting-started/firmware-update/net-boot)。它會從主機上的 TFTP 伺服器啟動 DevKit，並直接將目標映像閃存到 eMMC。
:::
