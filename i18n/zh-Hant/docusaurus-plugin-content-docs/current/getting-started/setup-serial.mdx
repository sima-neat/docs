# 設定序列埠連線

在啟動過程中，無論您使用獨立模式還是 PCIe 模式，都請連接到 DevKit 的序列埠介面。

在獨立模式下，序列存取功能可讓您配置、監控和恢復 DevKit，即使在無法使用網路或網路配置錯誤時也能進行操作。

在 PCIe 模式下，序列介面可讓您在系統啟動時直接存取 PCIe 卡外殼和除錯主控台。請在主機驅動程式或 PCIe 連線完全運作之前，使用它進行低階控制和疑難排解。

序列存取主要用於開發和啟動階段。部署完成後，正常運作通常不需要序列連接。

為您的硬體選擇電纜配置，然後為您的電腦選擇序列終端方法。

## 開啟一個序列終端機

<Tabs>
<TabItem value="mac-linux" label="macOS & Linux" default>

:::note
請先安裝或升級 `sima-cli`，再繼續操作。本指南適用於最新版本的 `sima-cli`。
:::

在 macOS 或 Linux 上，使用 `sima-cli serial` 連接到序列埠。

```console
sima-cli serial
```

此指令會安裝存取序列埠所需的相依性。若要離開序列終端機，請按下 Ctrl + A，然後按下 Ctrl + X。

在某些較早的韌體版本中，系統可能使用不同的波特率來進行序列控制台通訊。如果您在終端中看到亂碼輸出，很可能是由於波特率不匹配所致。請嘗試指定更高的波特率：

```console
sima-cli serial -b 921600
```

</TabItem>
<TabItem value="windows" label="Windows">

若要從 **Windows** 連接到 DevKit，請遵循以下步驟：

1. 識別 COM 埠：
   - 開啟「裝置管理員」，然後展開「埠（COM 與 LPT）」。
   - 尋找類似於「**USB 序列埠 (COMx)**」的條目。

2. 安裝並開啟一個序列終端：
   - 使用 [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html) 或 **Tera Term**。
   - 將連線類型設定為「序列」。
   - 請輸入正確的 **COM 埠**（例如：`COM3`）。
   - 將「波特率」設定為 `115200`。

3. 點擊「**開啟**」以啟動連線。

</TabItem>
<TabItem value="web-serial" label="Web Serial Console">

**網頁序列埠控制台**是一個基於瀏覽器的替代方案，無需本地安裝。在 Chromium 瀏覽器中開啟它，透過 USB 連接 DevKit，然後連接到序列埠控制台。

</TabItem>
</Tabs>
