# 設定您的 DevKit

若要讓您的 Modalix DevKit 能夠立即使用，請從 [快速入門指南](pathname:///tools/qsg/index.html) 開始。

本節提供逐步的進階指南，說明如何在不同的部署情境中設定 DevKit，包括**獨立模式**和**PCIe 模式**。它還涵蓋如何更新 DevKit 的韌體，以確保與最新軟體版本的相容性。

請使用以下連結，以存取每個設定選項和韌體更新程序的詳細說明。

- [DevKit 3.0 快速入門指南](pathname:///tools/qsg/index.html)
- [設定序列連線](./setup-serial)
- [獨立模式](./standalone-mode/)
- [PCIe 模式](./pcie-mode)
- [韌體更新](./firmware-update/)
