# PCIe 模式

<Tabs>
<TabItem value="prereq" label="先決條件" default>

:::note
請在繼續操作之前安裝或升級 `sima-cli`。本指南適用於最新版本的 `sima-cli`。
:::

在您開始之前：

- 支援的主機平台：Ubuntu 22.04 LTS。
- 目前，Windows 10/11 主機的支援功能正處於測試階段。
- 請設定您的主機的 UEFI/BIOS 設定，以達到最佳效能並確保驅動程式能正常運作。
  - 在 Intel 架構的機器上，啟用 SRIOV、IOMMU 和 VT-D。
  - 在搭載 AMD 處理器的電腦上，請停用 AMD-V 並啟用 IOMMU。

</TabItem>
<TabItem value="hardware" label="硬體準備">

![SiMa.ai MLSoC PCIe 卡的 PCIe DIP 開關](/img/devkit/pcie-dip-switch.png)

1. 在 MLSoC PCIe 卡上，有四個撥動開關，如上圖所示。請確認開關 #1 處於 `OFF` 位置。
2. 請確認「執行/程式」開關已開啟。
3. 關閉主機，將 DevKit 插入 PCIe 插槽，然後開啟主機。
4. 在 Modalix 早期版本 PCIe 卡上，請將 DIP 開關保持在其出廠預設位置。
5. 如果主機主機板同時提供一個主要（藍色）和一個非主要（黑色）的 PCIe 插槽，請將 SiMa PCIe 卡安裝在次要（黑色）插槽中。
6. 建議將卡片的序列連接器（即 UART 連接器）連接到主機，以便進行啟動和除錯。
7. 這張 PCIe 卡還配備了一個實體乙太網路連接埠，以便直接存取網路。

如需更詳細地了解 DevKit 的介面、開關和連接器，請參閱 [SiMa.ai DevKit 介面](/hardware/devkit/modalix-ea-pcie)。

:::note
在極少數情況下，如果您不需要在主機重新啟動時自動載入驅動程式，請建立（或編輯，如果檔案已存在）`/etc/modprobe.d/blacklist.conf`，並新增一行，內容為 blacklist `sima_mla_drv`。完成後，執行 `update-initramfs`，然後重新啟動主機。重新啟動後，可以使用 `insmod` 或 `modeprobe` 手動載入驅動程式。
:::

</TabItem>
<TabItem value="driver-linux" label="驅動程式安裝 (Linux)">

在 Linux 主機上執行以下指令，以安裝最新的驅動程式。

```console
sima-user@sima-user-machine:~$ sima-cli install drivers/linux
... ... ...
=== Driver Installation Validation ===
  Component            | Status     | Details
  ----------------------------------------------------------------
  GStreamer            | PASS       | ✅ GStreamer plugin 'pciehost' installed
  Kernel Module        | PASS       | ✅ Kernel module 'sima_mla_drv' installed
  PCI Devices          | PASS       | ✅ Detected SiMa PCIe device(s):
  - 0000:04:00.0 Modalix HHHL v2              driver=sima_mla_drv

✅ Installation complete.
```

若要安裝特定版本的驅動程式，請使用 `-v` 參數：

```console
sima-user@sima-user-machine:~$ sima-cli install drivers/linux -v 2.1.0
```

:::note
在安裝驅動程式後，請在進行驗證之前，先重新啟動主機。
:::

:::warning
針對 **MLSoC PCIe 卡**的 PCIe 驅動程式支援已於 SDK 2.0.0 中結束。上述指令安裝的驅動程式僅支援 **Modalix**。如果您使用的是 MLSoC PCIe 卡，請使用 `sima-cli install drivers/linux -v 2.0.0` 安裝 2.0.0 驅動程式。
:::

## 虛擬網路 {#virtual-network}

:::note
「虛擬網路」功能可在 Linux 主機的韌體版本 `1.5` 或更高版本中使用。若要使用此功能，請確認您的 DevKit 已更新至最新的韌體版本 [已更新](/hardware/getting-started/firmware-update/)。

此功能僅適用於 Linux 主機系統。
:::

當透過 PCI Express (PCIe) 連接到主機系統時，SiMa.ai DevKit 會建立一個虛擬乙太網路介面。此介面可讓主機與 DevKit 透過高速 PCIe 匯流排進行直接的網路通訊。

「虛擬網路」功能主要設計用於除錯目的，讓使用者能夠：

- **安全殼層 (SSH)**：遠端存取 DevKit 的命令列介面，以進行疑難排解和系統管理。
- **安全複製協定 (SCP)**：安全地在主機和 DevKit 之間傳輸檔案，以便在開發和除錯過程中，輕鬆地移動日誌、設定和其他必要的檔案。

此功能還能讓使用者：

- **更新韌體**：在遵循「檔案複製方法」時，使用 `scp` 和 `ssh` 工具，手動更新韌體。
- **設定靜態 IP 位址（透過 PCIe 的乙太網路）**：手動為您的主機機器／MLSoC 裝置設定靜態 IP 位址。

預設情況下，`10.0.cardnum.1` 位址會指派給主機，而 `10.0.cardnum.2` 會指派給 MLSoC 裝置。然而，為了確保網路的穩定性和一致性，您必須停用預設 IP 位址，該位址會指派給主機介面。具體做法是在載入模組時，傳遞模組參數 `default_ip=false`。

如果模組已經載入，請先移除，然後使用 `default_ip=false` 參數重新載入，如下所示：

```console
sudo modprobe -r sima_mla_drv
sudo modprobe sima_mla_drv default_ip=false
```

**持續性設定**

為了確保 `default_ip=false` 設定在系統重新啟動後仍然有效，請遵循以下步驟：

1. 建立一個包含必要選項的 modprobe 設定檔：

   ```console
   echo "options sima_mla_drv default_ip=false" | sudo tee /etc/modprobe.d/sima_mla_drv_options.conf
   ```

2. 更新初始 RAM 檔案系統，以包含新的設定：

   ```console
   sudo update-initramfs -u
   ```

3. 重新啟動主機以應用變更：

   ```console
   sudo shutdown -r now
   ```

4. 系統重新啟動後，請確認參數是否已正確設定：

   ```console
   cat /sys/module/sima_mla_drv/parameters/default_ip
   ```

**手動指定 IP 位址**

當您手動載入模組時（使用 `insmod`），請使用以下指令。這可讓您手動將靜態 IP 位址指派給主機機器介面，進而指派給 MLSoC 裝置。

```console
sudo insmod sima_mla_drv.ko default_ip=false
```

這也需要主機具備已安裝的 `ifconfig` 工具。

```console
ifconfig <eth interface> 20.1.2.1
```

一旦將 IP 位址指派給主機介面，系統就會自動將 IP + 1 指派給 SoC 介面。例如，如果將 `20.1.2.1` 指派給主機，則 MLSoC 的 IP 將會是 `20.1.2.2`。

當建立介面時，主機介面將具有格式為 `cardnum:S:I:m:A:0` 的 MAC 位址，而 SoC 介面將具有 MAC 位址 `cardnum:S:I:m:A:1`。IP 位址會在建立時指派，分別為 `host:10.0.cardnum.1` 和 `soc:10.0.cardnum.2`。此外，這也要求主機必須安裝 `ifconfig` 工具。

1. 在主機上執行的 `ifconfig` 指令的輸出結果：

   ```console
   enp2s0: flags=4163<UP,BROADCAST,RUNNING,MULTICAST>  mtu 65536
       inet 10.0.0.1  netmask 255.255.255.0  broadcast 10.0.0.255
       inet6 fe80::253:49ff:fe4d:4130  prefixlen 64  scopeid 0x20<link>
       ether 00:53:49:4d:41:30  txqueuelen 1000  (Ethernet)
       RX packets 14107  bytes 4460994 (4.4 MB)
       RX errors 0  dropped 0  overruns 0  frame 0
       TX packets 818  bytes 74840 (74.8 KB)
       TX errors 0  dropped 0 overruns 0  carrier 0  collisions 0
   ```

2. `ifconfig` 在 SiMa.ai DevKit 上的輸出：

   ```console
   eth2: flags=4163<UP,BROADCAST,RUNNING,MULTICAST>  mtu 65536
       inet 10.0.0.2  netmask 255.255.255.0  broadcast 10.0.0.255
   ```
