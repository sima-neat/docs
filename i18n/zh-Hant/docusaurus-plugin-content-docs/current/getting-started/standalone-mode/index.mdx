# 獨立模式

在獨立模式下，Modalix DevKit 作為一個獨立的邊緣設備運行。它接收來自感測器、相機、儲存裝置或網路介面的資料，在本地進行處理，並透過網路傳送結果。

當 DevKit 未作為 PCIe 卡安裝在主機機器上時，請使用本節。
