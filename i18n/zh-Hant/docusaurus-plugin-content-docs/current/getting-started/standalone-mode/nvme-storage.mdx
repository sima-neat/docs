# NVMe 儲存空間

**Modalix DevKit** 包含一個 500GB 的 NVMe 儲存裝置。如果您需要更大的儲存容量，請將預先安裝的儲存裝置替換為與主機板相容的 M.2 NVMe 模組。

:::note
請在繼續操作之前安裝或升級 `sima-cli`。本指南適用於最新版本的 `sima-cli`。
:::

:::note
這個指令必須直接在 Modalix DevKit 上執行。
:::

若要格式化 NVMe 磁碟，請執行：

```console
modalix:~$ sima-cli nvme format
```

格式化完成後，NVMe 磁碟機會掛載到 `/media/nvme`。

若要驗證掛載狀態並查看儲存空間使用情況，請執行：

```console
modalix:~$ df -h
```

這個指令會顯示所有已掛載檔案系統中可用的磁碟空間，包括 NVMe 磁碟機。

若要重新掛載 NVMe 磁碟機，請執行：

```console
modalix:~$ sima-cli nvme remount
```

這個 `format` 以及 `remount` 指令會將一筆資料新增到 `/etc/fstab` 因此 NVMe 開機時，磁碟機會自動掛載。
