# SiMa.ai 硬體檔案

本指南涵蓋硬體設定、韌體以及 SiMa.ai 的 MLSoC Modalix DevKit 產品的低階介面。這是一份專用的硬體參考資料，軟體、機器學習和管線工具則分別以不同的檔案呈現。

## 關於 MLSoC 和 Modalix

**MLSoC Modalix** 是 SiMa.ai 的第二代機器學習系統晶片。它結合了一個 Arm Cortex-A65 應用處理器、一個高吞吐量的機器學習加速器 (MLA)、一個用於相機輸入的影像訊號處理器 (ISP)，以及一個用於傳統視覺工作負載的電腦視覺單元 (CVU)——所有這些都整合在單一晶片上。

這種整合讓開發人員可以在邊緣部署多模態、生成式和視覺 AI 管線，而無需將個別的加速器、主機 CPU 和相機橋接器組合在一起。這裡記錄的每個產品——DevKit、早期存取套件以及 PCIe 卡——都是基於相同的 MLSoC Modalix 矽晶片建置的，因此為某種外觀形式編寫的應用程式可以輕鬆地移植到其他外觀形式。

## 部署架構

現代機器學習和推理應用程式需要具備彈性的架構，以應對各種部署情境。SiMa.ai 的解決方案旨在適應這些需求，提供可最佳化效能、效率和可擴展性的設定。無論是整合到更大的系統中，還是作為獨立設備使用，MLSoC Modalix 都能確保針對各種使用案例實現無縫的適應性。

<Tabs>
<TabItem value="standalone" label="MLSoC Modalix 作為獨立裝置" default>

在這個架構中，MLSoC Modalix 作為一個獨立的、自成一體的裝置運作。它特別適合於需要小型化、高效能和盡可能降低功耗的應用。

**主要應用案例**

- **Edge AI 應用**：部署於邊緣端，可在無需依賴中央伺服器或雲端基礎架構的情況下執行推論。非常適合智慧攝影機、工業物聯網裝置或自主機器人等應用。
- **考量成本的部署**：減少對額外硬體的需求，使其成為一種具有成本效益的解決方案，適用於獨立作業。
- **電力受限環境**：針對能源效率至關重要的情境進行最佳化，例如由電池或太陽能板供電的遠端監控系統。

**優點**

- **獨立運行**：無需主機系統，可簡化部署流程並降低系統複雜度。
- **節能高效**：設計時注重降低功耗，使其適用於對電力敏感的環境。
- **體積小巧且易於攜帶**：其小巧的尺寸使其能夠輕鬆地部署在空間有限的環境中。

**典型的資料流程**

1. 資料會直接從網路介面或感測器接收。
2. MLSoC Modalix 內建一個 [NEAT 應用程式](https://docs.sima-neat.com)，用於定義裝置上的推論管線。
3. MLSoC 和 Modalix 會執行推論，並在本地處理資料。
4. 結果會透過網路連線傳送到其他裝置或系統，以便進行後續處理或視覺化呈現。

<a className="docs-button" href="/hardware/getting-started/standalone-mode">使用 DevKit 設定獨立模式系統。</a>

</TabItem>
<TabItem value="pcie" label="MLSoC 作為 Modalix PCIe 卡">

在這個架構中，MLSoC Modalix 就像一張 PCIe 卡，可以無縫地整合到主機系統中。這種設定非常適合需要額外運算資源來執行推論任務，但同時又具備足夠的資料儲存和處理能力的主機系統，例如伺服器、桌上型電腦或工作站。

**主要應用案例**

- **高效能系統：** 適用於資料中心或高階工作站，在這些環境中，大規模資料處理和儲存至關重要。主機系統負責處理需要大量 CPU 運算的任務，而 MLSoC Modalix 則執行專用的推論作業。
- **擴展的 I/O 解決方案：** 目標系統可能需要額外的 I/O 功能，而這些功能在 MLSoC Modalix 上並非隨時可用，例如 USB 介面或其他感測輸入。此架構使系統能夠利用主機系統的擴展 I/O 資源，以支援諸如影片分析或大規模 AI 模型推論等應用。

**優點**

- **強化運算資源：** 透過將推論任務卸載到專用硬體，來擴充主機系統的功能。
- **靈活性：** 適用於需要根據需求增加額外推論卡片的環境。

**典型的資料處理流程**

1. 主機系統會從感測器、周邊設備、儲存裝置或網路介面擷取資料。
2. MLSoC Modalix 內含一個 [NEAT 應用程式](https://docs.sima-neat.com)，用於封裝推理管線和經過調整的 AI 模型。
3. 資料會透過 PCIe 介面傳送到 MLSoC 的 Modalix，以進行推論。
4. 結果會由主機系統處理，或轉送至後端系統以進行後續操作。
