SiMa.ai 以晶片、模組與完整產品等形式提供 MLSoC Modalix。請從您現有或計畫採用的外形規格開始。

| 產品 | 說明 | 從這裡開始 |
| --- | --- | --- |
| MLSoC Modalix | 系統單晶片。您將它放在自行設計的電路板上。 | [以 SoC 進行設計](/hardware/design/chip-down) |
| Modalix SoM | 搭載 SoC、LPDDR5 記憶體與電源的模組，可插入載板使用。 | [整合 SoM 與載板](/hardware/design/carrier-board) |
| Modalix DevKit | 將 Modalix SoM 安裝於載板並置於機殼內，用於評估與開發。 | [評估與使用 DevKit](/hardware/getting-started) |
| Modalix PCIe 卡 | 半高半長的介面卡，可為主機加入 Modalix 推論能力。 | [PCIe 模式](/hardware/getting-started/pcie-mode) |

### SoM 或 Chip-Down {#som-or-chip-down}

若要打造您自己的硬體，請在 Modalix SoM 的載板與直接搭載 SoC 的電路板之間擇一。兩者所需的設計工作、技術資料與硬體啟動流程都不相同。

| | Chip-down 設計 | 載板設計 |
| --- | --- | --- |
| 您要設計的內容 | 搭載封裝後 Modalix SoC 的電路板，包括記憶體、電源與時脈 | Modalix SoM 的載板；SoM 本身已包含 SoC、LPDDR5 與電源 |
| 主要設計工作 | 電源時序、時脈與重置、LPDDR5 佈線與調校、高速電路佈局、介面、散熱 | 連接器腳位對應、電源供應、介面、散熱 |
| 技術資料 | Chip-down 設計指南、SoC 資料手冊與設計套件，簽署 NDA 後可向 SiMa.ai 取得 | 公開的資料手冊與硬體啟動指南 |
| 軟體起點 | Modalix BSP，並進行板級調整 | Modalix BSP，並針對您的載板修改 device tree |

電路板能夠開機之後，兩條路徑都使用相同的系統軟體。請參閱[建置與部署自訂系統軟體](/hardware/software)。

## 關於 MLSoC Modalix

**MLSoC Modalix** 是 SiMa.ai 的第二代機器學習系統晶片。它結合了一個 Arm Cortex-A65 應用處理器、一個高吞吐量的**機器學習加速器 (MLA)**、一個用於相機輸入的**影像訊號處理器 (ISP)**，以及一個用於傳統視覺工作負載的**電腦視覺單元 (CVU)**——所有這些都整合在單一晶片上。

此整合功能讓您可以在邊緣端執行多模態、生成式和視覺 AI 管線，而無需整合個別的加速器、主機 CPU 和相機橋接器。Modalix SoM 將 MLSoC Modalix 包裝起來，以便與載板和產品整合，並且這裡記錄的每個 DevKit 都使用相同的矽晶片。

## 部署架構

MLSoC Modalix 支援兩種常見的開發架構：獨立模式和 PCIe 模式。請選擇與您的硬體連接方式以及應用程式運行位置相符的架構。

<Tabs>
<TabItem value="standalone" label="獨立模式" default>

在獨立模式下，一個 Modalix DevKit 或一個自訂的基於 Modalix SoM 的系統將作為一個獨立的設備運行。當設備直接從感測器、相機、儲存裝置或網路介面接收資料時，請使用此模式。

**主要應用場景**

- **邊緣 AI 應用**：無需依賴中央伺服器或雲端基礎架構即可執行推論。
- **精簡部署**：減少對額外主機硬體的需求。
- **電力受限系統**：支援由電池或太陽能板供電的遠端監控系統。

**優點**

- **獨立運行**：無需依賴主機機器即可運行。
- **節能高效**：支援對電力敏感的環境。
- **精簡**：適用於空間有限的部署環境。

**典型資料流程**

1. DevKit 直接從網路介面或感測器接收資料。
2. DevKit 會載入一個定義裝置端推論管線的 [NEAT 應用程式](https://developer.sima.ai/software)。
3. MLSoC Modalix 會在本機執行推論並處理資料。
4. 結果會透過網路連線傳送到其他裝置或系統，以進行後續處理或視覺化呈現。

<a className="docs-button" href="/hardware/getting-started/standalone-mode">設定獨立模式</a>

</TabItem>
<TabItem value="pcie" label="PCIe 模式">

在 PCIe 模式下，Modalix PCIe 卡會安裝在主機機器中。當伺服器、桌面電腦或工作站處理協調、儲存和 I/O 時，請使用此模式，而該卡則提供 Modalix 推論加速功能。

**主要應用場景**

- **高效能系統：** 使用資料中心伺服器或工作站進行資料處理和儲存，同時讓 Modalix PCIe 卡執行推論。
- **主機管理的 I/O：** 使用主機儲存、網路或感測器輸入，同時將推論任務卸載到卡上。

**優點**

- **專用加速：** 將推論作業從主機 CPU 卸載到 Modalix 硬體。
- **可擴展容量：** 隨著需求的增加，您可以新增推論卡。

**典型資料處理流程**

1. 主機機器會從感測器、周邊裝置、儲存裝置或網路介面擷取資料。
2. Modalix PCIe 卡載入一個 [NEAT 應用程式](https://developer.sima.ai/software)，該應用程式封裝了推論管線和經過調整的 AI 模型。
3. 主機透過 PCIe 將資料傳送到 Modalix PCIe 卡。
4. 主機會處理結果或將其轉送至後端系統。
