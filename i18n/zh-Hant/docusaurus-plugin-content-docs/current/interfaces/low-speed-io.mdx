# 低速 I/O

Modalix 具備**兩個專用 SPI 通道**以及**八個可設定的 SIO 區塊**。每個 SIO 區塊都可設定為提供 GPIO、UART、I2C 或 SPI 功能，並由輸出腳位多工器選擇要將哪個功能送到各個腳位。

## 腳位對應準則

指派 SIO 腳位時：

1. 請先選定您要使用的乙太網路與 PCIe 通道：部分腳位功能是預先定義的，必須搭配對應的 PCIe 與乙太網路介面使用。
2. 在每個 SIO 區塊中，**上方列的腳位具有優先權**，應優先考慮。
3. 請使用 **Function** 欄中所列的功能，讓所選介面與該腳位可用的功能相符。

## GPIO

**驅動程式：** `gpio-dwapb`

在使用者空間中，請使用 **libgpiod** 及其命令列工具：

| 工具 | 用途 |
| --- | --- |
| `gpiodetect` | 列出可用的 GPIO 晶片 |
| `gpioinfo` | 列出晶片與線路，以及其狀態和所屬的驅動程式 |
| `gpioset` | 設定線路的值 |
| `gpioget` | 讀取線路的值 |

請先確認晶片與線路；裝置會顯示為 `/dev/gpiochip0` 等名稱：

```console
root@modalix:~# gpiodetect
root@modalix:~# gpioset gpiochip0 17 1
root@modalix:~# gpioget gpiochip0 17
```

開發自訂應用程式時，請使用 **libgpiod C API**，而不是呼叫命令列工具。

Binding：[`snps,dw-apb-gpio.yaml`](https://github.com/SiMa-ai/simaai-linux/blob/master/Documentation/devicetree/bindings/gpio/snps,dw-apb-gpio.yaml)

## UART

**驅動程式：** `snps-dw-apb-uart`

UART 節點的名稱標示了其 SIO 區塊與索引：`uart12` 代表 SIO 區塊 1、索引 2。每個 SIO 區塊最多提供 **4 個 UART 連接埠**，每個連接埠佔用 2 個腳位，因此索引 2 對應到輸出腳位 4 與 5。

```dts
uart12: uart@0x0401a000 {
    compatible = "snps,dw-apb-uart";
    reg = <0x0 0x0401a000 0x0 0x100>;
    interrupts = <GIC_SPI 319 IRQ_TYPE_LEVEL_HIGH>;
    reg-io-width = <4>;
    reg-shift = <2>;
    clocks = <&sio10_clk SIMAAI_SIO_DEV_UART2>;
    resets = <&reset10 SIMAAI_SIO_DEV_UART2>;
    pinctrl-0 = <&pins_uart12_deafult>;
    pinctrl-names = "default";
    dmas = <&dmac10 4>, <&dmac10 5>;
    dma-names = "tx", "rx";
    status = "disabled";
};
```

從 overlay 啟用它：

```dts
&uart12 {
    status = "okay";
};
```

時脈、重設及其他設定也可以在同一個 overlay 中覆寫。每個 SIO 區塊都有各自的時脈、重設、腳位與 DMA 控制器，並由上方的節點參照。

Binding：[`snps-dw-apb-uart.yaml`](https://github.com/SiMa-ai/simaai-linux/blob/master/Documentation/devicetree/bindings/serial/snps-dw-apb-uart.yaml)

## I2C

40 針排針（Waveshare 載板上的 J12）上引出了兩個 I2C 介面。

### 確認匯流排

```console
root@modalix:~# ls /dev/i2c-*
/dev/i2c-0
/dev/i2c-1
```

### 驅動程式與 Device Tree

I2C GPIO 擴充器由 **PCF857x** 驅動程式支援，並已在 `arch/arm64/configs/simaai_modalix_defconfig` 中啟用：

```text
CONFIG_GPIO_PCF857X=y
```

此驅動程式涵蓋 NXP PCF8574 與 PCF8575 I2C GPIO 擴充器，請參閱 [`simaai_modalix_defconfig`](https://github.com/SiMa-ai/simaai-linux/blob/master/arch/arm64/configs/simaai_modalix_defconfig)。以下範例啟用匯流排 0 並連接一顆 PCF8574：

```dts
&i2c00 {
    status = "okay";
    clock-frequency = <400000>;

    pcf8574: gpio@27 {
        compatible = "nxp,pcf8574";
        reg = <0x27>;
        gpio-controller;
    };
};
```

### 命令列工具

`i2c-tools` 已包含在標準建置中；若缺少，請自行安裝：

```console
root@modalix:~# apt update
root@modalix:~# apt install i2c-tools
```

Binding：[`snps,designware-i2c.yaml`](https://github.com/SiMa-ai/simaai-linux/blob/master/Documentation/devicetree/bindings/i2c/snps,designware-i2c.yaml) 與 [`nxp,pcf8575.yaml`](https://github.com/SiMa-ai/simaai-linux/blob/master/Documentation/devicetree/bindings/gpio/nxp,pcf8575.yaml)

`i2cdetect` 會探測匯流排上的每個位址，並回報哪些裝置有回應。`-r` 使用 SMBus read-byte 方式探測，`-y` 會略過確認提示，最後一個引數則是匯流排編號：

```console
root@modalix:~# i2cdetect -r -y 0
```

## SPI

除了設定為 SPI 的 SIO 區塊之外，Modalix 還具備兩個專用 SPI 通道。NVS SPI 與 SIO SPI 路徑的裝置 overlay，以及 SPI 裝置驅動程式與 device tree binding，都遵循上方 UART 所示的相同 overlay 模式。
