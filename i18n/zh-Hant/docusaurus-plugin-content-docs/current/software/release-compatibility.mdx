# 版本相容性

每個 Modalix 平台版本都是由公開的核心與 U-Boot 儲存庫中的某一個 commit 建置而成。若要重新建置與電路板上映像檔相符的元件，請在建置前先 check out 該版本對應的 commit。請參閱[從原始碼建置 BSP](./build-from-source.mdx)。

## 如何解讀此表

- 這些儲存庫沒有版本標籤。每個版本都是 `master` 上的單一 commit，標題為 `SiMa.AI Release <version>`。
- `master` 永遠是最新版本。若為執行較舊版本的電路板建置它，所得到的核心或開機載入程式會與該電路板的根檔案系統及模組不相符。
- 在執行中的電路板上，可使用 `cat /etc/buildinfo` 查詢版本。

若要 check out 某個版本：

```console
root@sdk:/data/simaai-linux$ git checkout 65aba29989da
```
