# Modalix DevKit 介面支援情形

本頁列出 Modalix DevKit 的介面。每個介面都會說明電路板上的連接器、其背後的 Modalix SoM 訊號，以及平台版本 2.1.3 的 device tree 如何處理。DevKit 是將 Modalix SoM 安裝在 Waveshare 載板上的產品，因此本表僅適用於這個組合。

:::caution[尚未在硬體上驗證]
本頁依據平台版本 2.1.3 的核心原始碼與本網站的其他頁面撰寫，目前尚無任何一列有硬體測試紀錄。
:::

## 介面 {#interfaces}

本表涵蓋序列主控台、Gigabit Ethernet、USB、HDMI、NVMe 儲存裝置、MIPI CSI-2 相機、I2C、GPIO、SPI、I2S 音訊、Bluetooth、eMMC、即時時鐘與 CAN。若介面有對應的指南，其名稱會連結至該指南。

## 如何閱讀狀態 {#status}

- **支援**：此版本在這塊電路板上提供該介面。可能是 SoM 的 device tree 已啟用，或是該元件位於 SoM 上而不需設定。
- **需要 overlay**：硬體已具備，但此版本的 device tree 未啟用。請依照 [Device Tree 與 Overlay](../software/device-tree.mdx) 的說明加入 device tree overlay。
- **不支援**：該介面無法搭配 Modalix SoM 運作。
- **尚未確認**：本頁沒有相關資訊。

## 其他電路板 {#other-boards}

SoM 訊號在每款載板上都相同，但連接器與 overlay 不同。若使用其他載板，請從[第三方載板](../design/third-party-carriers.mdx)與[載板硬體啟動](../design/som-carrier.mdx)開始。
