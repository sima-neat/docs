# 從 2.1.3 升級到 3.0.0。

此程序適用於 **Modalix SoM DevKit** 和 **Modalix PCIe 卡**。大多數新板卡在工廠預先安裝了 **2.1.x** 韌體。

**2.1.x** 版本使用與 **Debian 12** 相容的系統映像。**3.0.0** 版本則改用 **Debian 13**。此外，它還包含對 **OverlayFS**、**A/B 映像**和 **SWUpdate** 的系統變更。

這些變更使 3.0.0 系統映像與 2.1 系統映像不相容。轉換需要特殊的更新程序。首先，將板卡更新到最新的 **2.1.3** 韌體。然後，使用 **netboot** 透過網路啟動板卡，並將 3.0.0 映像寫入其儲存空間。

本文使用以下術語：

- **板卡**：SoM DevKit 或 PCIe 卡。
- **主機**：透過 TFTP 伺服器提供啟動映像檔的 Ubuntu 或 macOS 電腦。
- **燒錄**：將系統映像寫入板卡的儲存空間。

## 在您開始之前

- 備份您從板卡上需要的檔案和設定。
- 請確認板卡已連線至網際網路，以便進行 2.1.3 版的更新。
- 請確認主機已連上網際網路，以便進行 CLI 更新和下載映像檔。
- 請在主機上使用 **sima-cli 2.1.19 或更高版本**。如果主機可以存取網際網路，`sima-cli` 會自動更新到最新版本。
- 準備好板卡與主機之間的乙太網路連線。
- 如果可以，請準備好序列連接，以便監控板卡。

若要將最新版的 `sima-cli` 安裝在**主機**上，請執行：

```bash
curl -fsSL https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh | bash
```

## 1. 將板卡更新至 2.1.3。

請在板卡上執行本節中的指令。

1. 透過 SSH 或序列埠連接到板卡。
2. 檢查韌體版本：

   ```bash
   cat /etc/buildinfo
   ```

   如果您的板卡已安裝最新版本的 **2.1.3**，請前往第 2 節。

3. 安裝最新版的 `sima-cli`：

   ```bash
   curl -fsSL https://artifacts.neat.sima.ai/sima-cli/linux-mac.sh | bash
   ```

4. 開始韌體更新：

   ```bash
   sima-cli update
   ```

5. 請依照螢幕上的指示，安裝最新的 **2.1.3** 版本。
6. 在收到指示時重新啟動板卡。
7. 請再次檢查 `/etc/buildinfo`，以確認板卡是否正在執行 **2.1.3**。

## 2. 將板卡連接到主機。

建議使用直接的乙太網路連線，並啟用網際網路共用功能。

1. 將板卡的乙太網路埠連接到主機。
2. 在主機上啟用網際網路共用：
   - **Ubuntu**：請依照 [網路設定](/hardware/getting-started/standalone-mode/network) 中的「共享連線」程序操作。
   - **macOS**：啟用乙太網路介面的網際網路共用功能，該介面連接到板卡上。

或者，將兩個系統連接到同一個網路。主機必須能夠連線到板卡。板卡必須能夠連線到主機的 TFTP 伺服器。

### 尋找板卡的 IP 位址。

啟用網際網路共用功能後，主機會為板卡指派一個 IP 位址。請使用序列主控台來找出這個位址。

1. 將板卡的序列埠連接到主機。請參閱 [序列連接](/hardware/getting-started/setup-serial)。
2. 在**主機**上開啟終端機，然後執行：

   ```bash
   sima-cli serial
   ```

3. 登入板卡。
4. 請在**板卡上**執行這個指令：

   ```bash
   /sbin/ifconfig
   ```

5. 找出與主機連線的乙太網路介面。
6. 記錄其 IPv4 位址，該位址顯示在 `inet` 之後。請勿使用迴路位址 `127.0.0.1`。
7. 在主機的另一個終端機中，檢查連線：

   ```bash
   ping {ip}
   ```

將所有指令中的 `{ip}` 替換為記錄的位址。請保持序列主控台開啟，以便監控轉換過程。

### 沒有序列存取功能的 PCIe 擴充卡

PCIe 卡上的序列埠可能不易觸及。如果您無法連接序列線，請使用以下靜態 IP 位址方法。

如果 PCIe 卡（版本為 **2.1.3**）未收到 IP 位址，則會使用 **192.168.1.10**。

1. 將卡上的乙太網路連接埠直接連接到主機。
2. 將主機的已連接乙太網路介面設定為 **192.168.1.20**，使其與卡位於同一個子網路中。
3. 檢查主機的連線：

   ```bash
   ping 192.168.1.10
   ```

4. 在第 3 節中使用 **192.168.1.10** 作為 `{ip}`。

這些位址適用於卡上的乙太網路埠。[透過 PCIe 介面的乙太網路](/hardware/getting-started/pcie-mode/virtual-network) 使用獨立的設定。

## 3. 刷入 3.0.0 版本的映像檔。

請在**主機**上執行本節中的指令。

1. 請確認 CLI 版本為 **2.1.19 或更高版本**。
2. 如果您已連接序列埠線，請保持序列埠主控台開啟。
3. 在另一個主機終端機中，啟動轉換程序：

   ```bash
   sima-cli bootimg -v 3.0.0 --netboot --devkit {ip} --autoflash
   ```

這個指令會在主機上啟動一個 TFTP 伺服器。它會指示板卡從該伺服器啟動。然後，`--autoflash` 選項會自動將映像檔寫入板卡。

在程序完成之前，請保持主機終端視窗開啟。請保持網路連線，並確保板卡已開啟電源。

## 4. 重新啟動板卡。

1. 請等待 `sima-cli` 指示您重新啟動板卡。
2. 重新啟動板卡。
3. 請等待板卡啟動。
4. 透過序列埠或 SSH 連接到板卡上。
5. 請檢查**板卡上**的韌體版本：

   ```bash
   cat /etc/buildinfo
   ```

6. 請確認版本為 **3.0.0** 後，再繼續進行系統設定。

對於 PCIe 主機系統，請依照 [PCIe 驅動程式安裝](/hardware/getting-started/pcie-mode/driver-installation) 的步驟來設定主機驅動程式。
