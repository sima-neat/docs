# 轉換為 eLxr

請使用本指南，將現有的 SiMa.ai **Yocto 架構的 DevKit** 轉換為 **eLxr 執行階段環境**，並在需要時切換回 Yocto。

:::note
從 SDK **2.0.0** 及其後續版本開始，即可使用 eLxr 平台，該平台可在 **Modalix DevKit** 上使用。

轉換為 eLxr 需要更新 tRoot 並重新刷寫 eMMC，此過程由 [Net Boot Recovery](/zh-Hant/hardware/getting-started/firmware-update/net-boot) 協助完成。
:::

**eLxr** 平台取代舊版的 Yocto 環境，成為 SiMa.ai DevKit 的預設執行階段。它提供：

- **簡化的更新** — 採用統一的根檔案系統佈局，並擴大了根檔案系統的容量。
- **標準套件管理工具** — 以 Debian 為基礎，提供持續性的套件管理功能。

在您進行遷移之前，請檢查 DevKit 目前執行的韌體版本。透過序列埠或 SSH 連線，然後執行：

```bash
cat /etc/buildinfo | grep DISTRO
```

您應該會看到以下其中一種情況：

```text
DISTRO = poky
```

或

```text
DISTRO = eLxr
```

如果您看到 `poky`，請按照以下步驟進行遷移。

<details open>
<summary><strong>步驟 1：更新至最新的 tRoot </strong></summary>

在轉換為 eLxr 之前，請將 DevKit 更新至最新的 **tRoot** 映像檔。

此更新使 tRoot（受信任的根）與 eLxr 相容。

當主機使用靜態 IP 位址 `192.168.1.10`，且 DevKit 可透過 `192.168.1.20` 存取時（請參閱 [網路設定](/zh-Hant/hardware/getting-started/standalone-mode/network)）：

<img src={useBaseUrl('/img/media/host-cli.png')} alt="在主機上執行" width="55" style={{float: 'left', marginRight: '8px'}} />

```bash
sima-user@sima-user-machine:~$ sima-cli update --ip 192.168.1.20 %platform_version% --troot_only
```

更新完成後，請**重新啟動 DevKit**，以應用變更。

</details>

<details open>
<summary><strong>步驟 2：透過網路啟動 eLxr 映像檔，並將其燒錄到 eMMC </strong></summary>。

剩餘的轉換步驟使用標準的 TFTP 網路啟動 + 燒錄程序，該程序已記錄在 [Net Boot Recovery](/zh-Hant/hardware/getting-started/firmware-update/net-boot) 中。請按照該程序，並使用以下針對 eLxr 進行設定的特定值：

- **步驟 2（啟動 TFTP 伺服器）：** 使用 `--boardtype modalix --fwtype elxr -v %platform_version%`。
- **步驟 3（設定 U-Boot）：** 在執行 `boot` 之前，除了設定 `boot_targets=net` 之外，還需要設定 `cpio_name=simaai-image-palette-modalix.cpio.gz`。
- **步驟 4（快閃）：** 在 `netboot>` 提示字元處輸入 `f`。

![連線圖](/img/tech-notes/conversion-diagram.png)

*連線圖*

在完成刷機且您重新啟動 DevKit 後，它會從 eMMC 執行 **eLxr**。

</details>

<details open>
<summary><strong>步驟 3：安裝 NEAT 並試用應用程式</strong></summary>

當 DevKit 執行 eLxr 時，請安裝 Palette Neat SDK，然後執行範例應用程式。請參閱 [NEAT 檔案](https://developer.sima.ai/software)，以了解安裝和試用應用程式的步驟。

</details>

<details open>
<summary><strong>切換回 Yocto（可選）</strong></summary>

若要切換回 Yocto，請再次執行 [網路啟動恢復](/zh-Hant/hardware/getting-started/firmware-update/net-boot)，並使用 `--fwtype yocto`。對於 Yocto 目標，不需要 `cpio_name` U-Boot 變數，只需要 `setenv boot_targets net`、`saveenv` 和 `boot`。

:::note
在轉換回 Yocto 時，**沒有最低 tRoot 版本要求**，因此可以跳過上述步驟 1。

如果在轉換為 eLxr 後，序列埠控制台上出現與 NFS 相關的錯誤訊息，則可以安全地忽略這些訊息。
:::

</details>

## 摘要

1. 更新至最新的 **tRoot** 映像檔（≥ 2.0.0）。
2. 請按照以下步驟進行：[網路啟動恢復](/zh-Hant/hardware/getting-started/firmware-update/net-boot)，使用 `--fwtype elxr` 和 eLxr `cpio_name`，將 eLxr 刷入 eMMC。
3. 安裝 Neat SDK，並透過 [NEAT 檔案](https://developer.sima.ai/software) 試用應用程式。
