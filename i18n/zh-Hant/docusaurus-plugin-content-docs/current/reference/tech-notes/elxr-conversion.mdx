# 轉換為 eLxr

請使用本指南，將現有的 SiMa.ai **Yocto 架構的 DevKit** 轉換為 **eLxr 執行階段環境**，並在需要時切換回 Yocto。

:::note
從 SDK **2.0.0** 及其後續版本開始，即可使用 eLxr 平台，該平台可在 **Modalix DevKit** 上使用。

轉換為 eLxr 需要更新 tRoot 並重新刷寫 eMMC，此過程由 [網路開機復原](/hardware/getting-started/firmware-update/net-boot) 協助完成。

使用 Windows 主機時，請在 **Windows 子系統 Linux 版（Windows Subsystem for Linux，WSL）** 的 Ubuntu 環境中安裝並執行 `sima-cli`。原生 Windows 環境不支援 NetBoot。請依照 [WSL 網路設定說明](/hardware/getting-started/firmware-update/net-boot#windows-hosts)操作。
:::

**eLxr** 平台取代舊版的 Yocto 環境，成為 SiMa.ai DevKit 的預設執行階段。它提供：

- **簡化的更新** — 採用統一的根檔案系統佈局，並擴大了根檔案系統的容量。
- **標準套件管理工具** — 以 Debian 為基礎，提供持續性的套件管理功能。

在您進行遷移之前，請檢查 DevKit 目前執行的韌體版本。透過序列埠或 SSH 連線，然後執行：

```bash
cat /etc/buildinfo | grep DISTRO
```

您應該會看到以下其中一種情況：

```text
DISTRO = poky
```

或

```text
DISTRO = eLxr
```

如果您看到 `poky`，請按照以下步驟進行遷移。

<details open>
<summary><strong>步驟 1：更新至最新的 tRoot </strong></summary>

在轉換為 eLxr 之前，請將 DevKit 更新至最新的 **tRoot** 映像檔。

此更新使 tRoot（受信任的根）與 eLxr 相容。

當主機使用靜態 IP 位址 `192.168.1.10`，且 DevKit 可透過 `192.168.1.20` 存取時（請參閱 [網路設定](/hardware/getting-started/standalone-mode/network)）：

<img src={useBaseUrl('/img/media/host-cli.png')} alt="在主機上執行" width="55" style={{float: 'left', marginRight: '8px'}} />

```bash
sima-user@sima-user-machine:~$ sima-cli update --ip 192.168.1.20 %platform_version% --troot_only
```

更新完成後，請**重新啟動 DevKit**，以應用變更。

</details>

<details open>
<summary><strong>步驟 2：透過網路啟動 eLxr 映像檔，並將其燒錄到 eMMC </strong></summary>。

剩餘的轉換步驟使用標準的 TFTP 網路啟動 + 燒錄程序，該程序已記錄在 [網路開機復原](/hardware/getting-started/firmware-update/net-boot) 中。請按照該程序，並使用以下針對 eLxr 進行設定的特定值：

- **步驟 2（啟動 TFTP 伺服器）：** 使用 `--boardtype modalix --fwtype elxr -v %platform_version%`。
- **步驟 3（設定 U-Boot）：** 如果無法遠端設定，請依照復原指南，透過序列主控台載入開機指令碼。
- **步驟 4（燒錄）：** 手動燒錄時，請在 `netboot>` 提示輸入 `f`，並在燒錄完成後接受重新啟動提示。

![連線圖](/img/tech-notes/conversion-diagram.png)

*連線圖*

DevKit 重新啟動後，會從 eMMC 執行 **eLxr**。

</details>

<details open>
<summary><strong>步驟 3：安裝 Palette SDK 並試用應用程式</strong></summary>

當 DevKit 執行 eLxr 時，請安裝 Palette SDK，然後執行範例應用程式。請參閱 [Palette SDK 文件](https://developer.sima.ai/software)，以了解安裝和試用應用程式的步驟。

</details>

<details open>
<summary><strong>切換回 Yocto（可選）</strong></summary>

若要切換回 Yocto，請指定 `--fwtype yocto` 和目標 Yocto 韌體版本，再依照[網路開機復原](/hardware/getting-started/firmware-update/net-boot)的步驟操作。

:::note
在轉換回 Yocto 時，**沒有最低 tRoot 版本要求**，因此可以跳過上述步驟 1。

如果在轉換為 eLxr 後，序列埠控制台上出現與 NFS 相關的錯誤訊息，則可以安全地忽略這些訊息。
:::

</details>

## 摘要

1. 更新至最新的 **tRoot** 映像檔（≥ 2.0.0）。
2. 使用 `--fwtype elxr` 並依照[網路開機復原](/hardware/getting-started/firmware-update/net-boot)的步驟，將 eLxr 燒錄到 eMMC。
3. 安裝 Palette SDK，並透過 [Palette SDK 文件](https://developer.sima.ai/software) 試用應用程式。
